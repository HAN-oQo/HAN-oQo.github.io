사용법

A. 로컬 세션 (권장)
  1. 이 레포에서 Claude Code 실행 → 공부 띄워줘
  2. Claude가 python3 tools/study_server.py 로 http://localhost:8000/learn/ 를 띄움
  3. 답안은 learn/progress/ 에 저장(gitignore) → Claude가 서술형을 채점해 feedback.json 에 기록 → 새로고침하면 반영
  4. 확인 퀴즈는 진단 결과에 맞춰 Claude가 생성해 data/mX.json 에 추가
B. 웹 (GitHub Pages)
  1. 객관식·계산 문제는 즉시 채점, 진행은 이 브라우저에 저장
  2. 서술형은 채점 프롬프트 복사 → Claude 대화에 붙여넣기 → 응답 끝의 JSON 을 아래에 붙여넣기
  3. 오른쪽 아래 ✦ Claude에게 질문 버튼으로 이 페이지에 대해 claude.ai에 바로 질문 가능
채점 결과 붙여넣기 (Claude 응답 끝의 {"m1-d3": {"score": 2, ...}} 줄)
