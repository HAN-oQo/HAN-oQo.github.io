ReplaySSM: Cache SSM Inputs, Not StateSSM / hybridvLLMarXiv:2610.13778
arxiv.org/abs/2610.13778 →

Problem문제 정의State-space layers keep a fixed-size recurrent state, but reading and writing it at every decoding step creates large state I/O at low arithmetic intensity in hybrid models. This eager state handling also leaves speculative decoding without a cheap rollback and feeds state quantization error into later updates.상태공간(SSM) 계층은 고정 크기 재귀 상태를 유지하지만, 디코딩 스텝마다 상태를 읽고 쓰면 하이브리드 모델에서 산술 강도가 낮은 대규모 상태 I/O가 생긴다. 이런 즉시 상태 관리는 추측 디코딩에 값싼 롤백도 주지 못하고 상태 양자화 오차를 이후 갱신에 흘려 넣는다.

Method방법ReplaySSM unrolls the recurrence so the state is a checkpoint plus a buffer of recent SSM inputs, which separates output computation from checkpoint updates. The checkpoint is refreshed only periodically, speculative rollback becomes a buffer-pointer move, and a low-precision checkpoint can serve outputs while a higher-precision one serves recurrent updates.ReplaySSM은 재귀를 펼쳐 상태를 체크포인트와 최근 SSM 입력 버퍼로 표현하고, 출력 계산과 체크포인트 갱신을 분리한다. 체크포인트는 주기적으로만 갱신하고, 추측 롤백은 버퍼 포인터 이동이 되며, 저정밀 체크포인트가 출력을 맡고 고정밀 체크포인트가 재귀 갱신을 맡는다.

Results결과Implemented in vLLM for Mamba-2 and Gated DeltaNet, it roughly halves the dominant state memory traffic and speeds up standard decoding by 1.20-1.47x over a tuned vLLM baseline at batch size 256 across four hybrid models. On the two 120B-class models it delivers about 1.8x the throughput of vLLM's speculative decoding.vLLM에서 Mamba-2와 Gated DeltaNet용으로 구현했으며, 지배적인 상태 메모리 트래픽을 대략 절반으로 줄이고 배치 256에서 네 가지 하이브리드 모델 전반에 걸쳐 튜닝된 vLLM 기준선 대비 표준 디코딩을 1.20~1.47배 가속한다. 120B급 두 모델에서는 vLLM의 추측 디코딩 대비 약 1.8배 처리량을 낸다.

Summary요약Treating the state as inputs plus a checkpoint turns most state writes and all speculative rollbacks into cheap buffer operations.상태를 입력과 체크포인트로 다루면 대부분의 상태 쓰기와 모든 추측 롤백이 값싼 버퍼 연산으로 바뀐다.

Problem문제 정의Accelerators with native 4-bit support need both weights and activations quantized to realize their throughput gains. Weight quantization is well studied, but activation quantization is harder and usually needs calibration data.4비트를 기본 지원하는 가속기에서 처리량 이득을 얻으려면 가중치와 활성값을 모두 양자화해야 한다. 가중치 양자화는 많이 연구됐지만 활성값 양자화는 더 어렵고 보통 보정 데이터가 필요하다.

Method방법DualQuant minimizes weight-reconstruction MSE and uses the resulting scaling factors, as a by-product, for per-channel activation rescaling before activation quantization, so no calibration data is needed. It solves a non-differentiable reconstruction problem with variable splitting and block coordinate descent with closed-form subproblem updates, and supports the MX family and NVFP4.DualQuant는 가중치 재구성 MSE를 최소화하고 그 부산물인 스케일 인자를 활성값 양자화 전 채널별 재조정에 쓰므로 보정 데이터가 필요 없다. 미분 불가능한 재구성 문제를 변수 분할과 블록 좌표 하강으로 풀며 각 하위 문제는 닫힌 형태로 갱신되고, MX 계열과 NVFP4를 지원한다.

Problem문제 정의Long-context serving runs out of KV memory before the hardware reaches useful throughput. HiSparse keeps history in host memory and fetches only selected entries, but it uses one cache budget at every load and does not handle draft-model speculative decoding such as DSpark and DFlash2.장문 컨텍스트 서빙은 하드웨어가 유용한 처리량에 도달하기 전에 KV 메모리가 바닥난다. HiSparse는 기록을 호스트 메모리에 두고 선택된 항목만 가져오지만 부하와 무관하게 하나의 캐시 예산을 쓰고, DSpark나 DFlash2 같은 드래프트 모델 추측 디코딩은 다루지 못한다.

Method방법Adaptive DHiSparse supports speculative decoding over a hierarchical sparse KV cache and adapts residency to load: it protects the required working set, keeps extra history while GPU memory is spare, and recovers the rest through exact fused retrieval. Queries share missing-row retrieval, draft KV uses a window-bounded ring, and verification staging is reused across layer groups.Adaptive DHiSparse는 계층형 희소 KV 캐시 위에서 추측 디코딩을 지원하고 부하에 따라 상주량을 조절한다. 필요한 작업 집합은 보호하고, GPU 메모리가 남으면 추가 기록을 유지하며, 나머지는 정확한 융합 검색으로 복구한다. 질의들이 누락 행 검색을 공유하고, 드래프트 KV는 윈도 제한 링을 쓰며, 검증 스테이징은 레이어 그룹 간에 재사용된다.
