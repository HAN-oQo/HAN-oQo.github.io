vLLM v0.25.0 — Model Runner V2 default for all dense models, PagedAttention removed, Transformers backend now as fast as native vLLMJul 11

vLLM cut v0.25.0 on Jul 11 (558 commits from 232 contributors), the biggest structural release in months. Model Runner V2 (MRv2) is now the default execution path for all dense models (#44443), adding EVS support, realtime embeddings, prefix caching for Mamba hybrids, multimodal-prefix bidirectional attention, and dynamic speculative decoding under full CUDA graphs. Post-release main kept moving through Jul 12 (~39 commits since): DP-replica-aware tiering offload, a runtime draft-weight update path for speculative decoding (#46725), Qwen MoE all-reduce replaced with reduce-scatter (#47006), and partial prefix-cache hits for hybrid models (#46384). The throughline: retire the legacy path and make MRv2 the one runner.

SGLang v0.5.15 — GLM-5.2 NVFP4 tuned to 500+ tok/s/user on 8×B300, Spec V2 default (+11% TPS), IndexShare MTP SGLangJul 10

SGLang shipped v0.5.15 on Jul 10 and kept ~51 commits landing on main through Jul 12. The headline is production tuning of GLM-5.2 NVFP4 on Blackwell — 500+ tok/s/user on 8×B300 and 450 on 4×GB300 at batch size 1. Spec V2 is now the default: zero-overhead scheduling via CUDA-graphable DSA draft-extend, dropped D2H/H2D syncs and fused metadata ops for +11% end-to-end TPS, plus IndexShare MTP that reuses the indexer top-k across draft steps for up to 1.9× lower draft-step cost at long context. Post-release main added DSpark confidence-scheduled speculative decoding (#30261), a kill-switch env for draft-extend CUDA-graph capture (#30944), optimistic-prefill PD improvements, an extensible mxfp8 MoE runner backend list, and a VLM prefill profiler. The throughline: squeeze Blackwell for low-bit MoE serving and make aggressive speculative decoding safe by default.

Method방법DominoTree uses the released Domino drafter's GRU-based causal correction to make each draft token's distribution path-dependent, then builds a conditional tree-structured drafting on top — training-free — so branches reflect Domino's causal structure DDTree's factorized formulation cannot.DominoTree는 공개된 Domino 드래프터의 GRU 기반 인과 보정으로 각 초안 토큰 분포를 경로 의존적으로 만든 뒤, 그 위에 조건부 트리 구조 드래프팅을 학습 없이 구축한다 — 그래서 분기가 DDTree의 인수분해 정식화가 담지 못하는 Domino의 인과 구조를 반영한다.
