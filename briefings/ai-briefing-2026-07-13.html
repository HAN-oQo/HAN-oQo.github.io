vLLM v0.25.0 — Model Runner V2 default for all dense models, PagedAttention removed, Transformers backend now as fast as native vLLMJul 11

vLLM cut v0.25.0 on Jul 11 (558 commits from 232 contributors), the biggest structural release in months. Model Runner V2 (MRv2) is now the default execution path for all dense models (#44443), adding EVS support, realtime embeddings, prefix caching for Mamba hybrids, multimodal-prefix bidirectional attention, and dynamic speculative decoding under full CUDA graphs. The legacy PagedAttention implementation was deleted outright (#47361) now that the V1/MRv2 backends are standard, and the Transformers modeling backend reached parity with native vLLM speed (#47187) with FP8 MoE support. Post-release main kept moving through Jul 12 (~39 commits since): DP-replica-aware tiering offload, a runtime draft-weight update path for speculative decoding (#46725), Qwen MoE all-reduce replaced with reduce-scatter (#47006), and partial prefix-cache hits for hybrid models (#46384). The throughline: retire the legacy path and make MRv2 the one runner.

SGLang v0.5.15 — GLM-5.2 NVFP4 tuned to 500+ tok/s/user on 8×B300, Spec V2 default (+11% TPS), IndexShare MTP SGLangJul 10

SGLang shipped v0.5.15 on Jul 10 and kept ~51 commits landing on main through Jul 12. The headline is production tuning of GLM-5.2 NVFP4 on Blackwell — 500+ tok/s/user on 8×B300 and 450 on 4×GB300 at batch size 1. Spec V2 is now the default: zero-overhead scheduling via CUDA-graphable DSA draft-extend, dropped D2H/H2D syncs and fused metadata ops for +11% end-to-end TPS, plus IndexShare MTP that reuses the indexer top-k across draft steps for up to 1.9× lower draft-step cost at long context. Post-release main added DSpark confidence-scheduled speculative decoding (#30261), a kill-switch env for draft-extend CUDA-graph capture (#30944), optimistic-prefill PD improvements, an extensible mxfp8 MoE runner backend list, and a VLM prefill profiler. The throughline: squeeze Blackwell for low-bit MoE serving and make aggressive speculative decoding safe by default.

SGLang이 7/10 v0.5.15을 내고 7/12까지 main에 ~51커밋을 더했다. 중심은 Blackwell용 GLM-5.2 NVFP4 튜닝으로, 배치 1에서 8×B300 500+ tok/s/user, 4×GB300 450을 낸다. Spec V2가 기본이 됐다. CUDA 그래프화한 DSA draft-extend로 스케줄링 오버헤드를 없애고, D2H/H2D 동기화 제거와 메타데이터 op 퓨전으로 종단 TPS를 +11% 올렸다. IndexShare MTP는 draft 단계끼리 인덱서 top-k를 재사용해 장문맥 draft 비용을 최대 1.9× 줄인다. 릴리스 뒤에는 DSpark 신뢰도 스케줄 추측 디코딩(#30261), draft-extend CUDA 그래프 캡처 킬스위치 env(#30944), 낙관적 프리필 PD 개선, mxfp8 MoE 러너 백엔드 확장, VLM 프리필 프로파일러가 들어왔다. 저비트 MoE에서 Blackwell 성능을 끌어내고 공격적 추측 디코딩을 기본값으로도 안전하게 만드는 흐름이다.
