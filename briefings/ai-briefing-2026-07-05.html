Problem문제 정의Even with long context windows, LLMs often fail to use relevant evidence that is already in the input — a gap between context access and effective context utilization. There is no clean mechanism to reorganize what is already present so the model actually attends to it before answering.긴 컨텍스트 윈도우가 있어도 LLM은 입력에 이미 있는 관련 증거를 제대로 쓰지 못한다 — 컨텍스트 접근과 실효적 활용 사이의 간극이다. 답하기 전에 이미 존재하는 것을 재조직해 실제로 주목하게 만드는 깔끔한 장치가 없다.
Method방법ReContext is a training-free inference method. It uses the model's own internal relevance signals to build a query-conditioned evidence pool, then "replays" that pool before final generation while preserving the full original context. This recursive selection separates evidence organization from answer generation — no training, external memory, or context pruning. The authors frame it via associative memory: context is a memory store, the question a retrieval cue, attention the cue–trace association, and replay a trace reactivation.ReContext는 학습 없는 추론 방법이다. 모델 내부 관련성 신호로 질의 조건 증거 풀을 만들고, 원본 컨텍스트 전체를 유지한 채 최종 생성 전에 그 풀을 "재생"한다. 이 재귀 선택은 증거 조직과 답 생성을 분리한다 — 학습·외부 메모리·컨텍스트 프루닝 없음. 저자들은 연상 기억으로 설명한다: 컨텍스트=기억 저장소, 질문=검색 단서, 어텐션=단서-흔적 연상, 재생=흔적 재활성.

OrbitQuant (arXiv 2607.02461, submitted Jul 2) ↗OrbitQuant (arXiv 2607.02461, 7/2 제출) ↗
Problem문제 정의Diffusion transformers (DiTs) give SOTA image/video generation but are expensive at inference. Post-training quantization is the natural fix, yet DiT activations shift across timesteps, prompts, and guidance branches, forcing prior methods to re-fit calibration data for every new checkpoint or modality.확산 트랜스포머(DiT)는 최고 수준 이미지·영상 생성을 주지만 추론이 비싸다. 사후 학습 양자화가 자연스러운 해법이지만, DiT 활성값은 타임스텝·프롬프트·가이던스 분기에 걸쳐 이동해, 기존 방법은 새 체크포인트·모달리티마다 보정 데이터를 다시 맞춰야 한다.
Method방법OrbitQuant is a data-agnostic weight-activation quantizer that bypasses range estimation by quantizing in a normalized, rotated basis. A randomized permuted block-Hadamard (RPBH) rotation concentrates each coordinate around one fixed, known marginal regardless of input, so a single Lloyd-Max codebook serves all timesteps, prompts, and layers of a given dimension. The rotation is absorbed into weight rows offline, so only a forward rotation on activations remains at runtime — and the same recipe transfers image→video with no per-modality tuning.OrbitQuant은 정규화·회전 기저에서 양자화해 범위 추정을 우회하는 데이터 비의존 가중치-활성 양자화기다. 랜덤 순열 블록-Hadamard(RPBH) 회전이 입력과 무관하게 각 좌표를 하나의 고정·기지 주변분포에 집중시켜, 단일 Lloyd-Max 코드북이 한 차원의 모든 타임스텝·프롬프트·층을 담당한다. 회전은 오프라인에서 가중치 행에 흡수돼 런타임엔 활성 순방향 회전만 남으며, 같은 레시피가 이미지→영상으로 모달리티별 튜닝 없이 전이된다.
Results결과Across FLUX.1, Z-Image-Turbo, Wan 2.1, and CogVideoX, OrbitQuant sets the state of the art for PTQ at several low-bit settings, and pushes PTQ of image diffusion transformers to W2A4 with usable generation quality.FLUX.1·Z-Image-Turbo·Wan 2.1·CogVideoX에서 OrbitQuant은 여러 저비트 설정에서 PTQ 최고 성능을 세우고, 이미지 확산 트랜스포머의 PTQ를 쓸 만한 품질로 W2A4까지 밀어붙인다.
Summary요약Quantize DiTs in a rotated basis where every coordinate lands on one known distribution, so a single codebook works for all timesteps, prompts, and modalities — no calibration data.모든 좌표가 하나의 기지 분포에 놓이는 회전 기저에서 DiT를 양자화해, 단일 코드북이 모든 타임스텝·프롬프트·모달리티에 통하게 하라 — 보정 데이터 불필요.

Problem문제 정의LLM inference is a fast-growing slice of data-center energy.
