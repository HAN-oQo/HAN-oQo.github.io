ReCache: Efficient KV Cache Reuse and Compression for Tool-Augmented LLM AgentsKV cachetool schemasarXiv:2608.19662
arxiv.org/abs/2608.19662 — Fang, Wei, Hu et al. (submitted Aug 20 2026)
Problem / 문제 정의 Agent prompts repeat the same tool and skill schemas in different combinations and orders. Prefix caching only hits on a byte-for-byte match from position zero, so swapping two tools invalidates everything after them, and the schemas get re-encoded on almost every call. 에이전트 프롬프트에는 같은 도구·스킬 스키마가 조합과 순서만 바뀐 채 반복된다. 프리픽스 캐싱은 0번 위치부터 바이트 단위로 같아야 적중하므로, 도구 두 개의 순서만 바뀌어도 그 뒤가 전부 무효가 되고 스키마를 거의 매번 다시 인코딩한다.
Method / 방법 ReCache caches each resource on its own. Resource-wise attention removes cross-resource attention and gives each resource local positions, so its KV block stays valid in any combination or order. Visibility is then limited to contribution-selected layer and KV-head-group routes, and structural plus semantic pruning keeps only the fields needed for invocation. ReCache는 자원마다 따로 캐시한다. 자원별 어텐션이 자원 사이 어텐션을 없애고 자원마다 지역 위치를 주므로, KV 블록이 어떤 조합과 순서에서도 그대로 유효하다. 여기에 기여도로 고른 레이어·KV 헤드 그룹 경로에만 자원을 보이게 하고, 구조적·의미적 프루닝으로 호출에 필요한 필드만 남긴다.
Results / 결과 On a benchmark built from seven public tool- and skill-use datasets (including resource-disjoint tests), resource-wise attention matches dense quality (82.3% vs 82.4% Inv-F1) with a 3.655× TTFT speedup. The full framework cuts allocated KV-tensor memory by 92.43% and speeds attention up 1.423×. 공개 도구·스킬 데이터셋 7종으로 만든 벤치마크(자원 비중첩 테스트 포함)에서 자원별 어텐션은 밀집 방식과 품질이 같으면서(Inv-F1 82.3% 대 82.4%) TTFT를 3.655배 줄인다. 전체 프레임워크는 KV 텐서 메모리를 92.43% 줄이고 어텐션을 1.423배 빠르게 한다.
Summary / 요약 It gives up attention between tool descriptions, which the model barely used. Without it, each schema block becomes a self-contained cache entry. 모델이 거의 쓰지 않던 도구 설명 사이의 어텐션을 포기한 대가로, 스키마 블록 하나하나가 독립된 캐시 항목이 된다.

A Thread-Register Decoupled GPU Execution Model for Efficient Tensor Computation (FIBER)GPU architecturemixed precisionarXiv:2608.19628
arxiv.org/abs/2608.19628 — Liu, Leng, Zhou et al. (submitted Aug 20 2026)
Problem / 문제 정의 Tensor Core throughput keeps rising, and operand supply already moved from registers (Ampere) to redundancy-free memory (Hopper, Blackwell). Work assignment has not: parallelism is fixed and scheduling is coarse, which handles the constant GEMM/non-GEMM interleaving of LLM serving badly. Tensor Core 처리량은 계속 오르고, 오퍼랜드 공급도 Ampere의 레지스터 방식에서 Hopper·Blackwell의 중복 없는 메모리 방식으로 바뀌었다. 그런데 작업 할당은 그대로다. 병렬성은 고정이고 스케줄링은 거칠어서, GEMM과 비-GEMM이 계속 섞이는 LLM 서빙에 맞지 않는다.
Method / 방법 FIBER adds a new SIMT execution unit, the fiber, which owns no private registers: it holds minimal control state and reaches SM registers through a shared view. That allows dynamic parallelism, register-level dataflow scheduling and duplicate-free operand supply. ISA, microarchitecture and compiler are extended together for shared-register addressing, conflict-free operand delivery and fiber-based program mapping. FIBER는 SIMT에 fiber라는 실행 단위를 더한다. fiber는 전용 레지스터 없이 최소한의 제어 상태만 갖고, 공유 뷰로 SM 레지스터에 접근한다. 덕분에 병렬성을 동적으로 바꾸고, 레지스터 단위로 데이터플로를 스케줄링하고, 행렬 오퍼랜드를 중복 없이 공급한다. 이를 위해 ISA·마이크로아키텍처·컴파일러를 함께 확장했다.
Results / 결과 In a typical mixed-precision LLM serving scenario: 2.25× end-to-end on Ampere (1.15× for FP16 alone), 1.8× on Hopper, 2.09× on Blackwell, and up to 2.49× at kernel level. 전형적인 혼합 정밀도 LLM 서빙 시나리오에서 종단 가속은 Ampere 2.25배(FP16 연산만은 1.15배), Hopper 1.8배, Blackwell 2.09배이고, 커널 단위로는 최대 2.49배다.
Summary / 요약 An architecture proposal, not something a serving engine can enable today. It names a real cost in mixed-precision decode: threads hold registers they are not using while the tensor pipeline waits for operands. 지금 서빙 엔진에서 켤 수 있는 기능은 아니고 아키텍처 제안이다. 다만 혼합 정밀도 디코드의 실제 비용을 짚는다. 텐서 파이프라인이 오퍼랜드를 기다리는 동안 스레드는 쓰지도 않는 레지스터를 붙잡고 있다.

Accelerating Visual On-Policy Distillation with Batched Speculative Jacobi Rollouts (HB-SJD)speculative decodingrollout costarXiv:2608.18183
arxiv.org/abs/2608.18183 — Shan, Yu, Lin et al. (submitted Aug 18 2026)
Problem / 문제 정의 On-policy distillation trains a compact visual autoregressive model on its own rollouts, so every training step pays for token-by-token inference. Speculative Jacobi Decoding emits several tokens per forward pass without a draft model, but it was built for a single sequence, not a batched training loop. 온폴리시 증류는 소형 시각 자기회귀 모델을 스스로 만든 롤아웃으로 학습시키므로, 학습 스텝마다 토큰 단위 추론 비용을 낸다. Speculative Jacobi Decoding은 초안 모델 없이 순전파 한 번에 여러 토큰을 내지만 단일 시퀀스용이라 배치 학습 루프에 맞지 않는다.
Method / 방법 HB-SJD is a batched SJD rollout backend. Each image decodes at its own pace, yet images at different positions are verified together in batched forwards. As images finish, it switches between Full and Compact modes so finished slots stop costing compute. Only the student's rollout backend changes; teacher, objective and optimizer stay the same. Problem / 문제 정의 Hadith computational science, the machine processing of the Prophet's reported sayings and practices including narrator chains and authenticity, is being reshaped by transformers, retrieval pipelines and LLMs. Prior reviews note growth but not which advances are robust, which are benchmark-bound, and what still blocks scholarly use. 하디스 계산과학은 예언자의 전승된 언행을 전승자 사슬과 진위 판정까지 포함해 기계로 처리하는 분야로, 트랜스포머·검색 파이프라인·LLM으로 재편되고 있다. 기존 리뷰는 문헌이 늘었다는 사실만 적을 뿐, 어떤 진전이 견고하고 어떤 것이 벤치마크에 묶였으며 무엇이 학술 활용을 막는지는 다루지 않는다.

Results / 결과 Progress is uneven. Data, segmentation, narrator and source verification, and LLM-assisted enrichment have advanced.
