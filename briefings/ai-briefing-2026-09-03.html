Problem문제 정의On a phone, the OS reclaims memory when the user switches apps, evicting the LLM's weights and KV cache. The next request must reload from slow storage or recompute, so the first token is late.휴대폰에서는 사용자가 앱을 바꾸면 운영체제가 메모리를 회수해 LLM 가중치와 KV 캐시를 쫓아낸다. 다음 요청은 느린 저장소에서 다시 읽거나 재계산해야 해서 첫 토큰이 늦다.

Problem문제 정의A KV cache belongs to the model that made it, so a second model must re-prefill shared context. Method방법CacheBridge keeps the closed-form affine interface and adds three things: architecture-indexed support (each target head maps from one matched source head), attention-aligned calibration weighted by causal attention sensitivity, and bounded construction via a fused GPU kernel that accumulates sufficient statistics.CacheBridge는 닫힌 형식의 아핀 인터페이스를 유지하고 세 가지를 더한다. 타깃 헤드마다 대응 소스 헤드 하나만 쓰는 아키텍처 색인, 인과 어텐션 민감도로 가중한 보정, 충분통계를 누적하는 융합 GPU 커널로 비용을 묶은 구성이다.
