Problem문제 정의Dynamic sparse attention (DSA) speeds long-context decoding by attending only to the top-K KV blocks relevant to each query, but it introduces a serialized selection-to-attention dependency: the model must finish picking blocks before it can attend, and that step becomes a new latency bottleneck.동적 희소 어텐션(DSA)은 쿼리마다 top-K KV 블록만 봐서 롱컨텍스트 디코딩을 빠르게 한다. 대신 블록 선택이 끝나야 어텐션을 시작할 수 있어, 선택 단계가 새 병목이 된다.
Method방법PRR is a speculate-reuse-repair runtime that exploits temporal locality in DSA selections: it predicts the likely blocks for the next step and speculatively attends over them while selection is still in flight, reusing recent selections, then repairs the result if the actual selection differs.DSA 선택의 시간적 지역성을 이용한다. 최근 선택을 재사용해 다음 블록을 예측하고, 실제 선택이 진행되는 동안 미리 어텐션한 뒤, 예측이 틀리면 결과를 수선한다.
Results결과By overlapping speculative attention with block selection and only repairing on mismatch, PRR hides the selection-to-attention latency that vanilla DSA exposes, accelerating long-context decoding.추측 어텐션을 블록 선택과 겹쳐 선택→어텐션 지연을 숨기고 롱컨텍스트 디코딩을 가속한다.
