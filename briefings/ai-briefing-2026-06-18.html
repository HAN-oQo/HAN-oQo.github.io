Problem문제 정의Sparse MoE grows parameters under a fixed inference budget by activating a top-k of experts. But discrete top-k is not differentiable, so the active-expert count is fixed per input and compute is wasted on tokens that need fewer.희소 MoE는 상위 k개 전문가만 켜서 고정 추론 예산 안에서 파라미터를 키운다. 그런데 이산 top-k는 미분할 수 없어 입력마다 활성 전문가 수가 고정되고, 더 적은 전문가로 충분한 토큰에서도 연산이 낭비된다.
Method방법A truncated soft top-k LapSum relaxation makes routing trainable by gradients. The mean number of active experts per layer is a parameter under a global budget, so the model learns how to spread expert capacity across layers while staying compatible with autoregressive modeling.잘린 소프트 top-k LapSum 완화로 라우팅을 경사로 학습한다. 레이어별 평균 활성 전문가 수를 파라미터로 두고 전역 예산 제약을 걸어, 자기회귀 모델링과 호환되면서 레이어 간 전문가 배분을 학습한다.
Results결과Matches or beats sparse MoE on language modeling and downstream tasks with significantly fewer active experts; the learned per-layer allocation is highly non-uniform rather than a fixed top-k.훨씬 적은 전문가를 켜고도 언어 모델링과 다운스트림에서 희소 MoE와 같거나 낫다. 학습된 레이어별 배분은 고정 top-k와 달리 매우 불균일하다.
Summary요약Differentiable routing lets the model decide how many experts each layer gets under one global budget.라우팅을 미분 가능하게 만들어, 전역 예산 안에서 레이어별 전문가 수를 모델이 정한다.

Problem문제 정의Heterogeneous serving splits scheduling into two isolated layers: model routers pick by quality and cost but ignore instance load, and load balancers optimize queues but ignore quality. Neither reaches the best quality–latency–cost trade-off.이질적 서빙 스택은 스케줄링을 두 계층으로 나눠 따로 최적화한다. 모델 라우터는 품질·비용만 보고 인스턴스 부하를 무시하고, 로드밸런서는 큐만 보고 품질을 무시해 어느 쪽도 품질·지연·비용의 최적 절충에 닿지 못한다.
Method방법RouteBalance fuses both into one online assignment over concrete model instances, trading off quality, latency, and cost jointly. Problem문제 정의Serving clusters spread requests over many GPU workers, and failures are common at scale. A dead worker loses its GPU-resident KV caches and capacity at once, so survivors absorb redirected traffic while re-running interrupted requests from scratch.서빙 클러스터는 요청을 여러 GPU 워커에 나누고, 규모가 커지면 장애는 흔하다. 워커가 죽으면 GPU 상주 KV 캐시와 서빙 용량을 한꺼번에 잃어, 남은 워커가 재라우팅 트래픽을 받으면서 중단된 요청을 처음부터 다시 돌린다.
Method방법Existing systems restart interrupted requests or restore KV from a fixed neighbor, ignoring current load.
