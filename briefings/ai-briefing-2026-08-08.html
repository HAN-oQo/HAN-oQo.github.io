DBLast: Dependent Block Drafting for Stochastic Speculative Decodingspeculative decodingstochastic sampling2608.05448
DBLast — dependent block drafting for non-greedy decoding (arXiv 2608.05448) ↗DBLast: 비탐욕 디코딩용 종속 블록 드래프팅 (arXiv 2608.05448) ↗
Problem문제 정의Speculative decoding proposes future tokens with a lightweight drafter that a target model verifies. Recent block or diffusion-style drafters predict several positions in one pass but assume those positions are conditionally independent — an assumption that breaks under non-greedy (stochastic) sampling, where multiple continuations are plausible and accepted draft length collapses as target entropy rises.블록·확산형 드래프터는 여러 위치를 한 번에 예측하면서 위치끼리 조건부 독립이라고 가정한다. 이 가정은 이어질 토큰 후보가 여럿인 비탐욕 샘플링에서 깨지고, 타깃 엔트로피가 클수록 수락 길이가 급감한다.
Method방법DBLast builds a dependent block drafter on a low-rank latent mixture over token positions, so drafted positions are modeled jointly rather than independently. It is trained with an acceptance-oriented objective that directly optimizes the expected verified (accepted) length, aligning the drafter with what the target will actually accept.저랭크 잠재 혼합으로 초안 위치들을 결합 분포로 모델링한다. 기대 수락 길이를 직접 최적화하는 목적함수로 학습한다.
Results결과On Qwen3-4B and Qwen3-8B across GSM8K, MT-Bench, HumanEval, and creative-writing benchmarks, DBLast consistently improves accepted length over independent block sampling, restoring speculative speedups precisely in the non-greedy regime where prior block drafters degrade.Qwen3-4B·8B에서 GSM8K·MT-Bench·HumanEval·창작 벤치마크 모두 독립 블록 샘플링보다 수락 길이가 길다. 기존 블록 드래프터가 무너지는 비탐욕 구간에서 가속을 되찾는다.
Summary요약A block drafter that models inter-position dependence and trains for acceptance, restoring speculative decoding under stochastic target sampling.위치 간 의존을 모델링하고 수락 길이를 목표로 학습해, 확률적 샘플링에서도 스펙 디코딩이 통하게 만든다.

QEvict: Recoverable Quantized KV Eviction for Attention-Drift-Robust Long-Context DecodingKV-cachequantization2608.05326
QEvict — reversible three-tier KV eviction (arXiv 2608.05326) ↗QEvict: 되돌릴 수 있는 3계층 KV 축출 (arXiv 2608.05326) ↗
Problem문제 정의KV-cache eviction cuts memory by dropping tokens judged unimportant, but the decision is irreversible — once evicted, a token can never be reused. The authors show this is brittle: token and window importance drift as generated queries evolve, so standard policies permanently discard states that later receive heavy attention under the full-cache model.KV 축출은 한번 버린 토큰을 다시 쓸 수 없다. 그런데 생성이 진행되면서 토큰 중요도가 바뀌기 때문에, 기존 정책은 나중에 큰 어텐션을 받을 상태까지 영구히 버린다.
Method방법QEvict is a three-tier KV scheme that replaces binary retain/delete with recoverable eviction: high-confidence windows stay full-precision, intermediate windows go to a quantized recoverable tier, and only the lowest-confidence windows are deleted. During decoding, cumulative attention updates each window's importance, and a quantized window that becomes important again is dequantized and promoted back to full precision. Two diagnostics (Future Missed Mass, Global LIR) measure attention lost to discarded states.보존/삭제 이분법 대신 3계층을 둔다. 고신뢰 윈도는 풀 정밀도, 중간 윈도는 양자화 복구 계층, 최저 신뢰 윈도만 삭제한다. 누적 어텐션으로 중요도를 갱신해 다시 중요해진 양자화 윈도는 풀 정밀도로 승격하고, Future Missed Mass·Global LIR 두 지표로 잃은 어텐션을 잰다.
Results결과Across long-context understanding, retrieval, and reasoning benchmarks, QEvict consistently beats representative eviction and quantization baselines under a fixed memory budget, reducing missed attention and improving information retention as query-driven importance drifts.같은 메모리 예산에서 장문맥 이해·검색·추론 벤치마크 전반에 걸쳐 기존 축출·양자화 기준선을 앞선다.
Summary요약Turn irreversible KV eviction into a reversible full / quantized / deleted hierarchy so drifting-importance tokens can be recovered instead of lost.되돌릴 수 없던 KV 축출을 풀·양자화·삭제 3계층으로 바꿔, 중요도가 바뀐 토큰을 되살린다.

Method방법AcceptMoE is a verifier-side expert selector that combines target-router scores with offline-estimated commitment probabilities, automatically self-sizing the number of eligible experts per verification block with no user-set budget.
