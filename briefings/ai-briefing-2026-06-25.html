Execution-State Capsules — graph-bound checkpoint/restore for on-device servingruntimeon-device2606.20537
Execution-State Capsules: Graph-Bound Execution-State Checkpoint and Restore for Low-Latency, Small-Batch, On-Device Physical-AI Serving (arXiv 2606.20537, submitted Jun 18) ↗Execution-State Capsules: Graph-Bound Execution-State Checkpoint and Restore for Low-Latency, Small-Batch, On-Device Physical-AI Serving (arXiv 2606.20537, 6/18 제출) ↗
Problem문제 정의Mainstream serving reuses prefix work through paged or radix KV caches — but that manages only one positional fragment of execution state. In low-latency, small-batch, on-device serving (interactive agents, speech systems, robot policies) that repeatedly branch, reset, interrupt, and re-enter under tight responsiveness budgets, the rest of the live state has no first-class reuse mechanism.주류 서빙은 paged·radix KV 캐시로 접두사를 재사용하지만, 이는 실행 상태의 한 조각만 관리한다. 분기·리셋·중단·재진입이 잦은 저지연·소배치 온디바이스 서빙(대화 에이전트, 음성, 로봇 정책)에서는 나머지 상태를 재사용할 방법이 없다.
Method방법The paper introduces execution-state capsules, a graph-bound checkpoint/restore of the complete restorable state at a committed boundary. FlashRT, a white-box backend kernel runtime, runs captured graph plans over contiguous static buffers with no block-table indirection. Because the live state is a closed set of named buffers, a capsule can snapshot, restore, fork, or roll back the whole execution boundary — KV, recurrent state, convolution state, and more.커밋된 경계의 복원 가능한 상태 전체를 그래프 단위로 체크포인트/복원하는 execution-state capsule을 제안한다. 런타임 FlashRT는 블록 테이블 없이 연속 정적 버퍼 위에서 캡처된 그래프를 돌리므로, KV·순환 상태·합성곱 상태를 통째로 스냅샷·포크·롤백할 수 있다.
Results결과By treating the entire boundary as a closed set of static buffers, branch/reset/re-enter patterns become cheap state operations rather than recomputation, fitting the responsiveness budgets of physical-AI workloads. The capsule abstraction generalizes prefix reuse from "just the KV cache" to the full restorable execution state.분기·리셋·재진입이 재계산 대신 값싼 상태 연산이 되어 물리 AI 워크로드의 응답 예산에 맞는다. 접두사 재사용의 범위가 KV 캐시에서 실행 상태 전체로 넓어진다.
Summary요약Checkpoint the whole on-device execution boundary as a capsule, so branching and re-entry cost a restore instead of a recompute.실행 경계 전체를 캡슐로 저장하면 분기와 재진입이 재계산 대신 복원으로 끝난다.
