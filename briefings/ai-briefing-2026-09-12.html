Problem문제 정의 Prefix caching cuts time-to-first-token by reusing previously computed KV states, but the reuse is not free: the cache has to be loaded from wherever it was stored. For short prefixes, or on a fast enough GPU, simply recomputing the prefix beats loading it. Problem문제 정의 Soft context compression condenses a context into a handful of memory tokens that a frozen LLM reads in place of the raw text. Problem문제 정의 A single agent task can spawn many concurrent sandbox sessions, and at that fan-out memory becomes the bottleneck.
