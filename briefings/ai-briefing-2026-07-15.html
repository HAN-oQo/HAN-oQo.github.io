Underneath, main stayed busy (~70 commits across the window): a TPOT optimization for thinking-budget speculative decoding (#46662), split write/read KV-offload usage gauges (#47666), an MLA+SWA fix to check the layer backend rather than model config (#48520), and a DSv3.2 + MTP + sequence-parallel accuracy fix (#48036).

Method방법HCRMap is a residency-mapping framework that treats the goal not as "move fewer tokens" but as dynamically placing and reusing hot-expert replicas across memory tiers.
