Problem문제 정의The computation integrity of remote LLM serving is hard to trust. The TEE-shielded partitioning (TSDP) approach uses a trusted enclave to compute non-linear parts and verify linear parts offloaded to an untrusted GPU — but applied directly to Transformers it incurs heavy TEE computation and TEE↔GPU communication.원격 LLM 서빙의 계산 무결성은 신뢰하기 어렵다. Method방법VeriAttn offloads both the linear and non-linear parts of attention to the GPU while the TEE only verifies. Problem문제 정의Modern CPUs integrate matrix extensions like Arm SME for high-throughput matrix math, but they are not a universal replacement for CPU cores: prefill, decode, attention, and KV-cache ops have different arithmetic intensities, vector behavior, and layout needs, while SME units and cores compete for shared memory bandwidth.현대 CPU는 고처리량 행렬 연산을 위해 Arm SME 같은 행렬확장을 통합하지만, CPU 코어의 만능 대체재는 아니다 — prefill·decode·어텐션·KV 캐시 연산은 산술강도·벡터 거동·레이아웃 요구가 다르고, SME 유닛과 코어는 공유 메모리 대역폭을 두고 경쟁한다.
