UBTree: Parallel Tree Drafting via Unigram and Bigram Models for Speculative Decodingspeculative decodingparallel draftingarXiv:2609.39972
arxiv.org/abs/2609.39972 →

Problem문제 정의Parallel drafters verify many draft tokens in one target pass, but their gains fade as the entropy of the target distribution rises because the drafts lack diversity.병렬 드래프터는 한 번의 타깃 패스로 여러 드래프트 토큰을 검증하지만, 타깃 분포의 엔트로피가 높아지면 드래프트의 다양성이 부족해 효과가 떨어진다.

Method방법UBTree couples a Unigram proposer, trained with cross-entropy to propose candidates per position, with a lightweight Bigram selector that scores transitions between adjacent candidates. The selector is trained with a renormalized KL objective on high-temperature data, so the drafting tree covers plausible alternative branches.교차 엔트로피로 학습한 Unigram 제안기가 위치별 후보를 내고, 가벼운 Bigram 선택기가 인접 후보 쌍의 전이 점수를 매긴다. 선택기를 고온 데이터와 재정규화 KL로 학습해 트리가 대안 가지까지 담게 한다.

Results결과On seven benchmarks with Qwen3-4B and Qwen3-8B, UBTree averages a 5.84-6.94x speedup over autoregressive decoding and beats DARTree in all 28 comparisons. Production-scale evaluation also shows an advantage over frontier baselines such as DSpark.Qwen3-4B/8B, 7개 벤치마크에서 자기회귀 대비 평균 5.84~6.94배 빠르고 28개 비교 모두 DARTree를 앞섰다. 프로덕션 규모에서도 DSpark 등을 앞섰다.

Summary요약Training the selector on branches beyond the greedy path keeps a parallel drafter useful when the target is uncertain.탐욕 경로 바깥의 가지까지 선택기를 학습시키면 타깃이 불확실할 때도 병렬 드래프터가 쓸모를 유지한다.

Capture the lifecycle: KV Cache management in ReAct Agents with KVTetherKV cacheagent servingarXiv:2609.39819
arxiv.org/abs/2609.39819 →

Problem문제 정의ReAct agent harnesses mutate context, run tools and coordinate subagents, yet the serving stack only sees KV accesses. This lifecycle blindness stops recency-only policies like LRU from reclaiming dead KV promptly or keeping older KV that will be reused soon.서빙 스택은 ReAct 하네스의 컨텍스트 변경·도구 실행·서브에이전트 조율을 모르고 KV 접근만 본다. 그래서 LRU 같은 정책은 죽은 KV를 늦게 회수하고 곧 재사용될 오래된 KV를 버린다.

Method방법KVTether traces semantic primitives embedded in agent harnesses and translates message-level semantics into KV-level lifecycle states. These states drive state-prioritized cache management: dead KV is reclaimed first, and live-but-idle KV waiting for reuse is preferentially preserved.하네스에 심은 기본 요소로 메시지 수준 의미를 KV 수명 주기 상태로 바꾸고, 이를 우선순위로 써서 죽은 KV는 먼저 회수하고 재사용될 유휴 KV는 보존한다.

Results결과Across agent benchmarks and production workloads, KVTether cuts end-to-end request latency by up to 26.3% versus LMCache and 17.4% versus MORI. Estimated task cost drops by 40.0% and 33.2% on average, respectively.에이전트 벤치마크와 프로덕션 워크로드에서 종단 간 요청 지연을 LMCache 대비 최대 26.3%, MORI 대비 17.4% 줄였다. 추정 작업 비용은 각각 평균 40.0%, 33.2% 낮아졌다.

Summary요약Letting the cache know which messages are live, idle or dead beats evicting by recency alone for long-running agents.캐시가 어떤 메시지가 살아 있고 유휴이며 죽었는지 알면, 장시간 에이전트에서 최근성만으로 쫓아내는 것보다 낫다.

arxiv.org/abs/2609.39334 →

Problem문제 정의Speculative execution can speed up the exploration of reasoning paths in test-time scaling, but it creates two problems for serving systems. The search space of candidate paths explodes, and fine-grained verification tasks arrive frequently.테스트 타임 스케일링의 추측 실행은 탐색을 빠르게 하지만, 후보 경로가 폭발하고 세밀한 검증 작업이 잦아 서빙을 어렵게 한다.

Method방법SpecScale is a serving system that balances latency against compute overhead with three techniques: early pruning of low-quality candidate paths, deduplicating computation across redundant paths, and deferring fine-grained verification tasks.저품질 경로 조기 가지치기, 중복 경로 연산 제거, 세밀한 검증 지연이라는 세 기법으로 지연과 연산을 맞춘다.

Results결과On reasoning benchmarks including MATH and Olympiad, SpecScale outperforms both non-speculative and recent speculative approaches. The abstract reports substantial throughput and latency gains with answer quality preserved.MATH, Olympiad 등에서 비추측·추측 방식을 모두 앞서며, 품질을 유지한 채 처리량과 지연이 크게 좋아졌다고 초록은 밝힌다.

PatchKV: Weight-Space Compensation of KV CacheKV compressionweight patcharXiv:2609.39329
arxiv.org/abs/2609.39329 →

Problem문제 정의Long-context inference is bottlenecked by the linearly growing KV cache. Compression by token eviction or approximation degrades sharply at aggressive budgets.장문 컨텍스트 추론은 선형으로 커지는 KV 캐시가 병목이다. 토큰 퇴출이나 근사로 압축하면 공격적인 예산에서 성능이 급격히 떨어진다.

Method방법PatchKV is training-free: it pairs an off-the-shelf compressed KV cache with a context-specific weight patch, computed once at context-loading time by closed-form ridge regression. The patch aligns block-wise activations of reference query tokens under the full and compressed caches, then is merged into the model.학습 없이 압축 KV 캐시에 컨텍스트별 가중치 패치를 붙인다. 패치는 로드 시 한 번 릿지 회귀(닫힌 형태)로 구하며, 전체·압축 캐시의 블록별 활성화를 맞춘 뒤 모델에 병합한다.

Results결과Once merged, the patch leaves the forward graph, so per-query inference cost is unchanged in the single-context, multi-query setting. On SCBench (up to 170K tokens), SQuAD, NIAH and GSM8K across three architectures, it consistently improves cache compression methods.병합 후엔 순전파에 흔적이 없어 쿼리당 비용이 그대로다. SCBench(최대 17만 토큰), SQuAD, NIAH, GSM8K, 세 아키텍처에서 압축 방법들을 꾸준히 개선했다.

Summary요약Carrying part of the context in the weights offers a way to recover quality that a heavily compressed KV cache loses.컨텍스트 일부를 가중치에 담으면 강하게 압축한 KV 캐시가 잃는 품질을 되찾을 수 있다.

arxiv.org/abs/2609.39068 →

Problem문제 정의Long-context agents accumulate histories that strain KV-cache memory and attention compute. Sparse attention helps, but heterogeneous cache representations make it hard to integrate with existing engines, and prior sparse-serving abstractions support only specific layouts or workflows.장문 에이전트 이력은 KV 메모리와 어텐션 연산을 압박한다. 희소 어텐션은 캐시 표현이 제각각이라 엔진에 넣기 어렵고 기존 추상화는 특정 레이아웃만 지원한다.

Method방법SparseEngine is a ground-up sparse-first engine with a shared lifecycle contract: each method controls its own KV representation and computation while coordinating state transitions with common serving infrastructure. It supports 15 methods in four categories, adds Chain Cache to resume KV-eviction methods from retained history, and offers controllable Prefix-Cache Pruning.공유 수명 주기 계약을 둔 희소 우선 엔진이다. 각 방법이 KV 표현과 연산을 직접 다루고 서빙 인프라와 상태 전이는 공통으로 쓴다. 네 범주 15개 방법을 지원하며, 퇴출 방식이 보존된 이력에서 재개하는 Chain Cache와 프리픽스 캐시 가지치기를 제공한다.

Results결과While maintaining method quality, it delivers over 10x higher throughput with KV eviction, over 2.5x faster decoding than vLLM at matched concurrency, and over 2x end-to-end speedup on agent benchmarks.방법별 품질을 유지하면서 KV 퇴출에서 처리량이 10배 넘게 높고, 같은 동시성에서 vLLM보다 디코딩이 2.5배 넘게 빠르며, 에이전트 벤치마크에서 종단 간 2배 넘게 빨라졌다.

Summary요약A common lifecycle contract lets many sparse-attention methods share one engine and its cross-request caching.공통 수명 주기 계약 덕분에 여러 희소 어텐션 방법이 하나의 엔진과 요청 간 캐싱을 공유할 수 있다.

Vosti: Specifying, Implementing, and Verifying Deterministic LLM Inferencedeterminismformal verificationarXiv:2609.38981
arxiv.org/abs/2609.38981 →

Problem문제 정의Batch composition, prompt chunking, prefill/decode execution and KV-cache reuse should not change outputs, yet vLLM's batch-invariant mode and SGLang's deterministic mode lack a formal system-level specification. Problem문제 정의Training LLM agents with RL is bottlenecked by environments that must give verifiable rewards, support long-horizon interaction and scale cheaply. Human-curated data is costly, and LLM-generated environments risk hallucination and benchmark contamination.에이전트 RL은 검증 가능하고 길고 싸게 늘릴 수 있는 환경이 병목이다. 사람 데이터는 비싸고 LLM 생성 환경은 환각과 오염 위험이 있다.

Method방법PhantomEnvironments builds multi-turn RL environments from fictional worlds generated entirely by rules, with no LLM and zero marginal cost. Agents search a corpus of templated articles to answer multi-hop questions about facts that share nothing with the real world.LLM 없이 규칙만으로 공짜로 만든 허구 세계를 멀티턴 RL 환경으로 쓴다. 에이전트는 현실과 사실을 공유하지 않는 기사 코퍼스를 검색해 멀티홉 질문에 답한다.

Results결과The trained agents transfer to real-world multi-hop search benchmarks, often outperforming real-world training data on newer benchmarks, and generalize to unseen fictional universes.
