LightRot: A Light-Weighted Rotation Scheme and Architecture for Accurate Low-Bit LLM Inferencelow-bit quantHW accelerator2607.27704
LightRot (arXiv 2607.27704) ↗LightRot (arXiv 2607.27704) ↗
Problem문제 정의Rotating activations before quantization smooths away the outliers that wreck low-bit accuracy, but the rotation itself costs energy and hardware. As LLM inference pushes to 4-bit, the challenge is keeping the accuracy benefit of rotation without paying its full compute and power overhead.양자화 전에 활성을 회전시키면 이상치가 줄어 저비트 정확도가 좋아지지만, 회전 자체가 에너지와 하드웨어를 쓴다. 4비트 추론에서 이 오버헤드를 줄이는 것이 과제다.
Method방법LightRot pairs a lightweight rotation algorithm with a dedicated accelerator. Grouped Local Rotation (GLR) rotates within small groups instead of globally, Outlier Direction Aligning (ODA) steers rotations toward the directions that most need smoothing, and a hierarchical Fast Hadamard Transform (FHT) unit implements the rotation cheaply in hardware.LightRot은 작은 그룹 안에서만 회전하는 GLR, 이상치 방향에 회전을 맞추는 ODA, 회전을 하드웨어로 싸게 처리하는 계층적 FHT 유닛을 묶었다.
Results결과Implemented in a 28nm CMOS process, the accelerator reaches a peak energy efficiency of 27.4 TOPS/W for 4-bit inference while preserving accuracy, showing that carefully localized rotation plus a matched transform unit makes low-bit rotation affordable.28nm CMOS 가속기가 4비트 추론 정확도를 유지하면서 최대 27.4 TOPS/W 에너지 효율을 냈다.
Summary요약Rotate in small aligned groups with a hardware Hadamard unit instead of globally, so 4-bit LLM inference keeps accuracy at 27.4 TOPS/W.작은 그룹 회전과 하드웨어 Hadamard 유닛으로 4비트 LLM 추론을 27.4 TOPS/W에서 돌린다.

Problem문제 정의Feed-forward networks dominate the memory traffic and compute of LLM inference, which makes them the prime target for activation sparsification — skipping intermediate channels that contribute little. But existing training-free methods lose substantial model quality once the sparsity is pushed high, because they mis-judge which channels are actually salient.FFN은 추론 메모리 트래픽과 연산의 대부분을 차지해 활성 희소화의 1순위 대상이다. 그런데 기존 학습 없는 방법은 희소성을 높이면 중요한 채널을 잘못 골라 품질이 크게 떨어진다.
Method방법Prox is a training-free scheme that estimates the salience of each FFN intermediate channel with a cheap approximation, then keeps only the channels whose approximate salience is high. Because the estimate is computed on the fly rather than learned, it drops into an existing model without any fine-tuning, and the sparsity budget can be set per layer.Prox는 FFN 중간 채널의 중요도를 싼 근사로 추정하고 높은 채널만 남긴다. 학습이 필요 없어 기존 모델에 바로 얹을 수 있고, 희소성 예산을 레이어별로 정할 수 있다.
Results결과By ranking intermediate channels with approximate salience, Prox sustains model quality at higher activation sparsity than prior training-free baselines, turning the FFN memory-and-compute bottleneck into skipped work without any retraining.기존 학습 없는 기준보다 높은 희소성에서도 품질을 유지한다.
Summary요약Score FFN channels with a fast salience approximation and skip the low ones — no training — to hold quality at high activation sparsity.FFN 채널을 빠른 중요도 근사로 채점해 낮은 채널을 건너뛰고, 학습 없이 높은 희소성에서 품질을 지킨다.

SparseSpec-L (arXiv 2607.27735) ↗SparseSpec-L (arXiv 2607.27735) ↗
Problem문제 정의Speculative decoding hides the memory-bandwidth cost of LLM inference by drafting several tokens cheaply and verifying them in one pass, but its speedup is jointly limited by drafting overhead, token acceptance, and how far ahead you speculate. Pushing the speculation horizon too far can actually slow things down.투기 디코딩의 속도향상은 초안 비용, 수용률, 투기 지평에 함께 달려 있다. 지평을 너무 길게 잡으면 오히려 느려진다.
Method방법The paper gives a unified efficiency analysis showing that extending the speculation horizon reduces speedup once the marginal acceptance probability falls below the relative drafting cost. Guided by that, SparseSpec-L is a training-free self-speculative decoder for long context: it drafts lightweight tokens directly from the target model using a dynamically chosen sparse subset of the model, so no separate draft model is needed.한계 수용 확률이 상대 초안 비용보다 낮아지면 지평을 늘릴수록 손해라는 분석을 제시한다. 이를 바탕으로 만든 SparseSpec-L은 타깃 모델의 동적 희소 부분집합으로 초안을 만드는 학습 없는 자기 투기 디코더라서 별도 드래프트 모델이 필요 없다.
Results결과By choosing the speculation length from the acceptance-vs-cost analysis and drafting from a sparse slice of the model itself, SparseSpec-L accelerates long-context decoding without training a draft model or storing extra weights.드래프트 모델 학습이나 추가 가중치 없이 롱컨텍스트 디코딩을 가속한다.
Summary요약Draft from a dynamic sparse subset of the target model itself, and pick the speculation length from an acceptance-vs-cost rule, to speed up long-context decoding train-free.타깃 모델의 희소 부분집합으로 초안하고 수용률-비용 규칙으로 투기 길이를 정해, 학습 없이 롱컨텍스트 디코딩을 가속한다.

Functional Reconstruction for MLA (arXiv 2607.27269) ↗MLA 기능적 재구성 (arXiv 2607.27269) ↗
Problem문제 정의Multi-head latent attention (MLA) is increasingly important for long-context LLMs because it replaces a growing key-value cache with compact latent states. But that same compression makes it awkward to build a fast draft model for speculative decoding: naively reconstructing full KV from the latent states is expensive and discards the compression benefit.MLA는 KV 캐시를 압축 잠재 상태로 바꿔 롱컨텍스트에서 중요해졌다. 하지만 압축 때문에 투기 디코딩용 드래프트 모델을 만들기 어렵고, 잠재 상태에서 전체 KV를 복원하면 비싸고 압축 이점도 사라진다.
Method방법Instead of reconstructing the raw KV tensors, the method reconstructs the function the draft model needs — the attention behavior — directly from MLA's latent states, so the draft stays cheap and compatible with the compressed cache. The draft therefore operates in the same latent space as the target rather than re-expanding it.KV 텐서 대신 드래프트에 필요한 어텐션 동작 자체를 MLA 잠재 상태에서 직접 재구성한다. 그래서 초안이 캐시를 펼치지 않고 타깃과 같은 잠재 공간에서 돈다.
Results결과By matching the draft to the target's function in latent space rather than in reconstructed KV, the approach makes speculative decoding practical for MLA-based long-context models without paying the full-KV reconstruction cost.전체 KV 재구성 비용 없이 MLA 기반 롱컨텍스트 모델에서 투기 디코딩을 쓸 수 있게 된다.
Summary요약Reconstruct the draft's attention function directly from MLA latent states — not the raw KV — so speculative decoding works on compressed long-context caches.MLA 잠재 상태에서 드래프트의 어텐션 함수를 바로 재구성해, 압축 캐시에서도 투기 디코딩이 돌게 한다.

InferScale: GPU-Native KV Injection for Personalized LLM Servingpersonalized servingKV reuse2607.27090
InferScale (arXiv 2607.27090) ↗InferScale (arXiv 2607.27090) ↗
Problem문제 정의LLMs are increasingly served with persistent personalized context — accumulated memory profiles or long histories shared across a user's many requests. Production memory systems like Mem0, MemGPT, and Zep retrieve a relevant subset of that memory and inject it into the prompt, forcing the engine to prefill the same content again and again; as the retrieval budget grows, time-to-first-token climbs even though the memory is reused.개인화 메모리를 붙여 LLM을 서빙하는 경우가 늘고 있다. Mem0·MemGPT·Zep 같은 시스템은 관련 메모리를 검색해 프롬프트에 넣는데, 그러면 같은 내용을 매번 다시 프리필하게 돼 검색 예산이 클수록 TTFT가 늘어난다.
Method방법InferScale is a GPU-native memory system that replaces repeated prompt prefilling with reusable KV state. It precomputes each memory fact's KV representation once, stores it alongside a semantic embedding on the GPU, retrieves the relevant facts by embedding similarity, and injects their precomputed KV directly into the running request instead of re-encoding the text.InferScale은 메모리 사실마다 KV를 한 번 미리 계산해 의미 임베딩과 함께 GPU에 둔다. 임베딩 유사도로 관련 사실을 찾고, 텍스트를 다시 인코딩하지 않고 저장된 KV를 실행 중인 요청에 바로 주입한다.
Results결과By turning memory retrieval into KV injection rather than re-prefill, InferScale keeps time-to-first-token from growing with the retrieval budget, so personalized serving with large memory contexts stays fast.검색 예산이 커져도 TTFT가 늘지 않아, 큰 메모리 컨텍스트의 개인화 서빙이 빨라진다.
Summary요약Precompute and store each memory fact's KV on the GPU, then inject the retrieved KV directly instead of re-prefilling the text — cutting TTFT for memory-augmented personalized serving.메모리 사실의 KV를 GPU에 미리 저장해 두고 재프리필 대신 주입해서 개인화 서빙의 TTFT를 줄인다.
