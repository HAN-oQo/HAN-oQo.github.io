C²KV: Compressed and Composable KV Cache Reuse for Efficient LLM InferenceKV cachelong context2607.17715
C²KV (arXiv 2607.17715, submitted Jul 20) ↗C²KV (arXiv 2607.17715, 7/20 제출) ↗
Problem문제 정의Long-context inference (RAG, multi-document reasoning) drives up cost, so recent work reuses KV caches to skip redundant prefill. But existing reuse methods focus on compute savings and ignore a second bottleneck: the cost of storing and moving huge KV caches. Compression looks like a natural fix, yet naively combining it with non-prefix KV reuse causes severe accuracy loss.장문 추론은 KV 캐시 재사용으로 중복 프리필을 건너뛰지만, 기존 방법은 KV 캐시의 저장·전송 비용을 무시한다. 압축을 비-프리픽스 재사용과 그냥 합치면 정확도가 크게 떨어진다.
Method방법C²KV is a unified framework for non-prefix reuse that jointly optimizes KV extraction and inference-time concatenation. It learns a composable, compressed, explicitly position-agnostic KV manifold via a lightweight sidecar Extractor with learnable compression tokens and a structured attention flow, so modular KV pieces can be reused and concatenated without touching the frozen base model. A compression–concatenation co-training strategy aligns extraction-time representations with how they will be reused downstream.경량 사이드카 Extractor가 학습 가능한 압축 토큰으로 위치 무관하고 조합 가능한 압축 KV를 만든다. 베이스 모델은 동결한 채, 압축–연결 공동학습으로 추출 표현을 재사용 방식에 맞춘다.
Results결과Across multiple long-context benchmarks and model families, C²KV significantly reduces KV-cache storage and transfer costs, reporting up to 17× inference speedup under long contexts while preserving generation quality (accepted at ACM SIGKDD 2026).여러 장문 벤치마크와 모델 계열에서 KV 저장·전송 비용을 크게 줄이고, 품질을 유지하면서 최대 17배 가속을 보고한다(ACM SIGKDD 2026 채택).
Summary요약Learn a position-agnostic compressed KV manifold so cached chunks can be reused and concatenated cheaply, cutting both compute and KV storage/transfer.위치 무관 압축 KV를 학습해 캐시 조각을 싸게 이어 붙이고, 연산과 저장·전송을 함께 줄인다.

VisMMOE: Exploiting Visual-Expert Affinity for Efficient Visual-Language MoE OffloadingMoE servingoffloading2607.05899
VisMMOE (arXiv 2607.05899) ↗VisMMOE (arXiv 2607.05899) ↗
Problem문제 정의Visual-language mixture-of-experts (MoE) models are large, so serving them on limited GPU memory forces inactive experts to be offloaded to CPU memory and streamed back on demand. Naive offloading stalls inference because the needed experts are fetched only after routing decides them, adding latency on the critical path.시각-언어 MoE를 작은 GPU 메모리에서 돌리려면 전문가를 CPU로 오프로딩해야 한다. 라우팅이 정해진 뒤에야 전문가를 가져오면 임계 경로에 지연이 생긴다.
Method방법VisMMOE exploits visual-expert affinity: visual tokens tend to route to a predictable subset of experts. By profiling which experts visual inputs prefer, it prefetches and caches those experts ahead of time and lays out CPU–GPU transfers around this affinity, so the right experts are resident when routing needs them.시각 토큰은 예측 가능한 전문가 부분집합으로 라우팅된다. 이 친화도를 프로파일링해 해당 전문가를 미리 프리페치·캐시하고 CPU–GPU 전송을 그에 맞춰 배치한다.
Results결과The paper reports lower inference latency and better memory efficiency for visual-language MoE serving under offloading, by reducing on-the-critical-path expert fetches relative to affinity-agnostic offloading baselines.친화도를 무시하는 오프로딩 대비 임계 경로 페치를 줄여 지연과 메모리 효율이 개선됐다고 보고한다.
Summary요약Use the predictable expert preferences of visual tokens to prefetch experts, hiding CPU→GPU transfer latency in VLM MoE offloading.시각 토큰의 전문가 선호로 프리페치해 VLM MoE 오프로딩의 CPU→GPU 전송 지연을 숨긴다.

TACG: Trajectory-Aware Commit Gating for Diffusion Language Model Decodingdiffusion LMparallel decoding2607.03236
TACG (arXiv 2607.03236) ↗TACG (arXiv 2607.03236) ↗
Problem문제 정의Diffusion language models decode many tokens in parallel per step, which is fast, but committing (finalizing) tokens too aggressively locks in mistakes and hurts quality, while committing too conservatively wastes the parallelism. Deciding which tokens are safe to commit each step is the crux.확산 언어모델은 스텝마다 여러 토큰을 병렬로 디코딩한다. 너무 빨리 커밋(확정)하면 실수가 굳고, 너무 늦게 하면 병렬성을 버린다.
Method방법TACG gates commits using the decoding trajectory: rather than thresholding a single-step confidence, it looks at how a token's prediction evolves across denoising steps and commits only tokens whose trajectory has stabilized. This trajectory-aware signal lets it finalize confident tokens early while holding volatile ones for more refinement.단일 스텝 신뢰도 대신 디노이징 스텝에 걸친 예측 궤적을 보고, 궤적이 안정된 토큰만 커밋한다. 변동이 큰 토큰은 더 정제하도록 남긴다.
Results결과The paper reports a better speed–quality trade-off for diffusion-LM decoding than confidence-threshold commit rules, keeping more of the parallel-decoding speedup without the accuracy drop from premature commits.신뢰도 임계 규칙보다 속도–품질 균형이 낫고, 조기 커밋에 따른 정확도 하락 없이 병렬 가속을 더 유지한다고 보고한다.
Summary요약Commit diffusion-LM tokens by watching whether their prediction has stabilized across steps, not a single-step confidence score.예측이 여러 스텝에 걸쳐 안정됐는지를 보고 확산 LM 토큰을 커밋한다.

WiSP: A Working-Set View of Mixture-of-Experts Serving on Extremely Low-Resource HardwareMoE servingmemory2606.21868
WiSP (arXiv 2606.21868) ↗WiSP (arXiv 2606.21868) ↗
Problem문제 정의Running large mixture-of-experts models on extremely low-resource hardware (little GPU/host memory) is hard because the full expert set can't stay resident, and repeatedly loading experts thrashes memory and stalls decoding.메모리가 적은 하드웨어에선 MoE 전문가 전체를 올려 둘 수 없고, 반복 로드하면 스래싱으로 디코딩이 멈춘다.

SpectrumKV: Per-Token Mixed-Precision KV Cache Transfer for Prefill–Decode Disaggregated LLM ServingKV transferPD disaggregation2606.08635
SpectrumKV (arXiv 2606.08635) ↗SpectrumKV (arXiv 2606.08635) ↗
Problem문제 정의In prefill–decode disaggregated serving, the KV cache produced during prefill must be shipped to the decode node before decoding can proceed. For long contexts the transfer's bandwidth and latency become first-order costs, and sending every token at full precision wastes bandwidth on tokens that matter little.PD 분리 서빙에선 프리필의 KV 캐시를 디코드 노드로 보내야 디코딩이 시작된다. 장문에선 이 전송이 주된 비용이고, 모든 토큰을 풀 정밀도로 보내면 대역폭이 낭비된다.
Method방법SpectrumKV transfers the KV cache at per-token mixed precision: it estimates each token's importance and sends important tokens' KV at higher precision while quantizing the rest more aggressively. The precision "spectrum" is allocated per token so total transferred bytes drop with minimal effect on decode quality.토큰별 중요도를 추정해 중요한 토큰의 KV는 높은 정밀도로, 나머지는 더 강하게 양자화해 보낸다.
Results결과The paper reports substantially reduced KV-transfer volume and latency for disaggregated long-context serving versus uniform-precision transfer, while preserving generation accuracy.균일 정밀도 전송보다 KV 전송량과 지연을 크게 줄이면서 정확도를 유지한다고 보고한다.
Summary요약Spend transfer bits where they matter: send important tokens' KV at high precision and squeeze the rest, cutting the PD-disaggregation KV-transfer bottleneck.전송 비트를 중요한 토큰에 몰아 PD 분리의 KV 전송 병목을 줄인다.

Method방법SplitZip is an ultra-fast lossless KV compressor tailored to KV-tensor statistics: it splits the KV representation into components that compress well and applies a lightweight codec fast enough to run inline during transfer, so the cache is shrunk without any loss before it crosses the network.KV 텐서 통계에 맞춘 초고속 무손실 압축기다. Summary요약A KV-tailored lossless codec fast enough to run inline on the transfer path — shrink the cache with zero accuracy cost.전송 경로에서 인라인으로 도는 KV 전용 무손실 코덱으로, 정확도 손실 0으로 캐시를 줄인다.
