Problem문제 정의Distributed MoE inference runs two all-to-all communications per layer: one to dispatch tokens to expert ranks and one to return expert outputs. Conventional implementations launch the return all-to-all only after expert compute finishes, so communication sits on the critical path and GPUs idle while data moves.분산 MoE 추론은 층마다 두 번의 all-to-all 통신을 돌린다 — 토큰을 전문가 랭크로 분배하는 것과 전문가 출력을 되돌리는 것. 통상 구현은 전문가 연산이 끝난 뒤에야 반환 all-to-all을 시작하므로, 통신이 임계 경로에 놓이고 데이터가 오가는 동안 GPU가 놀게 된다.
Method방법The authors overlap expert compute with the second all-to-all through tile-level signaling and scheduling. A producer–consumer co-design pairs a persistent per-rank computation kernel with a communication kernel so that finished output tiles are signaled and returned immediately, rather than waiting for the whole expert computation to complete.저자들은 타일 수준 시그널링·스케줄링으로 전문가 연산과 두 번째 all-to-all을 겹친다. 지속형 랭크별 연산 커널과 통신 커널을 짝지은 생산자–소비자 공동 설계로, 완료된 출력 타일을 전체 전문가 연산이 끝나길 기다리지 않고 즉시 신호·반환한다.
Results결과By hiding the return communication behind ongoing compute, the approach removes the exposed all-to-all latency from the critical path and raises GPU utilization for trillion-parameter-scale MoE serving, without changing model outputs.반환 통신을 진행 중인 연산 뒤로 숨김으로써, 이 방법은 노출된 all-to-all 지연을 임계 경로에서 제거하고 조 단위 파라미터 MoE 서빙의 GPU 활용률을 높이며, 모델 출력은 바꾸지 않는다.

Problem문제 정의Speculative decoding accelerates LLM inference by having a lightweight draft model propose tokens that the target verifies in parallel. Diffusion drafters (as in DFlash) can generate a whole draft in a single parallel denoising pass, but a fixed off-policy drafter drifts from the target's distribution, so acceptance rates and the useful draft length vary and are left on the table.투기 디코딩은 경량 초안 모델이 토큰을 제안하고 타깃이 병렬 검증하게 해 LLM 추론을 가속한다. Method방법AdaFlash distills the diffusion drafter on-policy — training it against samples from its own drafting distribution as paired with the target — so the drafter tracks the target more faithfully, and it adapts how many tokens to draft per step to the difficulty of the current context rather than using a fixed speculation length.AdaFlash는 디퓨전 드래프터를 온폴리시로 증류한다 — 타깃과 짝지은 자기 초안 분포의 샘플로 학습해 드래프터가 타깃을 더 충실히 따르게 하고, 고정 투기 길이 대신 현재 맥락의 난이도에 맞춰 스텝당 초안 토큰 수를 적응적으로 정한다.
Results결과Better drafter–target alignment plus adaptive draft length raises the accepted-token yield per verification step over prior diffusion-drafter speculative decoding, while remaining lossless with respect to the target model's outputs.더 나은 드래프터–타깃 정렬과 적응형 초안 길이는 이전 디퓨전 드래프터 투기 디코딩 대비 검증 스텝당 채택 토큰 수율을 높이며, 타깃 모델 출력에 대해 무손실을 유지한다.
Summary요약On-policy distillation and adaptive draft length make diffusion-drafter speculative decoding accept more tokens per step, losslessly.온폴리시 증류와 적응형 초안 길이로 디퓨전 드래프터 투기 디코딩이 스텝당 더 많은 토큰을 무손실로 채택하게 한다.

Problem문제 정의Long-context, multi-turn, and agentic workloads keep reusing previously processed context, so KV-cache reuse is essential to avoid recomputation. But that reuse shifts the bottleneck to the memory tier that must store and serve reusable KV state at cluster scale — and GPU HBM and host DRAM are far too expensive to scale to terabyte-sized shared contexts.롱컨텍스트·멀티턴·에이전트 워크로드는 이미 처리한 맥락을 계속 재사용하므로, 재계산을 피하려면 KV 캐시 재사용이 필수다. 그러나 그 재사용은 병목을 클러스터 규모에서 재사용 가능한 KV 상태를 저장·제공해야 하는 메모리 계층으로 옮긴다 — GPU HBM과 호스트 DRAM은 테라바이트급 공유 맥락으로 확장하기엔 너무 비싸다.
