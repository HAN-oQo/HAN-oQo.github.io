GSRQ (arXiv 2607.01065, submitted Jul 1) ↗GSRQ (arXiv 2607.01065, 7/1 제출) ↗
Problem문제 정의Long-context deployment is capped by KV cache memory that grows linearly with tokens. Residual vector quantization can push storage toward sub-1-bit by encoding residuals with small codebooks, but it leans on standard L2 K-means — and in high dimensions L2 centroid averaging causes "centroid shrinkage" that weakens the angular (directional) term, so the codebook preserves direction poorly.KV 캐시가 롱컨텍스트의 상한이다. 잔차 벡터 양자화로 서브-1-bit까지 갈 수 있지만, 고차원에서 L2 K-means는 "중심 수축"으로 방향 정보를 잃는다.
Method방법GSRQ replaces plain K-means with Gain-Shape K-means (GSKM), which separates a vector's magnitude (gain) from its direction (shape) so directional fidelity is preserved while matching or improving L2 distortion. Stacking these into a weighted residual-quantization scheme yields the sub-1-bit KV codebooks.K-means를 게인-셰이프 K-means(GSKM)로 바꿔 크기(gain)와 방향(shape)을 분리하고, 이를 가중 잔차 양자화로 쌓는다.
Results결과Fixing the directional weakness of L2 K-means lets residual quantization reach the sub-1-bit regime for the KV cache with better fidelity than the standard primitive, shrinking long-context memory further without the accuracy collapse shrinkage caused.방향 손실을 막아 표준 방식보다 높은 충실도로 서브-1-bit KV 캐시에 도달한다.
Summary요약Split gain from shape before you quantize residuals — L2 K-means shrinks centroids and loses direction; GSKM keeps it, unlocking sub-1-bit KV.gain과 shape를 분리하면 방향이 보존되어 서브-1-bit KV가 가능해진다.

Problem문제 정의Mixed-precision quantization assigns more bits to the "important" layers, but importance is usually ranked by perplexity sensitivity. Method방법TASA is a two-level framework that jointly optimizes calibration-data composition and mixed-precision bit allocation. Problem문제 정의With prompts of hundreds of thousands to millions of tokens, the KV cache is a first-order serving cost: it grows linearly with context, exhausts GPU memory, forces smaller batches, and cuts throughput. Method방법MosaicKV does dynamic two-dimensional compression — over both the sequence (which tokens) and channel (which feature dimensions) axes — exploiting the non-uniform importance of elements within the cache, so it compresses aggressively where elements matter least and preserves the important ones.요소별 중요도가 고르지 않다는 점을 이용해 시퀀스(토큰)와 채널(특징 차원) 두 축을 동적으로 압축한다.
