Problem문제 정의Quantization shrinks memory and speeds up inference so models fit consumer GPUs and edge devices. But most prior work uses uniform (evenly-spaced) quantization codebooks, which waste precision on the rare high-magnitude weights that dominate error, giving suboptimal low-bit representations.양자화는 메모리를 줄이고 추론을 빠르게 해 모델이 소비자 GPU·엣지 기기에 맞게 한다. 그러나 대부분의 기존 연구는 균일(등간격) 양자화 코드북을 쓰는데, 이는 오차를 지배하는 드문 고크기 가중치에 정밀도를 낭비해 저비트 표현이 최적이 아니다.
Method방법Log_bQuant places quantization levels logarithmically with an adjustable base b, so the codebook is dense where common low-magnitude weights sit and sparse out at the rare large ones — matching the shape of typical parameter distributions instead of spacing levels evenly.Log_bQuant는 조절 가능한 밑 b로 양자화 레벨을 로그 간격으로 배치해, 흔한 저크기 가중치가 있는 곳은 촘촘하고 드문 대크기 값 쪽은 성기게 만든다 — 레벨을 균일하게 두는 대신 전형적 파라미터 분포의 형태에 맞춘다.
Results결과At 4-bit tensor-wise granularity the method beats asymmetric linear quantization on several benchmarks, while delivering moderate speedup and high memory savings — suitable for private use on consumer-grade GPUs.4-bit 텐서 단위 granularity에서 여러 벤치마크에 걸쳐 비대칭 선형 양자화를 능가하며, 적당한 속도 향상과 큰 메모리 절감을 제공한다 — 소비자급 GPU에서의 개인 사용에 적합하다.
Summary요약Space the quantization levels logarithmically, not uniformly, so precision lands where the weights actually are.양자화 레벨을 균일이 아니라 로그로 배치해, 정밀도가 실제 가중치가 있는 곳에 가도록 하라.

GSRQ — Gain-Shape Residual Quantization for Sub-1-bit KV CacheKV cachequantization2607.01065
GSRQ (arXiv 2607.01065, submitted Jul 1) ↗GSRQ (arXiv 2607.01065, 7/1 제출) ↗
Problem문제 정의Long-context deployment is capped by KV cache memory that grows linearly with tokens. Residual vector quantization can push storage toward sub-1-bit by encoding residuals with small codebooks, but it leans on standard L2 K-means — and in high dimensions L2 centroid averaging causes "centroid shrinkage" that weakens the angular (directional) term, so the codebook preserves direction poorly.롱컨텍스트 배포는 토큰에 선형으로 커지는 KV 캐시 메모리가 상한이다. 잔차 벡터 양자화는 작은 코드북으로 잔차를 인코딩해 저장을 서브-1-bit까지 밀어붙일 수 있지만, 표준 L2 K-means에 의존한다 — 고차원에서 L2 중심 평균은 "중심 수축"을 일으켜 각도(방향) 항을 약화시키므로 코드북이 방향을 잘 보존하지 못한다.
Method방법GSRQ replaces plain K-means with Gain-Shape K-means (GSKM), which separates a vector's magnitude (gain) from its direction (shape) so directional fidelity is preserved while matching or improving L2 distortion. Stacking these into a weighted residual-quantization scheme yields the sub-1-bit KV codebooks.GSRQ는 일반 K-means를 게인-셰이프 K-means(GSKM)로 대체한다 — 벡터의 크기(gain)와 방향(shape)을 분리해 L2 왜곡을 맞추거나 개선하면서 방향 충실도를 보존한다. 이를 가중 잔차 양자화로 쌓아 서브-1-bit KV 코드북을 만든다.
Results결과Fixing the directional weakness of L2 K-means lets residual quantization reach the sub-1-bit regime for the KV cache with better fidelity than the standard primitive, shrinking long-context memory further without the accuracy collapse shrinkage caused.L2 K-means의 방향 약점을 고쳐, 잔차 양자화가 표준 방식보다 더 나은 충실도로 KV 캐시를 서브-1-bit 영역까지 밀어붙인다. 수축이 유발하던 정확도 붕괴 없이 롱컨텍스트 메모리를 더 줄인다.
Summary요약Split gain from shape before you quantize residuals — L2 K-means shrinks centroids and loses direction; GSKM keeps it, unlocking sub-1-bit KV.잔차를 양자화하기 전에 gain과 shape를 분리하라 — L2 K-means는 중심을 수축시켜 방향을 잃지만, GSKM은 이를 지켜 서브-1-bit KV를 연다.

TASA — Task-Aware Sensitivity Analysis for Mixed-Precision Quantizationquantizationcalibration2607.00908
TASA (arXiv 2607.00908, submitted Jul 1) ↗TASA (arXiv 2607.00908, 7/1 제출) ↗
Problem문제 정의Mixed-precision quantization assigns more bits to the "important" layers, but importance is usually ranked by perplexity sensitivity. The authors find a "Perplexity Illusion": layers that look important by perplexity barely correlate with those that actually drive complex reasoning (Kendall τ ≈ 0), so bits get spent on the wrong layers.혼합정밀 양자화는 "중요한" 층에 더 많은 비트를 준다. 그러나 중요도는 보통 퍼플렉시티 민감도로 순위를 매긴다. 저자들은 "퍼플렉시티 착시"를 발견한다 — 퍼플렉시티로 중요해 보이는 층은 실제 복잡 추론을 좌우하는 층과 상관이 거의 없다(Kendall τ ≈ 0). 그래서 비트가 엉뚱한 층에 쓰인다.
