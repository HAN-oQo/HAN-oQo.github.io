StrataFlux: Memory-Hierarchy-Native Low-Bit LLM Inferencequantizationtiered memoryarXiv:2611.08363

Problem문제 정의Quantization cuts memory and bandwidth use but can hurt accuracy, while offloading higher-precision data to slower memory can stall generation.양자화는 메모리와 대역폭 사용을 줄이지만 정확도를 해칠 수 있고, 더 높은 정밀도의 데이터를 느린 메모리로 내리면 생성이 멈출 수 있다.

Method방법StrataFlux uses host RAM and SSDs as sources of extra precision. It streams only selected precision data, overlaps transfers with computation, and reuses fetched data across decoding steps.StrataFlux는 호스트 RAM과 SSD를 추가 정밀도의 원천으로 쓴다. 선택된 정밀도 데이터만 스트리밍하고, 전송을 연산과 겹치며, 가져온 데이터를 여러 디코딩 단계에서 재사용한다.

Results결과With Llama-3.1-8B-Instruct at 2-bit weights, WikiText-2 perplexity drops from 9.46 to 8.40 at 95.4% of the quantized base’s throughput on an RTX 5090. With Qwen3-8B at 2-bit weights and KV cache, AIME 2024/2025 accuracy rises from 11.0% to 47.1% at unchanged GPU memory. At 128K context, 3-bit weights with a 2-bit KV cache match vLLM’s 4-bit AWQ plus 8-bit KV cache in perplexity and speed using about half the GPU memory.2비트 가중치의 Llama-3.1-8B-Instruct에서 WikiText-2 퍼플렉시티가 9.46에서 8.40으로 줄고, RTX 5090에서 양자화 기본 모델 처리량의 95.4%를 유지한다. 가중치와 KV 캐시가 2비트인 Qwen3-8B는 GPU 메모리 변화 없이 AIME 2024/2025 정확도가 11.0%에서 47.1%로 오른다. 128K 문맥에서 3비트 가중치와 2비트 KV 캐시는 vLLM의 4비트 AWQ와 8비트 KV 캐시와 퍼플렉시티·속도가 비슷하면서 GPU 메모리는 약 절반이다.

Summary요약A tiny low-bit model stays on the GPU while extra precision is pulled from slower tiers only when needed.아주 작은 저비트 모델은 GPU에 두고, 추가 정밀도는 필요할 때만 느린 계층에서 가져온다.

Problem문제 정의KV cache eviction must decide which entries carry information the rest of the cache can no longer supply. A learnable gate on each entry’s attention weight is a natural estimator, but training it on the model’s own objective is problematic.KV 캐시 제거는 나머지 캐시가 더 이상 제공할 수 없는 정보를 담은 항목이 무엇인지 정해야 한다. 각 항목의 어텐션 가중치에 학습형 게이트를 두는 것이 자연스러운 추정 방법이지만, 모델 자신의 목적함수로 학습하는 데 문제가 있다.

Method방법The gate sits inside the normalizing softmax. The paper shows that trained on language-modeling loss against a frozen backbone, it stays near a constant score, which is a no-op. The fix is to put dense attention beyond the gate’s reach and make the dense model’s predictions its target, and to recover discarded mass with parameter-free centroids read inside the same softmax.게이트는 정규화 소프트맥스 안에 놓인다. 논문은 고정된 백본에 대해 언어 모델링 손실로 학습하면 게이트가 상수에 가까운 점수에 머물러 아무 일도 하지 않음을 보인다. 해법은 밀집 어텐션을 게이트의 영향 밖에 두고 밀집 모델의 예측을 목표로 삼으며, 버려진 질량은 같은 소프트맥스 안에서 읽는 비학습 센트로이드로 복원하는 것이다.

Results결과At 75% KV cache compression with Qwen3-8B, the gate reaches 90.14 on RULER at 8K and 46.03 on LongBench, which is 3.72 and 1.36 points below full-cache inference.Qwen3-8B에서 KV 캐시를 75% 압축했을 때 게이트는 RULER 8K에서 90.14, LongBench에서 46.03을 얻으며, 이는 전체 캐시 추론보다 각각 3.72점, 1.36점 낮다.

arxiv.org/abs/2611.07256 →

Problem문제 정의Sparsity and quantization both cut attention cost, but useful interactions differ in their needs: some tolerate low-precision scores yet are sensitive to removal.희소성과 양자화는 모두 어텐션 비용을 줄이지만, 유용한 상호작용마다 요구가 다르다. 어떤 것은 낮은 정밀도 점수는 견디지만 제거에는 민감하다.

Method방법TriAttention assigns each query-key tile to skipping, 4-bit or 8-bit computation, encoded per head with two diagonal-distance boundaries. Offline calibration and a model-wide allocator choose the boundaries under a shared budget, a fused kernel skips omitted tiles, and quantized keys and values from prefill are reused in a compressed KV cache for decoding.TriAttention은 각 쿼리-키 타일을 건너뛰기, 4비트, 8비트 연산 중 하나에 배정하며 헤드별로 두 개의 대각선 거리 경계로 표현한다. 오프라인 보정과 모델 전체 할당기가 공유 예산 아래에서 경계를 고르고, 융합 커널이 생략된 타일을 건너뛰며, 프리필에서 만든 양자화 키·값을 디코딩용 압축 KV 캐시로 재사용한다.

Results결과End-to-end generation speeds up by up to 7.88x over Torch attention and 2.65x over the BF16 baseline, with quality comparable to the original models on general-purpose and long-context tasks.엔드투엔드 생성이 Torch 어텐션 대비 최대 7.88배, BF16 기준 대비 2.65배 빨라지며, 범용·장문 과제에서 원 모델과 비슷한 품질을 유지한다.
