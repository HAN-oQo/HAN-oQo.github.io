CARVE — content-aware recurrent attention that erases only on the key axislinear attentionefficiency2606.27229
CARVE: Content-Aware Recurrent with Value Efficiency for Chunk-Parallel Linear Attention (arXiv 2606.27229, submitted Jun 25) ↗CARVE: Content-Aware Recurrent with Value Efficiency for Chunk-Parallel Linear Attention (arXiv 2606.27229, 6/25 제출) ↗
Problem문제 정의Recurrent (linear-attention) models must forget to remember, yet the leading delta-rule architecture (GDN-2) gates without consulting stored memory. Its value-axis erase mask wastes parameters and, the authors prove, breaks the WY-form triangular chunk solver that makes recurrent training competitive.순환(선형 어텐션) 모델의 대표 델타-규칙 구조인 GDN-2는 저장된 메모리를 보지 않고 게이팅한다. value축 소거 마스크는 파라미터를 낭비하고, 저자들의 증명에 따르면 순환 학습을 빠르게 만드는 WY형 삼각 청크 솔버까지 깨뜨린다.
Method방법CARVE fixes this with one principle, erase only on the key axis, which it proves necessary and sufficient for the WY-form solver. It reuses the recurrent output tensor (already in GPU memory) as a free content signal for the erase gate and replaces the per-value write-gate projection with one scalar per head.CARVE는 키축에서만 소거한다는 원칙 하나로 세 결함을 푼다. 이는 WY형 솔버가 유효할 필요충분조건이며, 이미 GPU 메모리에 있는 순환 출력 텐서를 소거 게이트의 콘텐츠 신호로 재사용하고 쓰기 게이트는 헤드당 스칼라 하나로 줄인다.
Results결과The chunk-parallel training path stays intact while the write gate uses far fewer parameters.청크 병렬 학습 경로를 그대로 유지하면서 쓰기 게이트 파라미터가 크게 줄어든다.
Summary요약Key-axis erase plus gating on reused output keeps recurrent attention chunk-parallel and cheaper.키축 소거와 출력 재사용 게이팅으로 순환 어텐션을 청크 병렬 그대로 더 싸게 만든다.

CAT-Q: Cost-efficient and Accurate Ternary Quantization for LLMs (arXiv 2606.26650, submitted Jun 25) ↗CAT-Q: Cost-efficient and Accurate Ternary Quantization for LLMs (arXiv 2606.26650, 6/25 제출) ↗
Problem문제 정의State-of-the-art ternary quantization offsets the large accuracy loss of 1.58-bit weights with costly quantization-aware training (QAT). The paper asks whether a simple post-training scheme can reach ternary LLMs instead.최신 3진 양자화는 1.58비트 가중치의 큰 정확도 손실을 비싼 양자화 인식 학습(QAT)으로 메운다. 논문은 간단한 사후 학습만으로 3진 LLM을 만들 수 있는지 묻는다.
Method방법CAT-Q is a two-part PTQ scheme. Learnable modulation (LM) reshapes the weight distribution and ternary threshold to be less sensitive to ternarization, and softened ternarization (ST) adds a differentiable transition for stable convergence.CAT-Q는 두 요소로 된 PTQ 기법이다. 학습형 변조(LM)가 가중치 분포와 3진 임계값을 3진화에 덜 민감하게 바꾸고, 연화 3진화(ST)가 미분 가능한 전이 함수로 안정적인 수렴을 돕는다.

TileMaxSim — IO-aware GPU kernels that stop materializing the MaxSim matrixkernelsretrieval2606.26439
TileMaxSim: IO-Aware GPU MaxSim Scoring with Dimension Tiling and Fused Product Quantization (arXiv 2606.26439, submitted Jun 24) ↗TileMaxSim: IO-Aware GPU MaxSim Scoring with Dimension Tiling and Fused Product Quantization (arXiv 2606.26439, 6/24 제출) ↗
Problem문제 정의Multi-vector retrieval models like ColBERT score with token-level MaxSim. GPU implementations reach only 5–18% of peak HBM bandwidth because they materialize the full Nq×Nd similarity matrix, which is used once and discarded.ColBERT 같은 다중 벡터 검색 모델은 토큰 단위 MaxSim으로 점수를 매긴다. 기존 GPU 구현은 Nq×Nd 유사도 행렬 전체를 만들었다 버리느라 피크 HBM 대역폭의 5–18%만 쓴다.
Method방법TileMaxSim is a family of IO-aware Triton kernels: (1) multi-query SRAM tiling reads each embedding from HBM once and keeps per-query-token maxima in registers; (2) dimension tiling splits d>128 into 128-wide chunks; (3) fused product-quantization scoring via shared-memory lookup tables cuts HBM I/O further.TileMaxSim은 IO 인식 Triton 커널 모음이다. (1) 다중 쿼리 SRAM 타일링으로 각 임베딩을 HBM에서 한 번만 읽고 쿼리 토큰별 최대값은 레지스터에 누적하며, (2) d>128이면 임베딩을 128폭 청크로 나누고, (3) 공유 메모리 룩업 테이블로 곱 양자화(PQ) 점수를 융합해 HBM I/O를 더 줄인다.
Results결과A roofline analysis shows MaxSim is bandwidth-bound. Never writing the similarity matrix closes that gap, and the fused PQ path cuts HBM I/O substantially on top.루프라인 분석상 MaxSim은 대역폭 바운드다. 유사도 행렬을 HBM에 쓰지 않아 이 격차를 메우고, 융합 PQ 경로가 HBM I/O를 추가로 크게 줄인다.
Summary요약Fusing and tiling MaxSim keeps the score matrix out of HBM and pushes a bandwidth-bound kernel back toward peak.MaxSim을 융합·타일링해 점수 행렬을 HBM에 쓰지 않으면 대역폭 바운드 커널이 피크에 가까워진다.

ASAP: A Disaggregated and Asynchronous Inference System for MoE Prefill (arXiv 2606.22541, submitted Jun 21) ↗ASAP: A Disaggregated and Asynchronous Inference System for MoE Prefill (arXiv 2606.22541, 6/21 제출) ↗
Problem문제 정의MoE serving pairs Data Parallelism for attention with Expert Parallelism for experts, forcing frequent global sync barriers between them. In online serving, varying arrival rates and sequence lengths cause DP imbalance and sync stalls that hurt TTFT and throughput.MoE 서빙은 어텐션에 데이터 병렬(DP), MoE에 전문가 병렬(EP)을 써서 둘 사이에 전역 동기화 장벽이 잦다. 온라인 서빙에서는 도착률·시퀀스 길이 편차가 DP 불균형과 동기화 정체를 일으켜 TTFT와 처리량을 깎는다.
Method방법ASAP disaggregates attention and MoE into a fully asynchronous pipeline. Specialized async communication primitives and four coordinated optimizations across scheduling and execution remove the global barriers.ASAP는 어텐션과 MoE 단계를 분리해 완전 비동기 파이프라인으로 돌린다. 전용 비동기 통신 프리미티브와 스케줄링·실행 전반의 네 가지 협응 최적화로 전역 장벽을 없앤다.

StickyInvoc — rethinking the create-destroy task model for high-throughput LLM workflowsthroughputHPC2606.22175
StickyInvoc: Rethinking Task Models for High-throughput Workflows in the LLM Era (arXiv 2606.22175, submitted Jun 20) ↗StickyInvoc: Rethinking Task Models for High-throughput Workflows in the LLM Era (arXiv 2606.22175, 6/20 제출) ↗
Problem문제 정의High-throughput LLM workflows on HPC clusters break the "create-destroy" task model: every task rebuilds and tears down its state, re-moving multi-gigabyte weights from storage to disk to CPU to GPU. DeepSeek's DSpark combines semi-autoregressive generation with confidence-based scheduling for speculative decoding.
