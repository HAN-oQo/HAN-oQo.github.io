HAWK: Heterogeneity-Aware KV Cache Transfer for Efficient GPU-NPU Phase-Disaggregated LLM InferencePD disaggregationKV transferarXiv:2610.29873
arxiv.org/abs/2610.29873 →

Problem문제 정의Prefill is compute-bound while decode is memory-bound, so GPUs suit prefill and NPUs can use their compute better in decode. Splitting the phases across the two chip types requires moving the KV cache from GPU to NPU, which is hard because the devices use different communication mechanisms and tensor layouts.GPU와 NPU는 프리필(연산 집약)과 디코드(메모리 집약)에서 효율이 다르다. 두 칩에 단계를 나누려면 KV 캐시를 GPU에서 NPU로 옮겨야 하는데, 통신 방식과 텐서 레이아웃이 달라 어렵다.

Method방법HAWK is a transfer mechanism that uses RDMA for direct GPU-to-NPU copies and allocates layout-aware buffers on the NPU side. Transferred KV can then be consumed without rearrangement.HAWK은 RDMA로 GPU에서 NPU로 직접 복사하고, NPU 쪽에 레이아웃을 고려한 버퍼를 할당한다. 전송된 KV를 재배열 없이 바로 쓸 수 있다.

Results결과On commercially available GPUs and NPUs, the system performs within 7.88% of a GPU-only system under the same SLO constraints, with up to 1.26x higher power efficiency and 1.72x higher cost efficiency.상용 GPU와 NPU에서 같은 SLO 조건의 GPU 전용 시스템 대비 7.88% 이내 성능을 내면서 전력 효율은 최대 1.26배, 비용 효율은 최대 1.72배 높다.

Summary요약Layout-aware RDMA transfer makes GPU-prefill plus NPU-decode disaggregation nearly as fast as GPU-only serving at better efficiency.레이아웃을 고려한 RDMA 전송으로 GPU 프리필과 NPU 디코드 분리 서빙이 GPU 전용에 근접한 속도를 내면서 효율은 더 높다.

arxiv.org/abs/2610.29820 →

Problem문제 정의Sparse attention attends to only selected past tokens, but the full retained KV cache still has to stay available for later decoding steps, which is costly in memory for long contexts.희소 어텐션은 선택된 과거 토큰만 보지만, 이후 디코딩 단계를 위해 전체 KV 캐시를 유지해야 해 긴 컨텍스트에서 메모리 부담이 크다.

Method방법UlaCache is a KV cache manager that presents GPU KV pools and optional CPU memory as one logical address space, so the engine allocates and selects KV without tracking physical location. Local GPU buffers keep selected KV across steps so only missing entries move, and a Parallel Bucketed LRU manages a shared GPU pool across requests. It supports both data-parallel and tensor-parallel attention.UlaCache는 GPU KV 풀과 선택적 CPU 메모리를 하나의 논리 주소 공간으로 보여주어, 엔진이 물리적 위치를 추적하지 않고 KV를 할당·선택하게 한다. 로컬 GPU 버퍼가 선택된 KV를 단계 간 유지해 빠진 항목만 옮기고, Parallel Bucketed LRU가 요청 간 공유 GPU 풀을 관리한다. 데이터 병렬과 텐서 병렬 어텐션을 모두 지원한다.

Results결과With speculative decoding and matched CPU/GPU memory budgets, peak decoding throughput beats the state-of-the-art baseline by 1.16x (DP) and 1.70x (TP) on H200, and by 1.73x (DP) and 2.51x (TP) on B300.추측 디코딩과 동일한 CPU/GPU 메모리 예산에서 최고 디코딩 처리량이 기존 최고 기법 대비 H200에서 1.16배(DP), 1.70배(TP), B300에서 1.73배(DP), 2.51배(TP)다.

Summary요약One logical address space over GPU and CPU KV memory lets sparse-attention serving keep long contexts without engine-side placement logic.GPU와 CPU KV 메모리를 하나의 논리 주소 공간으로 묶어, 엔진이 배치 로직 없이 희소 어텐션 서빙에서 긴 컨텍스트를 유지하게 한다.

Problem문제 정의Request migration and interruption recovery in distributed LLM inference rely on historical KV caches. Keeping or transferring a full cache is costly in state, while replaying the history tokens costs extra computation.분산 LLM 추론에서 요청 이전과 중단 복구는 과거 KV 캐시에 의존한다. 전체 캐시를 유지·전송하면 상태 비용이 크고, 토큰을 재생하면 추가 연산이 든다.

Method방법RISK-KV reconstructs selected layers of historical KV instead of storing them. It keeps exact KV on both sides of a target layer, uses cross-layer ridge regression to predict the missing layer's attention-projection input, and folds in the model's KV projection matrices to save predictor storage. Reconstruction risk is measured as the change in negative log-likelihood, and a low-overhead topology search with quality gating picks the layer groups.RISK-KV는 과거 KV의 일부 레이어를 저장하는 대신 재구성한다. 대상 레이어 양쪽의 정확한 KV를 유지하고, 레이어 간 릿지 회귀로 빠진 레이어의 어텐션 투영 입력을 예측하며, 모델의 KV 투영 행렬을 합쳐 예측기 저장 공간을 줄인다. 재구성 위험은 음의 로그 가능도 변화로 재고, 품질 게이팅이 있는 저비용 토폴로지 탐색으로 레이어 그룹을 고른다.

Results결과On three language models, representative configurations omit 18.2% to 33.3% of historical KV with perplexity changes below 0.5%. In a local recovery experiment with a 512-token history, it is 1.51x to 3.31x faster than full token replay.세 언어 모델에서 대표 설정은 과거 KV의 18.2~33.3%를 생략하면서 퍼플렉서티 변화가 0.5% 미만이다. 512토큰 이력의 로컬 복구 실험에서 전체 토큰 재생보다 1.51~3.31배 빠르다.

Summary요약Predicting some layers' KV from their neighbours cuts recovery state and time with little quality change.이웃 레이어에서 일부 레이어의 KV를 예측해 품질 변화는 작게 두고 복구 상태와 시간을 줄인다.

Problem문제 정의Draft models are usually trained by soft-label distillation, which forces them to mimic the target's full output distribution, including high-entropy regions that lower acceptance rates and raise the risk of early rejection.드래프트 모델은 보통 소프트 라벨 증류로 학습되어 타깃의 전체 출력 분포를 모방한다. 이때 엔트로피가 높은 영역이 수용률을 낮추고 조기 거절 위험을 높인다.

Method방법RCSD trains the draft toward the system-level goal of longer acceptance. It builds implicit preference pairs from accepted and rejected sequences that occur naturally during speculative inference, and uses a masked loss so target-aligned tokens are not penalized.RCSD는 더 긴 수용 길이라는 시스템 수준 목표에 맞춰 드래프트를 학습한다. 추측 추론 중 자연히 생기는 수용·거절 시퀀스로 암묵적 선호 쌍을 만들고, 타깃과 일치하는 토큰은 벌점을 받지 않도록 마스크 손실을 쓴다.

Results결과Across multiple benchmarks, average acceptance length improves by 35% over HASS and end-to-end inference is 1.35x faster than HASS on practical workloads, without hurting generation quality.여러 벤치마크에서 평균 수용 길이가 HASS 대비 35% 늘고, 실제 워크로드에서 종단 추론이 HASS보다 1.35배 빠르며 생성 품질은 유지된다.

Summary요약Treating accepted vs. rejected drafts as preference data aligns draft training with what speculative decoding actually rewards.수용·거절된 초안을 선호 데이터로 쓰면 드래프트 학습이 추측 디코딩이 실제로 보상하는 것과 일치한다.

Method방법The authors show that guaranteed exact reuse needs a distribution computed at the next round's full context, and characterize when retaining it costs accepted tokens.
