STEPQuant: When and Where Errors Matter in Delta-Rule Recurrent State Quantizationstate quantizationlinear attentionarXiv:2609.38169
arxiv.org/abs/2609.38169 →

Problem문제 정의Linear attention swaps a growing KV cache for a fixed-size recurrent state, but under concurrent serving these persistent states still become a memory bottleneck. Quantizing them to low precision directly hurts accuracy because errors compound through successive state updates.선형 어텐션은 커지는 KV 캐시를 고정 크기 재귀 상태로 바꾸지만, 동시 서빙에서는 이 영속 상태가 여전히 메모리 병목이 된다. 낮은 정밀도로 바로 양자화하면 오차가 연속된 상태 갱신을 거치며 누적돼 정확도가 크게 떨어진다.

Method방법STEPQuant is a post-training, spatial-temporal quantizer for Delta-rule states. It allocates precision by error magnitude and memory lifetime (errors in long-lived memory persist across many decoding steps), and jointly fits key-row and value-column scales from the state distribution and each key row's impact on output error.STEPQuant는 Delta 규칙 상태를 위한 학습 후 시공간 양자화기다. 오차 크기와 메모리 수명(오래 사는 메모리의 오차는 여러 디코딩 단계에 걸쳐 남는다)에 따라 정밀도를 배분하고, 상태 분포와 키 행이 출력 오차에 미치는 영향으로 키 행·값 열 스케일을 함께 맞춘다.

Results결과On Qwen3.8-27B and Kimi-Linear-48B-A3B-Instruct, a nominal 6-bit budget closely matches FP32-state accuracy and the 4-bit configuration beats uniform INT8. Integrated into SGLang with optimized GPU kernels, 6-bit STEPQuant gives over 5x recurrent-state compression and cuts total serving memory by up to 68.7%.Qwen3.8-27B와 Kimi-Linear-48B-A3B-Instruct에서 명목 6비트 예산은 FP32 상태 정확도에 가깝게 맞고, 4비트 구성은 균일 INT8보다 낫다. 최적화된 GPU 커널로 SGLang에 통합한 6비트 STEPQuant는 재귀 상태를 5배 넘게 압축하고 전체 서빙 메모리를 최대 68.7% 줄인다.

Summary요약Where and when a state error lands matters more than uniform bit-width, so precision should follow lifetime and key-row impact.상태 오차가 어디에 언제 떨어지는지가 균일 비트 수보다 중요하므로, 정밀도는 수명과 키 행의 영향을 따라야 한다.

Problem문제 정의KV-cache memory and bandwidth grow with context length and batch size, which limits efficient long-context inference. Low-bit KV quantization is attractive, but outlier-heavy keys and values make the quantization error large without a good transform.KV 캐시 메모리와 대역폭은 컨텍스트 길이와 배치 크기에 따라 늘어 효율적인 장문 추론을 제한한다. 저비트 KV 양자화는 매력적이지만, 이상치가 많은 키와 값은 좋은 변환 없이는 양자화 오차가 커진다.

Method방법WUSH-KV adapts WUSH, which builds a data-aware transform from the second-order statistics of both factors in a matrix product. Calibration data yields separate key and value transforms: the value transform is folded into the model weights, the key transform is applied after RoPE, and both pair with clipped quantizers such as QuEST INT.WUSH-KV는 행렬 곱 양쪽 인자의 2차 통계로 데이터 인지 변환을 만드는 WUSH를 가져다 쓴다. 보정 데이터로 키와 값 변환을 따로 만들며, 값 변환은 모델 가중치에 녹이고 키 변환은 RoPE 뒤에 적용하고, 둘 다 QuEST INT 같은 클리핑 양자화기와 짝지을 수 있다.

Results결과Under mild assumptions the WUSH transform is near-optimal for QuEST INT, and WUSH-KV lowers layerwise reconstruction error with the lowest end-to-end perplexity among tested transforms. Integrated into SGLang with OSCAR-style percentile-clipped affine quantization, 2-bit WUSH-KV matches or beats OSCAR across all evaluated models and downstream tasks.온건한 가정 아래 WUSH 변환은 QuEST INT에 거의 최적이며, WUSH-KV는 층별 복원 오차를 낮추고 시험한 변환 중 종단 간 퍼플렉시티가 가장 낮다. OSCAR 방식의 백분위 클리핑 아핀 양자화로 SGLang에 통합했을 때 2비트 WUSH-KV는 평가한 모든 모델과 다운스트림 과제에서 OSCAR와 같거나 더 낫다.

Problem문제 정의As context grows, the KV cache can outgrow the model weights and, because decoding is memory-bound, decode cost climbs with cache size. Evicting low-relevance tokens helps but is a one-off decision that may prove harmful later.컨텍스트가 커지면 KV 캐시가 모델 가중치보다 커질 수 있고, 디코딩이 메모리 병목이라 캐시 크기에 따라 디코드 비용이 오른다. 관련성 낮은 토큰을 버리면 도움이 되지만 한 번의 결정이 나중에 해가 될 수 있다.

Method방법KV-Kaizen learns a selector that, from the context, emits a per-layer cache configuration meeting an overall compression budget. It combines three non-evicting axes: sharing one cache across layers (depth), caching at fewer bits (precision), and truncating low-rank latent cache representations (rank); the selector runs once before prefill.KV-Kaizen은 컨텍스트로부터 전체 압축 예산을 맞추는 층별 캐시 구성을 내놓는 선택기를 학습한다. 토큰을 버리지 않는 세 축, 즉 층 간 캐시 공유(깊이), 더 적은 비트로 저장(정밀도), 저랭크 잠재 캐시 표현 절단(랭크)을 조합하며, 선택기는 프리필 전에 한 번만 돈다.

Results결과On instruction-following and reasoning tasks the selectors reach the accuracy-versus-cache-size Pareto frontier against learning-free and post-hoc baselines. On long-context tasks it improves on eviction and composes with it, reaching a 32x smaller decode-time cache on a 14B model with accuracy preserved; 4x reduction costs no accuracy from 7B parameters up.지시 따르기·추론 과제에서 선택기는 학습 없는 기법과 사후 기법 대비 정확도–캐시 크기 파레토 프런티어에 도달한다. 장문 과제에서는 퇴출 방식을 개선하고 함께 쓸 수 있어 14B 모델에서 정확도를 지키면서 디코드 시 캐시를 32배 줄이며, 7B 이상에서는 4배 축소에 정확도 손실이 없다.

Summary요약Composing small per-layer compression choices adaptively beats applying any one uniformly.층마다 작은 압축 선택을 문맥에 맞게 조합하면 어느 하나를 균일하게 쓰는 것보다 낫다.

Problem문제 정의No single way of parallelizing attention fits all loads: low concurrency favors tensor parallelism, many requests favor data-parallel attention, long prompts favor context parallelism. Reasoning, agentic and RL-rollout workloads shift mid-run, yet engines fix one layout at launch because changing it meant draining requests and restarting workers.하나의 어텐션 병렬화 방식이 모든 부하에 맞지는 않는다. 낮은 동시성에는 텐서 병렬, 많은 요청에는 데이터 병렬 어텐션, 긴 프롬프트에는 컨텍스트 병렬이 유리하다. 추론·에이전트·RL 롤아웃 워크로드는 실행 중에 바뀌지만, 레이아웃을 바꾸려면 요청을 비우고 워커를 재시작해야 해서 엔진은 시작 때 하나로 고정한다.
