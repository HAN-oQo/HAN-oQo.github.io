Problem문제 정의Linear-attention and state-space models compress the prefix into a fixed-size recurrent state, giving O(1) memory but a lossy one: when many key–value associations compete, earlier facts get overwritten and needle recall degrades. There is no channel to keep the specific associations the state cannot hold.선형 어텐션·상태공간 모델은 프리픽스를 고정 크기 순환 상태로 압축해 O(1) 메모리를 얻지만 손실이 있다 — 많은 키-값 연관이 경쟁하면 앞선 사실이 덮어써지고 니들 회수가 나빠진다. 상태가 담지 못하는 특정 연관을 보존할 채널이 없다.
Method방법HOLA keeps the usual delta-rule state as compressive memory and adds a bounded exact KV cache — a semiparametric test-time memory. Problem문제 정의Disaggregated serving splits prefill and decode onto separate GPU pools to stop the phases interfering, but under bursty, heavy-tailed traffic prefill nodes saturate while decode nodes idle. On a 2P2D setup the authors find prefill execution is only 2–23% of P95 Time-to-First-Token (TTFT); queuing and inter-node GPU–GPU KV-cache transfer account for the rest.분리 서빙은 두 단계 간섭을 막으려 프리필과 디코드를 별도 GPU 풀로 나누지만, 버스티·헤비테일 트래픽에서 프리필 노드는 포화되고 디코드 노드는 논다. 2P2D 구성에서 프리필 실행은 P95 TTFT의 2–23%뿐이고 나머지는 큐잉과 노드 간 GPU-GPU KV 캐시 전송이 차지한다.
Method방법A proactive prefill-deflecting scheduler lets decode nodes serve a request's prefill as chunked-prefill steps interleaved with their in-flight decode batches. For each queued request it estimates the TTFT on the prefill node and searches each decode node for the largest chunk schedule that keeps in-flight decodes within their Time-Between-Tokens SLO, deflecting only when the decode path helps tail latency. Because deflected prefill runs in place, the inter-node KV transfer is eliminated.선제적 프리필 디플렉션 스케줄러는 디코드 노드가 요청의 프리필을 진행 중 디코드 배치와 인터리브된 청크 프리필 스텝으로 처리하게 한다. 큐의 각 요청에 대해 프리필 노드에서의 TTFT를 추정하고, 각 디코드 노드에서 진행 중 디코드를 TBT SLO 안에 유지하는 최대 청크 스케줄을 탐색해 꼬리 지연에 도움될 때만 디플렉트한다. 디플렉트된 프리필은 제자리에서 실행되어 노드 간 KV 전송이 제거된다.

Method방법Vera is an end-to-end automated safety-testing framework with a three-stage self-reinforcing pipeline: (1) literature-driven exploration continuously discovers and structures emerging risks into taxonomies; (2) combinatorial composition across taxonomy dimensions produces executable scenarios; (3) adaptive execution runs agents in isolated sandboxes with a control agent steering multi-turn interaction, while evidence-grounded verifiers judge from environment state and tool-call evidence — not model self-report.Vera는 3단계 자기강화 파이프라인의 종단 자동 안전 테스트 프레임워크다 — (1) 문헌 기반 탐색이 신흥 위험을 지속 발굴·구조화해 분류체계로 만들고, (2) 분류 차원 간 조합 합성이 실행 가능한 시나리오를 생성하며, (3) 적응적 실행이 격리 샌드박스에서 에이전트를 돌리고 제어 에이전트가 멀티턴 상호작용을 조종하며, 증거 기반 검증기가 모델 자기보고가 아니라 환경 상태·도구 호출 증거로 판정한다.

Problem문제 정의Autonomous customer-service agents are shifting from conversation to operational execution — retrieving firm records, applying policies, and executing backend writes such as refunds, cancellations, exchanges, and reservation changes. Applying heavy control uniformly across all sessions is wasteful, but errors on consequential writes are costly.자율 고객 서비스 에이전트는 대화에서 운영 실행으로 이동 중이다 — 기업 기록 조회, 정책 적용, 환불·취소·교환·예약 변경 같은 백엔드 쓰기 실행. 모든 세션에 무겁게 균일한 제어를 적용하면 낭비지만, 중대한 쓰기의 오류는 비싸다.
Method방법A difficulty-routed control architecture triggers "reconsideration" — concentrating deliberation and safeguards — before consequential backend writes, rather than applying additional control uniformly. Stronger control is routed toward requests with operational conflict.난이도 라우팅 제어 구조는 균일하게 추가 제어를 적용하는 대신, 중대한 백엔드 쓰기 앞에서 "재고"(심의·안전장치 집중)를 촉발한다. 더 강한 제어는 운영 갈등이 있는 요청으로 라우팅된다.
Results결과On human-verified retail and airline tasks from τ²-bench, the method consistently improves reliability on service requests with operational conflict. Routing evidence shows control is directed at conflicted (not routine) requests, and gains come from targeted evidence-gathering turns and tool calls — not indiscriminate interaction expansion or broader tool chains.τ²-bench의 인간 검증 소매·항공 태스크에서 이 방법은 운영 갈등이 있는 요청의 신뢰성을 일관되게 높인다. 라우팅 증거는 제어가 (일상 요청이 아니라) 갈등 요청으로 향함을 보이고, 이득은 무분별한 상호작용 확장이나 넓은 도구 체인이 아니라 표적화된 증거 수집 턴·도구 호출에서 온다.
