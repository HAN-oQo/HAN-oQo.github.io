vLLM — determinism gets cheaper: an autotuned batch-invariance kernel cuts 33.6% of end-to-end latency Aug 25

48 commits, still no new tag after v0.27.1. Batch invariance is the property that a request produces bit-identical output regardless of which other requests happen to be batched with it — necessary for reproducible evaluation and for RL rollouts that must match training, and historically paid for in throughput. This window autotunes the Triton kernel behind it on Blackwell and reports a 33.6% end-to-end latency reduction, while a separate change disables fuse_allreduce_rms whenever VLLM_BATCH_INVARIANT is set because the fusion is non-deterministic under tensor parallelism. Kimi K3 got a low-latency decode GEMM dispatch on SM100; sparse-MLA speculative decoding gained adaptive DSpark on the same architecture. Correctness work included deferring the request-level cascade of in-flight primary keys in KV offload, running CUDA-graph memory profiling in a throwaway pool so profiling no longer perturbs the real allocator, and rejecting malformed base64 audio with a 400 instead of a 500. 커밋 48개, v0.27.1 이후 새 태그는 여전히 없다. 배치 불변성은 어떤 요청이 다른 어떤 요청과 함께 묶이든 비트 단위로 같은 출력을 내는 성질이다 — 재현 가능한 평가와 학습과 일치해야 하는 RL 롤아웃에 필요하지만, 지금까지 그 대가는 처리량이었다. 이번 구간에는 그 뒤의 Triton 커널을 Blackwell에서 자동 튜닝해 종단 지연 33.6% 감소를 보고하고, 별도 변경으로 VLLM_BATCH_INVARIANT가 켜지면 fuse_allreduce_rms를 끈다 — 텐서 병렬에서 그 융합이 비결정적이기 때문이다. Kimi K3는 SM100에서 저지연 디코드 GEMM 디스패치를 얻었고, 희소 MLA 추측 디코딩은 같은 아키텍처에서 적응형 DSpark를 얻었다. 정확성 작업으로는 KV 오프로드에서 인플라이트 기본 키의 요청 수준 연쇄를 미루기, CUDA 그래프 메모리 프로파일링을 버리는 풀에서 돌려 프로파일링이 실제 할당기를 흔들지 않게 하기, 잘못된 base64 오디오를 500이 아닌 400으로 거절하기가 있다.

ProxyFormer: A Dual-Stream Proxy Architecture for Ultra-Long Context and High-Resolution Generationlong contextKV cachearXiv:2608.23463
arxiv.org/abs/2608.23463 — submitted Aug 24 2026
Problem / 문제 정의 Attention cost and KV-cache size both grow quadratically and linearly with sequence length, which is the central bottleneck for ultra-long-context language models and for high-resolution generative models. The usual fix is to compress the sequence into a smaller set of summary states once, then do all the expensive global work there. The paper's objection is that a single compression step is irreversible: anything the compressor drops at that moment is gone for every later layer. 어텐션 비용과 KV 캐시 크기는 시퀀스 길이에 따라 각각 제곱·선형으로 늘어나며, 이것이 초장문맥 언어 모델과 고해상도 생성 모델의 핵심 병목이다. 흔한 해법은 시퀀스를 더 작은 요약 상태 집합으로 한 번 압축한 뒤 비싼 전역 연산을 거기서 전부 처리하는 것이다. 논문의 반론은 단발 압축이 되돌릴 수 없다는 점이다: 그 시점에 압축기가 버린 것은 이후 모든 레이어에서 사라진다.
Method / 방법 ProxyFormer keeps two streams alive at every layer. Fine-grained local features are compressed bottom-up into a small set of proxy states; global interaction happens only in that compressed proxy space; the contextualized proxies are then decompressed and injected top-down back into the local stream. Because the local stream persists across layers, information missed by one compression step is still available for a later one to pick up. On top of this the paper adds factorized multi-level compression/decompression, layer-wise dynamic compression ratios, asymmetric dual embeddings, and a proxy-only KV-cache inference scheme. ProxyFormer는 모든 레이어에서 두 스트림을 함께 살려 둔다. 세밀한 로컬 특징은 상향식으로 소수의 프록시 상태로 압축되고, 전역 상호작용은 그 압축 공간에서만 일어나며, 문맥화된 프록시는 다시 복원돼 하향식으로 로컬 스트림에 주입된다. 로컬 스트림이 레이어를 가로질러 유지되므로 한 압축 단계가 놓친 정보를 이후 단계가 다시 집어 갈 수 있다. 그 위에 인수분해된 다단 압축·복원, 레이어별 동적 압축률, 비대칭 이중 임베딩, 그리고 프록시만 저장하는 KV 캐시 추론 방식을 얹는다.
Results / 결과 The paper reports language-modelling results including needle-in-a-haystack retrieval measured under 8K and 64K training windows and extrapolated out to 256K tokens, with the proxy-only KV cache being what makes that extrapolation affordable. Preliminary image-generation experiments demonstrate the architecture is workable for both pixel-space and latent-space flow matching, i.e. the dual-stream idea is not specific to text. 논문은 8K·64K 학습 창에서 측정하고 256K 토큰까지 외삽한 건초더미 속 바늘 검색을 포함한 언어 모델링 결과를 보고하며, 그 외삽을 감당 가능하게 만드는 것이 프록시만 저장하는 KV 캐시다. 예비 이미지 생성 실험은 이 구조가 픽셀 공간과 잠재 공간 flow matching 모두에서 동작함을 보여, 이중 스트림 아이디어가 텍스트 전용이 아님을 시사한다.
Summary / 요약 The interesting claim is architectural rather than numerical: compression should be a per-layer view of the sequence, not a one-time commitment. Keeping the uncompressed local stream alive costs memory during the forward pass but is exactly what buys back the recoverability that one-shot compression gives up — and at inference time only the proxies need caching. 흥미로운 주장은 수치가 아니라 구조에 있다: 압축은 한 번의 결정이 아니라 레이어마다 갱신되는 시퀀스에 대한 관점이어야 한다는 것이다. 압축되지 않은 로컬 스트림을 살려 두는 데는 순전파 메모리가 들지만, 그것이 바로 단발 압축이 포기한 복구 가능성을 되사 준다 — 그리고 추론 시점에 캐시가 필요한 것은 프록시뿐이다.

Sigmoid Attention as a Better Substrate for Learned KV Cache EvictionKV cacheattentionarXiv:2608.23296
arxiv.org/abs/2608.23296 — submitted Aug 24 2026
Problem / 문제 정의 Learned KV-cache eviction has a soft-to-hard mismatch. During training a differentiable gate merely attenuates a token's contribution; at inference you only save memory if the KV entry is physically deleted. The gap between "turned down" and "removed" is where learned eviction methods lose accuracy. The paper asks a question nobody had isolated: does the attention function itself — softmax versus sigmoid — change how well a soft gate survives that transition? 학습된 KV 캐시 축출에는 soft-to-hard 불일치가 있다. 학습 중 미분 가능한 게이트는 토큰의 기여를 줄일 뿐이지만, 추론에서 메모리를 아끼려면 KV 항목을 실제로 삭제해야 한다. "줄임"과 "제거" 사이의 간극에서 학습된 축출 기법은 정확도를 잃는다. 논문은 아무도 따로 떼어 보지 않은 질문을 던진다: 어텐션 함수 자체 — 소프트맥스냐 시그모이드냐 — 가 소프트 게이트가 그 전환을 얼마나 잘 견디는지를 바꾸는가?
Method / 방법 A controlled 2×2×2 comparison on GPT-2-scale Transformers trained on OpenWebText, varying attention type (softmax vs sigmoid), learned gating (on/off), and positional encoding.
