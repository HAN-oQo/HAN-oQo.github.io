CrossPool: Efficient Multi-LLM Serving for Cold MoE Models through KV-Cache and Weight Disaggregation (arXiv 2606.24506, submitted Jun 23) ↗CrossPool: Efficient Multi-LLM Serving for Cold MoE Models through KV-Cache and Weight Disaggregation (arXiv 2606.24506, 6/23 제출) ↗
Problem문제 정의Services now host many sparse MoE models, but most receive sparse traffic and stay cold. Weights are stable and model-determined while the KV cache is transient and demand-determined, so reserving worst-case KV capacity per cold model wastes memory — and in a monolithic GPU pool, static weights also compete with dynamic KV cache.서비스는 이제 많은 희소 MoE 모델을 호스팅하지만 대부분은 트래픽이 적어 콜드 상태다. 가중치는 안정적·모델 결정적이고 KV 캐시는 일시적·수요 결정적이라, 콜드 모델마다 최악 KV 용량을 예약하면 메모리가 낭비된다 — 단일 GPU 풀에선 정적 가중치가 동적 KV 캐시와 경쟁하기까지 한다.
Method방법CrossPool is a serving engine that disaggregates the two: a shared KV-cache pool provisions aggregate active demand across cold models instead of per-model worst case, while weights live in a separate pool so they no longer contend with transient KV. Because cold models rarely peak at once, the shared pool covers their combined active footprint at far lower reserved capacity.CrossPool은 둘을 분리하는 서빙 엔진이다 — 공유 KV 캐시 풀이 모델별 최악이 아니라 콜드 모델들의 합산 활성 수요를 충당하고, 가중치는 별도 풀에 두어 일시적 KV와 더는 경쟁하지 않게 한다. 콜드 모델은 동시에 피크에 도달하는 일이 드물어, 공유 풀이 훨씬 낮은 예약 용량으로 합산 활성 사용량을 덮는다.
Results결과By sharing KV across cold models and splitting weights from the KV pool, CrossPool raises GPU memory utilization and improves long-context support that KV-head-limited attention under cold, low-concurrency traffic otherwise leaves stranded — turning replicated-but-idle KV capacity into usable headroom.콜드 모델 간 KV를 공유하고 가중치를 KV 풀에서 분리함으로써, CrossPool은 GPU 메모리 활용을 높이고, 콜드·저동시성 트래픽에서 KV-head 제한 어텐션이 방치하던 롱컨텍스트 지원을 개선한다 — 복제됐지만 유휴인 KV 용량을 쓸 수 있는 여유로 바꾼다.
Summary요약Pool the KV cache across many cold MoE models and keep weights in a separate pool — aggregate demand needs far less reserved memory than per-model worst case.많은 콜드 MoE 모델에 걸쳐 KV 캐시를 풀링하고 가중치는 별도 풀에 둬라 — 합산 수요는 모델별 최악보다 훨씬 적은 예약 메모리면 된다.

Kamera: Unified Position-Invariant Multimodal KV Cache for Training-Free Reuse (arXiv 2606.23581, submitted Jun 22) ↗Kamera: Unified Position-Invariant Multimodal KV Cache for Training-Free Reuse (arXiv 2606.23581, 6/22 제출) ↗
Problem문제 정의Multimodal agents re-examine the same video frames, UI screenshots and artifacts as their context window slides, yet every look-back re-encodes from scratch because prefix caches only serve reuse at a fixed leading position.
