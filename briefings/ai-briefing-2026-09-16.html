SGLang — hybrid-SWA memory gets one shared byte budget, and DeepEP v2 learns batch-invariant BF16 Sep 15

Fifty-seven commits, no new tag. The memory change is the structural one: unified hybrid sliding-window attention now draws from a single shared byte budget rather than sizing full-attention and window layers against separate pools. A hybrid model mixes layers whose KV grows with the whole context and layers whose KV stops at the window, so two independent pools always leave one of them stranded; a shared byte budget lets the layers that actually need the bytes take them. On the kernel side, DeepEP v2 gained BF16 support together with batch-invariant inference — the property that a request's output does not shift depending on who else is batched with it, which is what makes a decode fleet reproducible under load. The PD lane got a test-infrastructure fix with a real operational edge: prefill and decode are now given their own RDMA NICs in disaggregation tests, which is how the deployment is actually wired and what the tests had been quietly conflating. The Rust frontend accepted external multimodal processors, the PD router picked up real-GPU end-to-end coverage for storage-tier-aware cache routing, and a shutdown-ordering bug was closed by releasing NCCL when the scheduler exits and letting the ASGI server own the teardown. Model plumbing: Gemma4's unified conditional-generation head had lm_head_is_tied set, first-token metadata and reused attention-layer indexing were corrected, and tool-call index, graph padded-row count and prefill-graph input_embeds refresh were fixed together. 커밋 57개, 새 태그 없음. 구조적인 변화는 메모리 쪽이다. 통합 하이브리드 슬라이딩 윈도 어텐션이 이제 전체 어텐션 층과 윈도 층을 별도 풀로 재는 대신 공유 바이트 예산 하나에서 끌어다 쓴다. 하이브리드 모델은 KV가 전체 문맥과 함께 자라는 층과 윈도에서 멈추는 층을 섞으므로, 독립된 두 풀은 항상 한쪽을 놀리게 된다. 공유 바이트 예산은 실제로 바이트가 필요한 층이 가져가게 한다. 커널 쪽에서는 DeepEP v2가 BF16과 배치 불변 추론을 함께 얻었다. 배치 불변성은 누구와 함께 배치되는가에 따라 요청의 출력이 달라지지 않는 성질로, 부하 상태의 디코드 설비를 재현 가능하게 만드는 조건이다. vLLM — NIXL pushes attention-HMA layouts across pipeline stages, and the V4.1 indexer gets sparse MQA logits Sep 15

Sixty-eight commits, no new tag. The KV-transfer change is the one with the longest reach: the NIXL connector now supports attention-HMA layouts in pipeline-parallel push prefill. Push prefill moves KV from the prefill side to the decode side as it is produced rather than having the decode side pull it, and the layout question is whether the connector understands how a hybrid-memory attention model has arranged its cache — if it does not, the shards either cannot be moved or have to be materialized into a dense form first. On the sparse-attention side, DeepGEMM sparse MQA logits were wired into the DeepSeek V4.1 indexer, and the ROCm lane optimized DSV4.1 K=512 decode top-k on gfx950 while adding Aiter MLA decode support for non-causal draft blocks. Sampling got a persistent top-k with sampled filtering, a perf change that keeps the top-k structure alive across steps instead of rebuilding it. Housekeeping was unusually dense: per-layer offsets are now preserved in HiSparse KV-cache bindings and the HiSparse attention config is inferred from its connector rather than declared twice; nested score-cancellation handlers for the /v1/score alias were removed; kernel-import errors are formatted eagerly so warning_once does not retain them; and the build lane refreshed public Rubin dependencies and MSA compatibility. 커밋 68개, 새 태그 없음. 파급이 가장 긴 변화는 KV 전송 쪽이다. Dynamo — the planner may scale down while workers are still starting, and Nemotron 3 Nano Omni gets image routing Sep 15

Thirty commits, no new stable tag. The planner fix is the operationally interesting one: scale-down is now allowed while workers are starting. A planner that refuses to shrink until every pending worker has finished coming up will hold a fleet at its high-water mark through exactly the traffic dip it was supposed to shed, and the window between "scale-up decided" and "worker ready" is long enough on large models to matter. Multimodal routing gained a path for Nemotron 3 Nano Omni images, keeping image-bearing requests on the worker that already holds the relevant state. Two reliability fixes landed against Kubernetes and container behaviour: RL worker discovery no longer returns an empty list on Kubernetes — a silent failure mode in which a healthy fleet looks unpopulated — and the TRT-LLM runtime's Triton JIT was made independent of the image's environment variables, so a container rebuild cannot quietly change compilation behaviour. Router tests were isolated per request. Problem문제 정의 LLM serving reuses KV cache by exact prefix match, so when a prompt is assembled from a set of reusable pieces — retrieved documents, tool descriptions, few-shot blocks — the order in which those pieces are concatenated decides how much of the cache is hit. Problem문제 정의 Chain-of-thought monitoring is a safety strategy in which an "actor" model's reasoning is inspected by a "monitor" — often another language model — for signs of unsafe planning, deception or misalignment.
