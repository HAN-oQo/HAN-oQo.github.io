Problem문제 정의Streaming video understanding must answer queries that arrive asynchronously while visual tokens keep streaming under strict GPU-memory and latency budgets. Method방법ProtoKV is a constant-footprint memory that keeps an exact near-window KV cache but folds older content into a fixed-capacity semantic-spatial "prototype bank" with residual statistics, rather than retaining token instances. Problem문제 정의Speculative decoding speeds inference by letting a draft model propose tokens that the target verifies. That raises a safety question: at temperature zero, can the draft's behavior leak into safety-scored outputs, so the "accelerated" model is no longer behaviorally identical to the target alone?추측 디코딩은 초안 모델이 토큰을 제안하고 타깃이 검증하게 해 추론을 가속한다. 여기서 안전성 질문이 생긴다 — 온도 0에서 초안의 행동이 안전성 채점 출력에 새어 들어, "가속된" 모델이 더 이상 타깃 단독과 행동적으로 동일하지 않을 수 있는가?
