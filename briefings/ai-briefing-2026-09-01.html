SGLang — the unified memory manager grows three sub-pools, a byte budget and a conservation check Aug 31

The largest merge of the day rebuilds unified memory around three separate sub-pools so that Mamba state, hybrid sliding-window KV and ordinary full-attention KV stop competing for one flat allocation — the case that breaks first on hybrid-SWA models. A companion change replaces token-count sizing with a byte budget, adds a feasibility floor so the pool refuses to boot into a configuration it cannot honour, and installs a conservation verifier that checks nothing leaks between sub-pools. Four boot and correctness fixes on the same hybrid paths landed alongside, and a separate [mem_cache] change made release, row-reuse asserts and presence checks all read the KV record instead of inferring state. 가장 큰 머지는 통합 메모리를 세 서브풀로 나눠 Mamba 상태, 하이브리드 SWA KV, 풀 어텐션 KV가 한 할당을 두고 다투지 않게 한다. 토큰 수 대신 바이트 예산으로 크기를 정하고, 지킬 수 없는 구성이면 부팅을 거부하는 하한과 서브풀 간 누수를 잡는 보존 검증기도 붙었다. 같은 경로의 부팅·정확성 수정 네 건과, 해제·존재 확인이 KV 레코드를 직접 읽게 한 [mem_cache] 변경도 들어왔다.

Sliding-window beats linear attentionattention architecturearXiv:2608.28444
arxiv.org/abs/2608.28444 →
Problem문제 정의Quadratic attention means every additional token costs more than the one before it, and its keys and values have to be kept in memory indefinitely. One popular escape route is to retrofit an existing LLM into linear attention through post-training. The paper's complaint is procedural: that line of work has never been measured against the simplest baseline that solves the same problem.선형 어텐션 개조(기존 LLM을 사후 학습으로 바꾸는 방식) 연구가 가장 단순한 기준선과 비교된 적이 없다는 지적이다.
Method방법The baseline in question is Sliding Window Attention with attention sinks — no post-training at all, just a bounded window plus the first few tokens kept permanently. The authors run it against post-trained linear-attention models across several LLMs and a spread of downstream tasks, including the two long-context retrieval benchmarks the linear-attention literature leans on, Needle-in-a-Haystack and BABILong.기준선은 싱크를 붙인 슬라이딩 윈도우 어텐션(SWA)이다. 학습 없이 여러 LLM·과제, 그리고 Needle-in-a-Haystack과 BABILong에서 선형 모델과 맞붙였다.
Results결과SWA with sinks performs as well as or better than the post-trained linear models across the models and tasks tested. On the long-context reasoning benchmarks the gap is not marginal: the paper reports SWA scoring 2 to 10 times higher than linear attention. SWA needs no post-training, is described as extremely fast, and keeps memory low.SWA는 전반적으로 선형 모델과 같거나 낫고, 장문맥 추론에서는 2~10배 높은 점수를 낸다. 빠르고 메모리도 적게 쓴다.
Summary요약The recommendation is blunt: to cut inference memory, switch to SWA rather than post-train a linear model. The authors allow that linear attention may still have promise, but suspect it would need training from scratch or far more extensive post-training merely to draw level with a baseline that costs nothing to adopt.메모리를 줄이려면 선형 모델을 사후 학습하지 말고 SWA로 바꾸라는 권고다. 선형 어텐션이 따라잡으려면 처음부터 학습해야 할 것으로 본다.

A Probabilistic Interpretation of KV Cache EvictionKV cachearXiv:2608.28293
arxiv.org/abs/2608.28293 →
Problem문제 정의KV eviction promises higher throughput for a negligible quality cost, and empirically it often delivers — but almost every method picks what to drop by a hand-built heuristic. The paper's objection is that the problem itself has never been stated formally, so there is no way to say what a good eviction rule is approximating or how far it falls short.KV 축출은 대부분 휴리스틱으로 버릴 항목을 고르고, 문제 자체가 형식적으로 정의된 적이 없다.
Method방법The authors formalize KV eviction and prove it computationally hard. Reframed probabilistically, it reduces to expectation estimation, which can be approximated by sampling — and once it is an estimation problem, correcting for the entries you already threw away becomes something you can do during decoding rather than an error you simply absorb.축출을 형식화해 계산적으로 어렵다는 것을 증명하고, 표본추출로 근사할 수 있는 기대값 추정 문제로 바꾼다. 그러면 버린 항목을 디코딩 중에 보정할 수 있다.
Results결과Seen through this lens, existing methods in the literature turn out to be zero-variance biased estimators, which means they can be adapted to support decode-time correction with little change. The probabilistic version plus that correction is reported as more robust across tasks than existing eviction methods, at competitive performance for the same compression budget.기존 방법은 분산 0인 편향 추정량이라 조금만 고치면 보정을 붙일 수 있다. 같은 압축 예산에서 과제 전반에 더 견고하다고 보고한다.
Summary요약The practical hook is the correction step, which the field had been ignoring: you are not obliged to pretend an evicted entry contributed nothing. For a serving stack this reframing matters more than any single eviction score, because it says where the remaining headroom is — in what you do after dropping, not only in what you drop.남은 여유는 무엇을 버리느냐보다 버린 뒤의 보정에 있다는 주장이다.

Parser States Already Know: Structure-Conditioned KV Persistence for Structured GenerationKV cachestructured generationarXiv:2608.28276
arxiv.org/abs/2608.28276 →
Problem문제 정의Agents that emit JSON, SQL or function calls are judged by whether the downstream action fires, and one wrong field is enough to break it. Constrained decoding already walks a grammar and knows exactly which tokens are a required field, an argument or a structural boundary — but KV compression throws that signal away and compresses by model-side importance alone, which is not the same thing as task-level risk.JSON·함수 호출은 필드 하나만 틀려도 깨진다. 제약 디코딩 파서는 중요한 토큰을 알고 있는데, KV 압축은 이 신호를 버리고 모델 쪽 중요도만 본다.
Method방법PASK (Parser-Aware Structural KV Persistence) turns parser transitions into layer-group-specific persistence decisions. Task-error sensitivity sets minimum protection floors — the KV entries a schema-critical decision cannot lose — while attention-output distortion allocates whatever capacity is left. An offline calibration stage compiles both signals into a persistence policy, so online the engine only does a lightweight structure-conditioned lookup.PASK는 파서 상태 전이를 층 그룹별 KV 잔류 결정으로 바꾼다. 과제 오류 민감도로 보호 하한을 정하고 남은 용량은 어텐션 출력 왜곡으로 배분하며, 정책은 오프라인에서 미리 컴파일한다.
Results결과At a total KV budget of 0.33 on Qwen3-4B, PASK beats the strongest compressed baseline by 17.39 percentage points averaged over eight BFCL non-live and Live subcategories. End to end in serving it reports up to 2.2x higher throughput and 3.3x lower TPOT while using 0.53x the peak GPU memory of full KV.Qwen3-4B, KV 예산 0.33에서 BFCL 여덟 하위 범주 평균이 최강 압축 기준선보다 17.39%p 높다. 서빙에서는 피크 메모리 0.53배로 처리량 최대 2.2배, TPOT 3.3배 개선을 보고한다.
Summary요약The appealing part is that the signal was free — the parser was already running to enforce validity, and its state doubles as a map of which tokens the task cannot afford to blur. For anyone serving tool-calling traffic, this is the rare compression policy that is aligned with the thing being measured rather than with perplexity.이미 돌고 있던 파서의 신호를 공짜로 쓴다. 퍼플렉시티가 아니라 도구 호출 성공에 맞춘 압축 정책이다.

H-Scale: Hessian-Guided Scale Refinement for NVFP4 Sub-Byte LLM InferencequantizationarXiv:2608.28113
arxiv.org/abs/2608.28113 →
Problem문제 정의NVIDIA's Blackwell parts support NVFP4 natively, and its micro-block design — groups as small as 16 weights — is good at capturing local distributions and isolating outliers. The catch is that every group needs its own scaling factor, which creates a large and very sensitive search space. Post-training quantization work has mostly polished the quantized weight values and left the scale-selection step alone.블랙웰의 NVFP4는 16개 단위 마이크로 블록마다 스케일이 필요해 탐색 공간이 크고 민감하다. 기존 PTQ는 가중치 값만 다듬고 스케일 선택은 건드리지 않았다.
Method방법H-Scale is a lightweight post-processing pass that refines per-group scales. Instead of minimizing plain weight reconstruction error, it picks hardware-valid group scales using a diagonal second-order proxy derived from calibration activations, so the objective is layer output rather than weight distance. It is designed as a drop-in replacement for RTN-style scale selection in existing NVFP4 pipelines.H-Scale은 보정 활성값의 대각 2차 근사로 층 출력 오차를 줄이는 그룹 스케일을 고르는 후처리다. 기존 RTN식 스케일 선택을 그대로 대체한다.
Results결과It requires only modest offline calibration and introduces strictly zero overhead at inference time. Under a fixed evaluation protocol on mainstream LLMs, H-Scale generally improves a broad range of NVFP4 baselines and brings several variants closer to the BF16 reference.오프라인 보정만 필요하고 추론 오버헤드는 0이다. 여러 NVFP4 기준선을 개선해 BF16에 더 가깝게 만든다.
Summary요약The interesting claim is about where the remaining accuracy lives in sub-byte formats: not in the rounded values but in the exponents you assign to each group of sixteen. Since the refinement happens offline and the served kernel is unchanged, this is about as cheap as an accuracy recovery gets on Blackwell.서브바이트 포맷의 남은 정확도는 값이 아니라 그룹 스케일에 있다는 주장이다. 커널은 그대로라 블랙웰에서 가장 싼 정확도 회복법에 속한다.

Speculative Probing: LLM Monitoring at Speculative-Decoding Costspeculative decodingarXiv:2608.28099
arxiv.org/abs/2608.28099 →
Problem문제 정의Classifying a generation while it is still being generated — for safety filtering, behavioural analysis or monitoring — currently forces a choice between fast and good. Hidden-state probes are cheap but read a single vector and cannot model interactions across positions; the accurate options are a dedicated guard model or pooling computation over every token's hidden state, and both are expensive.생성 중 분류(안전 필터링, 모니터링)는 빠름과 정확함 중 하나를 골라야 한다. 은닉 상태 프로브는 싸지만 약하고, 가드 모델이나 전체 토큰 풀링은 비싸다.
Method방법The observation is that recent LLMs already ship a speculative-decoding module, and it can be repurposed as a sequence classifier: append a trained soft prompt at the end of the target sequence and the draft module becomes the classifier head.
