Method방법HiLS starts from "naive block-sparse attention," which requires a full pass but yields a full-attention-derived chunk-selection pattern, and uses that as a target. It makes retrieval end-to-end learnable via a hierarchical factorization: attention mass is first allocated across retrieved chunks and then distributed among tokens within each chunk, avoiding the quadratic pass. Block selection thus becomes learnable under the language-model objective, so the model scores useful chunks higher and suppresses irrelevant ones.HiLS는 풀 어텐션에서 유도한 청크 선택 패턴("naive block-sparse attention")을 목표로 삼는다. 어텐션 질량을 먼저 청크들에, 다음으로 청크 안 토큰들에 나누는 계층적 인수분해로 이차 패스 없이 블록 선택을 LM 목적함수 아래에서 학습한다.

Problem문제 정의Disaggregated LLM serving runs prefill and decode on separate GPU pools. When prefill requests arrive in bursts, they queue on the prefill pool and inflate time-to-first-token (TTFT), even while decode GPUs have spare cycles. Existing disaggregated schedulers leave that decode-side headroom on the table.분리형 서빙에서 프리필 요청이 몰리면 프리필 풀에 큐가 쌓여 TTFT가 늘어난다. 디코드 GPU에 여유가 있어도 기존 스케줄러는 이를 쓰지 못한다.
Method방법A proactive prefill-deflecting scheduler lets decode nodes serve prefill phases as chunked-prefill steps interleaved with their decode batches. Soft Clamp (arXiv 2607.07050, submitted Jul 15) ↗Soft Clamp (arXiv 2607.07050, 7/15 제출) ↗
Problem문제 정의Agentic LLMs must decide when to call a tool versus answer directly. Multi-teacher on-policy distillation — one teacher specialized in tool calls, one in direct responses — is a natural training recipe, but the authors find it can shift the student toward over-calling in a way aggregate losses miss: tool-call samples do not receive more token exposure, and full-sequence divergence is not larger for the tool-call teacher.에이전트 LLM은 도구를 호출할지 직접 답할지 정해야 한다. 저자들은 멀티티처 온폴리시 증류(도구 호출 교사 1, 직접 응답 교사 1)가 총합 손실에는 드러나지 않는 방식으로 학생을 과호출로 몰아간다는 사실을 발견했다. 토큰 노출량이나 전시퀀스 발산 차이로는 설명되지 않는다.
Method방법They diagnose "behavior leverage imbalance": local token-level signals at mode-entry and structural positions — such as <tool_call> and function names — have disproportionate control over the whole generation mode. The fix is Soft Clamp, a per-token divergence calibration that dynamically compresses extreme token-level Jensen-Shannon divergence while preserving nonzero gradients, so ordinary tokens are untouched and only high-leverage extremes are limited.원인은 "행동 레버리지 불균형"이다. <tool_call>·함수명 같은 모드 진입 위치의 토큰 신호가 생성 모드 전체를 좌우한다. Soft Clamp는 극단적인 토큰 단위 JSD만 동적으로 압축하고 그래디언트는 0이 되지 않게 남긴다.
Results결과On APIGen-MT, Soft Clamp reduces over-calling from 13.7% to 9.0% relative to vanilla GKD while matching decision accuracy (89.2%). In a BFCL multi-turn diagnostic it lowers tool calls per turn (1.494→1.268), Loop@3 (14.8%→10.1%), and repeated same-calls (16.7%→11.1%), while raising the final-answer rate (89.6%→94.1%).APIGen-MT에서 바닐라 GKD 대비 과호출을 13.7%→9.0%로 줄이고 결정 정확도 89.2%를 유지했다. BFCL 멀티턴에서는 턴당 호출(1.494→1.268), Loop@3(14.8%→10.1%), 동일 호출 반복(16.7%→11.1%)이 줄고 최종 답변율은 89.6%→94.1%로 올랐다.

Problem문제 정의LLM agents are increasingly used for multi-step, stateful tool-use tasks, yet production reliability remains limited. Unlike static software repair, agent repair must recover dynamic trajectories whose early decisions propagate into later errors and external state changes. Existing remedies address only part of the problem: blind retry adds no diagnosis, outcome feedback says whether a run failed but not where or why, and self-reflection often lacks grounded evidence.LLM 에이전트는 다단계 상태 유지 작업에 쓰이지만 프로덕션 신뢰성은 아직 낮다. 맹목적 재시도는 진단이 없고, 결과 피드백은 어디서 왜 실패했는지 알려 주지 않으며, 자기 반성은 근거가 약하다.
