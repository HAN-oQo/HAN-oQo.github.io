Problem문제 정의Serving systems cache prompt KV state, but most front ends still re-tokenize the full request text on every call. The cost lands hardest on coding agents, which resubmit a long transcript after each small tool result, and reuse is hard because even a short append can change token boundaries near the end of the previous sequence.서빙 시스템은 KV 상태를 캐시하지만 프런트엔드는 매 호출마다 요청 전체를 다시 토큰화한다. 도구 결과마다 긴 트랜스크립트를 재제출하는 코딩 에이전트가 가장 손해를 보고, 짧은 추가만으로도 끝부분 토큰 경계가 바뀌어 재사용이 어렵다.
Method방법Measured across 153,951 calls from two agent ecosystems, the median call appends about 1.4K characters and only 1.0–3.6% of calls actually rebuild a sequence from scratch. TokTier는 세션별 토크나이저 상태를 유지해 추가분만 올바른 경계로 증분 토큰화한다.
Results결과By matching tokenization to how agents actually append, TokTier keeps prefix caches reusable across the overwhelming majority of turns rather than invalidating them on every small edit, removing redundant re-tokenization from the agentic serving hot path.대부분의 턴에서 프리픽스 캐시가 무효화되지 않아, 에이전트 서빙 핫패스의 중복 재토큰화가 사라진다.
Summary요약Keep per-session tokenizer state so an appended transcript is tokenized incrementally — most agent turns append ~1.4K chars, so exact stateful tokenization keeps the prefix cache valid instead of rebuilding it.에이전트는 주로 덧붙이기만 하므로, 정확한 상태 유지 토큰화로 프리픽스 캐시를 계속 살려 둘 수 있다.

Problem문제 정의KV-cache compression is essential for efficient long-context inference, but existing eviction methods permanently discard unselected tokens and remove their aggregate contribution to attention. Merging-based alternatives preserve more information but can perturb the retained keys and values that should stay exact.롱컨텍스트 추론에는 KV 캐시 압축이 필수지만, 축출 방식은 버린 토큰의 어텐션 기여를 통째로 잃는다. 병합 방식은 정보를 더 남기지만 그대로 둬야 할 키·값을 건드린다.
Method방법ResKV observes that the information dropped by eviction can be written as residual statistics in both the numerator and denominator of the softmax attention. Rather than keeping the evicted tokens, it reconstructs those aggregate residual contributions at attention time, so the fixed-budget cache approximates full attention without perturbing the exact keys and values it retains.축출로 잃는 정보는 소프트맥스 어텐션의 분자·분모 잔차 통계로 쓸 수 있다. ResKV는 이 잔차 기여를 어텐션 시점에 재구성해, 유지한 키·값은 건드리지 않고 완전 어텐션을 근사한다.
Results결과By restoring the omitted attention mass instead of throwing it away, ResKV closes much of the gap between hard eviction and full-cache attention at the same memory budget, targeting long-context settings where naïve eviction visibly degrades quality.같은 메모리 예산에서 강한 축출과 완전 캐시 사이 격차를 상당 부분 메운다. 단순 축출이 품질을 눈에 띄게 떨어뜨리는 롱컨텍스트가 대상이다.
Summary요약Write evicted tokens' lost attention as residual softmax numerator/denominator statistics and reconstruct them at attention time — recovering most of full-cache quality within a fixed KV budget.버린 토큰의 어텐션을 잔차 통계로 되살려, 고정 KV 예산으로 완전 캐시 품질에 가깝게 간다.
