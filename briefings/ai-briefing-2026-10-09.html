Problem문제 정의Parallel and semi-autoregressive drafters propose a whole block in one forward pass, but where each decoding round starts depends on how many tokens earlier rounds accepted. Existing training objectives use block-local surrogates that ignore this cross-round coupling.병렬·준자기회귀 드래프터는 한 번의 순전파로 블록 전체를 제안하지만, 각 디코딩 라운드의 시작 위치는 앞선 라운드가 몇 토큰을 수락했는지에 달려 있다. 기존 학습 목적함수는 이 라운드 간 결합을 무시하는 블록 국소 대리 지표를 쓴다.

Method방법The authors model speculative decoding as a Markov reward process, which yields the Expected Decoding Rounds (EDR) objective that equals the expected number of rounds and adds no hyperparameters. They derive an exact temporal-difference gradient from target-model rollouts and an exact offline round-count evaluator.저자들은 추측 디코딩을 마르코프 보상 과정으로 모델링해, 기대 라운드 수와 정확히 일치하고 하이퍼파라미터가 없는 EDR 목적함수를 얻는다. 타깃 모델 롤아웃에서 정확한 시간차 그래디언트와 정확한 오프라인 라운드 수 평가기도 유도한다.

Results결과Finetuning two state-of-the-art drafters, DSpark and DFly, with EDR consistently improves mean accepted length and beats existing training objectives across nine benchmarks spanning math reasoning, code generation and chat.최신 드래프터 DSpark와 DFly를 EDR로 미세조정하면 수학 추론, 코드 생성, 대화를 아우르는 9개 벤치마크에서 평균 수락 길이가 일관되게 늘고 기존 학습 목적함수를 앞선다.

Problem문제 정의Looped Transformers reuse shared blocks over several loops, so KV cache memory grows with the number of loops and limits batch size and throughput. Existing KV quantization loses much accuracy at aggressive low precision.루프형 트랜스포머는 공유 블록을 여러 루프에 걸쳐 반복 적용하므로 KV 캐시 메모리가 루프 수에 비례해 늘어 배치 크기와 처리량을 제한한다. 기존 KV 양자화는 공격적인 저정밀도에서 정확도를 크게 잃는다.

Method방법KV states across loops are highly similar, so ResidualQuant keeps the final-loop KV states as a reference and stores the other loops as low-precision residuals. It adds least-square scaling, rotations on the residuals and loop-wise mixed precision to reach INT2 with efficient reconstruction.루프 간 KV 상태가 매우 비슷하다는 점을 이용해, ResidualQuant는 마지막 루프의 KV를 기준으로 두고 나머지 루프는 저정밀 잔차로 저장한다. 최소제곱 스케일링, 잔차 회전, 루프별 혼합 정밀도로 INT2까지 효율적 복원을 가능하게 한다.

Results결과The method retains accuracy close to BF16 under mixed precision while cutting theoretical KV storage by 80.7%, with up to 13.0% higher accuracy than rotation-based quantization at the same budget. Problem문제 정의Sparse attention often retrieves the heaviest keys with maximum inner product search (MIPS). The open question is how many keys must be retrieved from a black-box MIPS oracle for an epsilon-accurate attention estimate.희소 어텐션은 최대 내적 탐색(MIPS)으로 가장 큰 키를 가져오는 경우가 많다. 블랙박스 MIPS 오라클에서 epsilon 정확도의 어텐션 추정을 얻으려면 키를 몇 개 가져와야 하는지가 미해결 질문이다.

Method방법The paper unifies prior approaches under priority sampling. Results결과Allowing augmentation of keys and queries bypasses the lower bounds: a simple priority-sampling estimator with one MIPS index and O(1/epsilon^2) retrieved keys exists. LLM 추론에 통합하면 top-k와 샘플링 기준선을 앞서고 긴 컨텍스트로 갈수록 유리하게 확장된다.
