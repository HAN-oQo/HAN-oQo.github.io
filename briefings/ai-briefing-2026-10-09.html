Training Parallel Speculative Draft Models by Directly Minimizing Expected Decoding Roundsspeculative decodingtrainingarXiv:2610.10411
arxiv.org/abs/2610.10411 →

Problem문제 정의Parallel and semi-autoregressive drafters propose a whole block in one forward pass, but where each decoding round starts depends on how many tokens earlier rounds accepted. Existing training objectives use block-local surrogates that ignore this cross-round coupling.병렬·준자기회귀 드래프터는 한 번의 순전파로 블록 전체를 제안하지만, 각 디코딩 라운드의 시작 위치는 앞선 라운드가 몇 토큰을 수락했는지에 달려 있다. 기존 학습 목적함수는 이 라운드 간 결합을 무시하는 블록 국소 대리 지표를 쓴다.

Method방법The authors model speculative decoding as a Markov reward process, which yields the Expected Decoding Rounds (EDR) objective that equals the expected number of rounds and adds no hyperparameters. They derive an exact temporal-difference gradient from target-model rollouts and an exact offline round-count evaluator.추측 디코딩을 마르코프 보상 과정으로 보고, 기대 라운드 수와 정확히 같으면서 하이퍼파라미터가 없는 EDR 목적함수를 얻는다. 타깃 모델 롤아웃으로 정확한 시간차 그래디언트와 오프라인 라운드 수 평가기도 유도한다.

Results결과Finetuning two state-of-the-art drafters, DSpark and DFly, with EDR consistently improves mean accepted length and beats existing training objectives across nine benchmarks spanning math reasoning, code generation and chat.최신 드래프터 DSpark와 DFly를 EDR로 미세조정하면 수학 추론, 코드 생성, 대화를 아우르는 9개 벤치마크에서 평균 수락 길이가 일관되게 늘고 기존 학습 목적함수를 앞선다.

Summary요약Training a block drafter against the true expected number of decoding rounds, instead of per-block surrogates, directly optimizes end-to-end speculative decoding efficiency.블록별 대리 지표 대신 실제 기대 라운드 수로 학습하면 추측 디코딩의 종단 효율을 직접 최적화한다.

ResidualQuant: KV Cache Quantization for Looped Transformers with 2-Bit ResidualsKV cachequantizationarXiv:2610.10381
arxiv.org/abs/2610.10381 →

Problem문제 정의Looped Transformers reuse shared blocks over several loops, so KV cache memory grows with the number of loops and limits batch size and throughput. Existing KV quantization loses much accuracy at aggressive low precision.루프형 트랜스포머는 공유 블록을 여러 번 반복하므로 KV 캐시가 루프 수만큼 늘어 배치 크기와 처리량을 묶는다. 기존 KV 양자화는 아주 낮은 정밀도에서 정확도를 크게 잃는다.

Method방법KV states across loops are highly similar, so ResidualQuant keeps the final-loop KV states as a reference and stores the other loops as low-precision residuals. It adds least-square scaling, rotations on the residuals and loop-wise mixed precision to reach INT2 with efficient reconstruction.루프 간 KV가 매우 비슷하므로, ResidualQuant는 마지막 루프의 KV를 기준으로 두고 나머지는 저정밀 잔차로 저장한다. 최소제곱 스케일링, 잔차 회전, 루프별 혼합 정밀도를 더해 INT2에서도 효율적으로 복원한다.

Results결과The method retains accuracy close to BF16 under mixed precision while cutting theoretical KV storage by 80.7%, with up to 13.0% higher accuracy than rotation-based quantization at the same budget. On an RTX 5090, fixed-batch decode throughput rises up to 2.73x and peak throughput up to 4.15x thanks to 2x larger batches.혼합 정밀도에서 BF16에 가까운 정확도를 유지하면서 이론적 KV 저장량을 80.7% 줄이며, 같은 예산에서 회전 기반 양자화보다 정확도가 최대 13.0% 높다. RTX 5090에서 고정 배치 디코드 처리량은 최대 2.73배, 배치가 2배 커져 최대 처리량은 최대 4.15배 오른다.

Summary요약Exploiting cross-loop similarity turns a memory-bound looped model into one that fits larger batches and decodes faster.루프 간 유사성을 쓰면 메모리에 묶인 루프형 모델이 더 큰 배치로 더 빠르게 디코딩한다.

Attention via Black-Box Vector Searchsparse attentiontheoryarXiv:2610.10135
arxiv.org/abs/2610.10135 →

Problem문제 정의Sparse attention often retrieves the heaviest keys with maximum inner product search (MIPS). The open question is how many keys must be retrieved from a black-box MIPS oracle for an epsilon-accurate attention estimate.희소 어텐션은 흔히 최대 내적 탐색(MIPS)으로 가장 큰 키를 가져온다. 블랙박스 MIPS 오라클에서 키를 몇 개 가져와야 epsilon 정확도의 어텐션 추정이 되는지는 아직 답이 없다.

Method방법The paper unifies prior approaches under priority sampling. With one MIPS index, Theta(sqrt(n)/epsilon) retrieved keys are both sufficient and necessary; with Theta(log n) indices, O(log n + 1/epsilon^2) keys suffice, and the two regimes trade off smoothly.논문은 기존 접근을 우선순위 샘플링으로 통합한다. 인덱스가 하나면 가져오는 키 Theta(sqrt(n)/epsilon)개가 충분하고 필요하며, Theta(log n)개 인덱스면 O(log n + 1/epsilon^2)개로 충분하고 둘 사이에서 매끄럽게 절충된다.

Results결과Allowing augmentation of keys and queries bypasses the lower bounds: a simple priority-sampling estimator with one MIPS index and O(1/epsilon^2) retrieved keys exists. Integrated into LLM inference, the algorithms outperform top-k and sampling baselines and scale favorably to long contexts.키와 질의의 증강을 허용하면 하한을 우회해 MIPS 인덱스 하나와 O(1/epsilon^2)개 키만으로 되는 단순한 추정기가 존재한다. LLM 추론에 통합하면 top-k와 샘플링 기준선을 앞서고 긴 컨텍스트로 갈수록 유리하게 확장된다.

Summary요약The work gives retrieval-count bounds for MIPS-based sparse attention and a practical estimator that beats top-k at long context.MIPS 기반 희소 어텐션에 필요한 검색 키 수의 한계를 밝히고, 긴 컨텍스트에서 top-k를 앞서는 실용 추정기를 내놓는다.

Dual-QK: Sharp Queries and Flat Keys for Prunable 2-bit KV CachesKV cachequantizationarXiv:2610.09827
arxiv.org/abs/2610.09827 →

Problem문제 정의Low-bit KV quantization and query-channel pruning both cut cache traffic. Rotation-based quantization spreads key outliers but also disperses query energy, which weakens the separation between channels to keep and channels to prune.저비트 KV 양자화와 질의 채널 가지치기는 모두 캐시 트래픽을 줄인다. 회전 기반 양자화는 키 이상치를 분산하지만 질의 에너지도 흩어져 남길 채널과 쳐낼 채널의 구분이 약해진다.

Method방법Dual-QK applies paired non-orthogonal query and key transforms calibrated on query and key statistics. Partial key whitening balances key scales for INT2, a query-aligned basis concentrates query energy for dynamic channel pruning, and channel-0 protection plus bucket-relative RoPE hold accuracy over long contexts.Dual-QK는 질의·키 통계로 보정한 비직교 질의/키 변환 쌍을 쓴다. 부분 키 화이트닝은 INT2용 키 스케일을 맞추고, 질의 정렬 기저는 동적 채널 가지치기를 위해 질의 에너지를 모으며, 채널 0 보호와 버킷 상대 RoPE가 긴 컨텍스트 정확도를 지킨다.

Results결과On four models across five generative benchmarks and long-context retrieval, accuracy beats OSCAR on most tasks at 40% query-channel sparsity. At 128K context it gives 6.8x KV compression, an estimated 8.3x less KV read volume than unpruned BF16, and up to 3.75x decoding throughput in an SGLang implementation.4개 모델의 5개 생성 벤치마크와 장문 검색에서 질의 채널 희소도 40% 조건에 대부분의 과제에서 OSCAR보다 정확하다. 128K 컨텍스트에서 KV 6.8배 압축, 가지치기 없는 BF16 대비 KV 읽기량 약 8.3배 감소, SGLang 구현에서 디코딩 처리량 최대 3.75배를 얻는다.

Summary요약Decoupling how queries and keys are transformed lets 2-bit keys and query-channel pruning work together instead of fighting.질의와 키의 변환을 분리하면 2비트 키와 질의 채널 가지치기가 충돌 없이 함께 작동한다.

arxiv.org/abs/2610.09778 →
