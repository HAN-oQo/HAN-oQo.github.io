Problem문제 정의Speculative decoding drafts several tokens and verifies them in parallel. Block-parallel drafters like DFlash predict a whole block in one pass but lack intra-block causal conditioning; methods that add that causality (Domino, DSpark) require training the drafter from scratch, which is costly and inflexible.추측 디코딩은 여러 토큰을 초안 작성해 병렬 검증한다. DFlash 같은 블록 병렬 드래프터는 한 번에 블록 전체를 예측하지만 블록 내 인과 조건화가 없고, 그 인과성을 더하는 방법(Domino·DSpark)은 드래프터를 처음부터 학습해야 해 비싸고 유연성이 낮다.
Method방법DeLS-Spec decouples long and short context. GitLost — tricking a GitHub AI agent into leaking private repositories Jul 9

Noma Labs disclosed GitLost, an indirect-prompt-injection flaw in GitHub's new Agentic Workflows: an unauthenticated attacker who merely opens a crafted issue in a public repo could steer the agent into exfiltrating a private repo's contents into a publicly-visible issue comment. Vulnerable workflows fire on issues.assigned, read the issue title/body, respond with add-comment, and hold read access across public and private repos — so no code, credentials, or access were needed.
