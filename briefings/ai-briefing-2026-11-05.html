Problem문제 정의Sparse attention limits what each query reads, yet long-context serving still needs large GPU memory because offloading systems keep every indexer key on GPU, and prefill’s temporary memory can delay admission.희소 어텐션은 쿼리가 읽는 범위를 줄이지만, 오프로딩 시스템이 모든 인덱서 키를 GPU에 두고 프리필의 임시 메모리가 요청 수락을 지연시켜 긴 컨텍스트 서빙은 여전히 메모리를 많이 쓴다.

Method방법LeanSparse streams layer histories through two reusable GPU buffers during prefill, overlapping the next layer’s load with compute.
