4-4. Learning points of this step4-4. 배운 점

  1. LB assumes statelessLB 는 stateless 를 가정한다: round-robin alternates blindly, so turn 1 and turn 2 of one conversation can land on different instances. No KV cache hits.: round-robin 은 요청을 기계적으로 번갈아 보낸다. 같은 대화의 turn 1 과 turn 2 가 다른 instance 로 갈 수 있어 KV cache hit 이 없다.
  2. In real production, this is a problemproduction 에선 이게 문제다: requests with the same system prompt should share the prefix KV cache. llm-d's prefix-cache-aware scorer addresses exactly this (§8).: 같은 system prompt 로 시작하는 요청은 prefix KV cache 를 공유해야 throughput 이 오른다. llm-d 의 prefix-cache-aware scorer 가 바로 이 문제를 푼다 (§8).
