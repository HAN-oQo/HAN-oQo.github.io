사이트 AI 위젯 + 내 Claude 봇 — 배포·확인·실행 런북

작성일: 2026-06-15 · han-oqo.github.io 의 "✦ Ask AI" 위젯과, 구독으로 도는 로컬 Claude 봇(Agent SDK)을 어떻게 깔았고 / 정보를 어디서 보고 / Claude에게 자동으로 시키고 / 수동으로 띄우는지 전부.

한 줄 요약. 모든 페이지 우하단에 "✦ Ask AI" 위젯이 자동으로 붙는다(배포 시 CI가 주입). 위젯은 BYO-key 멀티 프로바이더(Groq 무료 / Claude / OpenAI / Gemini) + "내 Claude 봇" 모드를 지원한다. 내 봇은 Claude Agent SDK로 구독 로그인(setup-token)을 써서 돈다 — API 결제 없음. 로컬에선 편집 모드(채팅으로 HTML에 메모 추가/수정), 라이브에선 읽기전용(cloudflared https 터널). 편집·push는 나만 가능(localhost 바인드 + 내 git 자격증명).

2. 어떻게 배포했나

2-1. 위젯 — 모든 페이지에 자동 주입

assets/ask.js가 위젯 본체다(플로팅 버튼 + 패널, 현재 페이지 .wrap 본문을 컨텍스트로 질문, EN/KO, 테마 토큰). 대부분 페이지는 assets/i18n.js가 같은 폴더의 ask.js를 자동 로드한다. 빠지는 페이지(briefings 등)까지 무조건 붙이려고, 배포 워크플로의 deploy 잡에서 업로드 직전 주입 스크립트를 돌린다:

# .github/workflows/pages.yml (deploy 잡)
- uses: actions/checkout@v4
- name: Inject Ask-AI widget into every page
  run: python3 tools/inject_ask_widget.py   # 소스 미수정, 배포 artifact에만 주입
- uses: actions/configure-pages@v5
- uses: actions/upload-pages-artifact@v3

tools/inject_ask_widget.py는 모든 *.html의 </body> 앞에 ask.js 로더를 넣는다(이미 ask.js/i18n.js 있으면·StatiCrypt 잠금·*.unencrypted 은 건너뜀). 그래서 누가 어디서 HTML을 만들어 push해도 라이브엔 위젯이 무조건 붙는다.

2-2. 위젯 — 프로바이더

BYO-key(키는 브라우저 localStorage, 해당 사로만 전송). 모델은 프로바이더별 드롭다운. 기본은 Groq(무료).

프로바이더특징웹검색
Groq (기본)무료 티어, 카드 불필요 (Llama)—
Claude / OpenAI / Gemini각 사 콘솔 키(종량/무료티어)✅ 내장 검색
My Claude bot내 로컬 봇(구독)으로 호출 — 결제 X✅ (WebSearch)
ProxyCloudflare Worker 등 내 서버가 키 보관✅

2-3. 내 Claude 봇 — 구독으로 (API 결제 없음)

assets/ask-bot-server/server.py는 Claude Agent SDK(claude-agent-sdk)를 감싼 작은 HTTP 서버(/ask)다. 로컬 claude 로그인(=claude setup-token)을 그대로 써서 구독으로 돈다(별도 ANTHROPIC_API_KEY 불필요). ce_slack_bot과 같은 공식 SDK 경로 — raw API에 토큰을 꽂는 우회가 아니다. 옵션: WebSearch, CORS, ACCESS_TOKEN 게이트, 편집 모드.

2-4. 라이브에서 쓰려면 — https 터널

라이브 사이트는 https라 http://127.0.0.1(봇)을 직접 못 부른다(mixed-content 차단). 그래서 cloudflared 터널로 봇 앞에 공개 https URL을 씌운다. 보안상 터널 모드는 읽기전용 강제(편집 OFF).

3. 정보 보는 법 (어디 떠있나 · URL · 토큰)

전부 내 맥에서 tmux 안 프로세스로 돈다. 직접 확인:

# 1) 어떤 봇이 떠있나 (세션)
tmux ls                       # askbot(로컬편집) / askbot-pub(공개읽기)

# 2) 연결정보 — launch.sh가 매 실행마다 저장
cat ~/.askbot/askbot.txt      # 로컬 편집 봇: URL + 토큰
cat ~/.askbot/askbot-pub.txt  # 공개 터널 봇: URL + 토큰

# 3) 포트 · 프로세스
lsof -nP -iTCP -sTCP:LISTEN | grep -E ':8787|:8788|:8000'
pgrep -fl 'server.py|cloudflared|http.server'

# 4) 토큰 — 실행 중 프로세스 env 에서 직접
ps eww $(pgrep -f 'ask-bot-server/server.py') | tr ' ' '\n' | grep ACCESS_TOKEN=

# 5) 터널 URL — cloudflared 로그에서
grep -oE 'https://[a-z0-9-]+\.trycloudflare\.com' /tmp/askbot-tunnel.log | tail -1
tmux attach -t askbot-pub     # 라이브로 보기 (나가기: Ctrl-b 그다음 d)
토큰은 레포에 없다. ~/.askbot/*.txt(홈)와 실행 프로세스 env 에만 있다. 터널 URL은 일회성(재시작마다 바뀜) — 저장 파일이 항상 최신값.

4. 자동 — Claude에게 시키는 법

레포에서 Claude Code를 열고 자연어로 시키면 된다(아래는 말 → Claude가 실행하는 명령):

로컬 편집 봇 띄우기

로컬 편집용 ask-bot 띄워줘

SKIP_TOKEN=1 PYTHON=~/ask-bot-venv/bin/python bash assets/ask-bot-server/launch.sh
# → ~/.askbot/askbot.txt 에 URL/토큰 저장, 프리뷰 http://localhost:8000

라이브용(공개 읽기전용) 터널 봇 띄우기

라이브에서 쓰게 ask-bot 터널로 띄워줘

TUNNEL=1 PORT=8788 TMUX_SESSION=askbot-pub SKIP_TOKEN=1 \
  PYTHON=~/ask-bot-venv/bin/python bash assets/ask-bot-server/launch.sh
# → 공개 https URL 출력 + ~/.askbot/askbot-pub.txt

정보 확인 / 끄기

ask-bot 정보(URL·토큰) 알려줘 / ask-bot 꺼줘

cat ~/.askbot/*.txt
tmux kill-session -t askbot ; tmux kill-session -t askbot-pub
왜 Claude가 해도 안전한가. Claude Code도 결국 위 셸 명령을 내 맥에서, 내 자격증명으로 실행할 뿐이다. 새 권한을 만들지 않는다 — 편집/push 권한은 여전히 내 GitHub 자격증명에 묶여 있다(§6).

5. 수동 — 직접 띄우는 법

최초 1회 준비

# claude CLI 로그인(구독) — 이미 쓰고 있으면 생략
npm i -g @anthropic-ai/claude-code && claude        # 또는: claude setup-token

# 봇 의존성 (venv 권장)
python3 -m venv ~/ask-bot-venv
~/ask-bot-venv/bin/python -m pip install claude-agent-sdk aiohttp

# (라이브 터널 쓸 거면) cloudflared
brew install cloudflared
다른 맥(새 머신)에서 처음 띄울 때. 위 준비에 두 가지만 더:
① 레포 클론 — git clone https://github.com/HAN-oQo/HAN-oQo.github.io.git && cd HAN-oQo.github.io
② 봇은 그 맥의 claude 구독으로 돈다 → 그 맥에서 claude 로그인 필수(SKIP_TOKEN 없이 실행하면 setup-token 브라우저 인증 1회).
③ 편집 모드로 push까지 하려면 그 맥에 GitHub push 자격증명이 있어야 한다(이 레포는 gh 토큰 credential helper). 없으면 봇이 commit은 해도 push는 실패 → 그 맥에서 gh auth login. push 권한이 없으면 그 맥에선 "로컬 편집·프리뷰"까지만 가능하고 라이브 반영은 안 된다.
그 뒤는 이 맥과 동일: SKIP_TOKEN=1 PYTHON=~/ask-bot-venv/bin/python bash assets/ask-bot-server/launch.sh (또는 TUNNEL=1 …). 정보는 cat ~/.askbot/*.txt.

A. 로컬 편집 모드 (나만 · localhost)

cd /path/to/inference-study
python3 -m http.server 8000 &                       # 사이트 프리뷰
ALLOW_EDITS=1 ACCESS_TOKEN="비밀" REPO_DIR="$PWD" \
  ~/ask-bot-venv/bin/python assets/ask-bot-server/server.py   # :8787 (127.0.0.1)
# 위젯 ⚙: Provider=My Claude bot, URL=http://127.0.0.1:8787/ask, 토큰=비밀, 편집모드 ✅
# → 프리뷰(http://localhost:8000)에서 "이 페이지에 ~ 메모 추가해줘"

B. 라이브 읽기전용 (https 터널)

ALLOW_EDITS=0 ACCESS_TOKEN="비밀2" ALLOW_ORIGIN="https://han-oqo.github.io" PORT=8788 \
  ~/ask-bot-venv/bin/python assets/ask-bot-server/server.py &
cloudflared tunnel --url http://localhost:8788       # → https://xxxx.trycloudflare.com
# 위젯 ⚙(라이브 사이트): URL=https://xxxx.trycloudflare.com/ask, 토큰=비밀2

※ launch.sh가 위 A/B를 tmux로 한 번에 해주는 래퍼다(§4).

6. 보안 모델 (왜 나만 가능한가)

  • 편집 봇은 127.0.0.1에만 바인딩. 남의 브라우저에서 127.0.0.1:8787은 그 사람 PC라 내 봇엔 못 닿는다. 서버는 편집 모드인데 외부 주소로 띄우려 하면 기동 거부(FORCE_REMOTE_EDIT 예외).
  • URL·토큰은 내 브라우저 localStorage·홈 디렉터리에만. 방문자는 기본 Groq라 봇 존재 자체를 모른다.
  • 실제 잠금 = GitHub push 권한. 봇은 그냥 내 맥에서 git을 호출할 뿐, push는 내 자격증명이 있어야 통과한다. 남이 레포를 클론해 봇을 띄워도 자기 fork에만 영향, 내 사이트엔 push 불가.
  • 터널(공개)은 읽기전용 강제. 공개 https에 파일편집+셸+git 봇을 노출하면 RCE라서, 터널 모드는 편집 OFF.
공개 터널의 현실 — 솔직히. askbot-pub 터널은 인터넷에서 접근 가능하다. 그 URL과 ACCESS_TOKEN을 둘 다 아는 사람은 누구나 호출할 수 있다 — 즉 내 구독을 소모해 Q&A를 시킬 수 있다(편집·push는 불가, 읽기전용이라 피해는 "쿼터 소모 + 임의 질문"으로 한정). 유일한 잠금은 토큰이다. ALLOW_ORIGIN(CORS)은 브라우저의 타 출처 요청만 막을 뿐 curl·스크립트는 못 막는다 — 보안 경계가 아니다. URL은 랜덤·일회성이라 추측은 어렵지만 비밀급은 아니다(로그로 샐 수 있음).
  • 잠그는 법. ① 안 쓸 땐 tmux kill-session -t askbot-pub 로 끈다(공개 노출 0). ② 회수하려면 터널 재시작(새 URL) + 새 ACCESS_TOKEN. ③ 진짜 인증이 필요하면 named Cloudflare Tunnel + Cloudflare Access(로그인) 를 앞에 둔다. ④ 외부 접근이 아예 싫으면 로컬 봇(localhost)만 쓰고 라이브에선 Groq/본인 키 사용.
  • 라이브 https → 로컬 http 봇은 mixed-content로 차단. 그래서 라이브는 터널(https), 편집은 로컬(http localhost).
하지 않는 것. claude setup-token의 OAuth 토큰을 raw API에 직접 꽂는 우회(=Claude Code인 척 위장)는 약관 밖이라 구현하지 않았다. 구독은 공식 Agent SDK 경로로만 쓴다.

흔한 문제

  • "Unexpected token '<'" → URL이 틀림. 정확히 http://127.0.0.1:8787/ask (//와 /ask 필수).
  • 라이브에서 봇 연결 안 됨 → mixed-content. 로컬 프리뷰에서 쓰거나 터널(https) 사용.
  • 편집 모드가 라이브에서 안 됨 → 의도된 동작(터널=읽기전용).
  • Gemini limit: 0 → 그 계정/지역 무료티어 미지원. Groq 무료 또는 결제.
