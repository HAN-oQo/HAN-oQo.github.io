10-3. What if PUT (sync)?10-3. 만약 PUT (sync) 였다면?

P would block until send completes. In concurrent scenarios, the next prefill can't start until the previous one finishes. The 3-parallel run of this experiment (1.5s) could degrade to 5-6s.P 가 send 끝까지 block. concurrent 시나리오에서 한 prefill 이 끝날 때까지 다음 prefill 시작 못 함. 본 실험의 3 parallel (1.5s) 이 5-6s 수준으로 느려질 가능성.

The reason PR #18242 set PUT_ASYNC as the default is for concurrent throughput. But PUT_ASYNC may overflow the queue (if P's producer rate outpaces the slower NCCL transfer).PR #18242 가 PUT_ASYNC 를 default 로 설정한 이유 — concurrent throughput 위해. 단 PUT_ASYNC 는 queue overflow 가능성 (queue 가 P 의 producer 속도보다 느린 NCCL transfer 따라잡지 못하면).
