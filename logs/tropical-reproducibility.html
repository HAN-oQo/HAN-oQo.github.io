5Results recap결과 요약

Full tables and charts are on the per-phase pages. The one-paragraph story: across single-instance and 4× scale-out, this 7B / ShareGPT / MI250 setup is purely queuing/TTFT-bound — TPOT never broke (p90 ~17ms vs a 74ms SLO, even at 40 rps and even with 1024-token outputs). The prefill-budget knob (Phase 2) did not recover TTFT — confirming Tropical's gain is architectural (dedicated prefill workers + slack routing across heterogeneous workers, needing the Path-① KV handoff), not a tuning trick. The baselines positively identify the operating point where a real toggle should win: idle decode slack + a drowning prefill queue. 전체 표·차트는 Phase별 페이지에. 한 문단 요약: 단일 인스턴스와 4× 스케일아웃 모두에서 이 7B / ShareGPT / MI250 구성은 순수 큐잉/TTFT-bound — TPOT가 안 깨졌다(40 rps, 1024-토큰 출력에서도 p90 ~17ms vs SLO 74ms). prefill 예산 knob(Phase 2)은 TTFT를 회복하지 못함 — Tropical의 이득이 아키텍처(전용 prefill 워커 + 이종 워커 slack 라우팅, Path-① KV 핸드오프 필요)이지 튜닝 트릭이 아님을 확인. 베이스라인은 진짜 토글이 이겨야 할 동작점을 짚어냈다: 유휴 decode slack + 익사하는 prefill 큐.

~/tropical-bench/serve/serve_vllm_rocm.sh launch ONE vLLM-ROCm instance (eager|chunked|prefill|decode)vLLM-ROCm 인스턴스 1개 기동
#!/usr/bin/env bash
# Launch ONE vLLM-ROCm instance for a Tropical Phase-0 baseline (Docker-only).
#   up   — start container, wait for /health
#   down — remove this container
#   down-all — remove every trop-* container (server hygiene)
#
# Config via env (defaults shown):
#   MODEL=Qwen/Qwen2.5-1.5B-Instruct  SERVED_NAME=$MODEL
#   TP=2  GCDS=0,1  PORT=8000  MODE=chunked|eager|prefill|decode
#   IMAGE=vllm-022-rocm:latest  NAME=trop-$MODE-$PORT  MAX_BATCHED=2048
#   KV_CONNECTOR=  (disagg only; ⚠ NIXL is NVIDIA-only on ROCm — pick a connector that works)
set -euo pipefail

ACTION="${1:-up}"
MODEL="${MODEL:-Qwen/Qwen2.5-1.5B-Instruct}"
SERVED_NAME="${SERVED_NAME:-$MODEL}"
TP="${TP:-2}"
GCDS="${GCDS:-0,1}"
PORT="${PORT:-8000}"
MODE="${MODE:-chunked}"
IMAGE="${IMAGE:-vllm-022-rocm:latest}"
NAME="${NAME:-trop-${MODE}-${PORT}}"
MAX_BATCHED="${MAX_BATCHED:-2048}"
KV_CONNECTOR="${KV_CONNECTOR:-}"

case "$ACTION" in
  down)     docker rm -f "$NAME" 2>/dev/null && echo "removed $NAME" || echo "no $NAME"; exit 0 ;;
  down-all) docker ps -aq --filter "name=trop-" | xargs -r docker rm -f; echo "removed all trop-*"; exit 0 ;;
esac

# ---- mode → vLLM flags ----
MODE_FLAGS=""
case "$MODE" in
  chunked) MODE_FLAGS="--enable-chunked-prefill --max-num-batched-tokens ${MAX_BATCHED}" ;;
  eager)   # disable chunked prefill (this vLLM uses --no-enable-chunked-prefill, not =False).
           # max-num-batched-tokens >= max_model_len so a long prefill isn't forced to chunk.
           # NOTE: vLLM v1 may still force chunking on; verify in startup log.
           MODE_FLAGS="--no-enable-chunked-prefill --max-num-batched-tokens 32768" ;;
  prefill) [ -z "$KV_CONNECTOR" ] && echo "⚠ MODE=prefill needs KV_CONNECTOR set" >&2
           MODE_FLAGS="--kv-transfer-config {\"kv_connector\":\"${KV_CONNECTOR}\",\"kv_role\":\"kv_producer\"}" ;;
  decode)  [ -z "$KV_CONNECTOR" ] && echo "⚠ MODE=decode needs KV_CONNECTOR set" >&2
           MODE_FLAGS="--kv-transfer-config {\"kv_connector\":\"${KV_CONNECTOR}\",\"kv_role\":\"kv_consumer\"}" ;;
  *) echo "unknown MODE=$MODE" >&2; exit 2 ;;
esac

echo "[up] $NAME  model=$MODEL  TP=$TP  GCDS=$GCDS  port=$PORT  mode=$MODE  image=$IMAGE"
docker rm -f "$NAME" >/dev/null 2>&1 || true

# Override the entrypoint to `vllm` for BOTH images: vllm-022-rocm has
# ENTRYPOINT=[vllm serve] (would mangle a python cmd), rocm/vllm has none.
# `vllm serve <model> [opts]` is the portable invocation.
docker run -d --name "$NAME" \
  --device /dev/kfd --device /dev/dri \
  --group-add video --ipc=host --shm-size 16g \
  --cap-add SYS_PTRACE --security-opt seccomp=unconfined \
  -e HIP_VISIBLE_DEVICES="$GCDS" \
  -e VLLM_ROCM_USE_AITER=0 \
  -v "$HOME/.cache/huggingface:/root/.cache/huggingface" \
  -p "${PORT}:8000" \
  --entrypoint vllm \
  "$IMAGE" \
  serve "$MODEL" --served-model-name "$SERVED_NAME" \
    --tensor-parallel-size "$TP" --port 8000 \
    $MODE_FLAGS >/dev/null

echo -n "[up] waiting for /health "
for i in $(seq 1 360); do
  if curl -fsS "http://localhost:${PORT}/health" >/dev/null 2>&1; then
    echo " ready (${i}s)"; exit 0
  fi
  # surface a crash early instead of waiting the full timeout
  if ! docker ps -q --filter "name=^${NAME}$" | grep -q .; then
    echo " CONTAINER EXITED"; echo "---- last logs ----"; docker logs --tail 40 "$NAME" 2>&1 || true; exit 1
  fi
  echo -n "."; sleep 1
done
echo " TIMEOUT"; docker logs --tail 40 "$NAME" 2>&1 || true; exit 1

#!/usr/bin/env bash
# Phase 0.5: bring up a 4-worker pool (each TP=2 on a GCD pair) + InFaaS dispatcher
# on :8000. Mirrors the paper's "4 workers, TP=2, InFaaS dispatch" setup.
#   MODE=eager|chunked  MODEL=Qwen/Qwen2.5-7B-Instruct  IMAGE=vllm-022-rocm:latest
set -euo pipefail
cd "$(dirname "$0")/.."

MODE="${MODE:-eager}"
MODEL="${MODEL:-Qwen/Qwen2.5-7B-Instruct}"
IMAGE="${IMAGE:-vllm-022-rocm:latest}"
PAIRS=("0,1" "2,3" "4,5" "6,7"); PORTS=(8001 8002 8003 8004)

echo "[pool] launching 4× $MODE workers (TP=2) — model=$MODEL"
pids=()
for i in 0 1 2 3; do
  ( MODE="$MODE" MODEL="$MODEL" TP=2 GCDS="${PAIRS[$i]}" PORT="${PORTS[$i]}" \
      NAME="trop-pool-${MODE}-${PORTS[$i]}" IMAGE="$IMAGE" \
      bash serve/serve_vllm_rocm.sh up ) & pids+=($!)

#!/usr/bin/env python3
"""Generate an LLMServingSim-format JSONL workload from a ShareGPT-style dataset,
with a Poisson arrival process at a target rate — for the Tropical Phase-0 sweep.

Output schema (consumed by replay_jsonl.py):
  {"input_toks": int, "output_toks": int, "arrival_time_ns": int, "input_tok_ids": [int,...]}

Arrival rate is the sweep knob: regenerate at several --rate values to drive the
SLO-attainment-vs-arrival-rate curve (paper §V-B).

Example:
  python gen_workload.py \
    --dataset ~/Desktop/Moreh\\ Desktop/analysis/sharegpt_gpt4.json \
    --tokenizer Qwen/Qwen2.5-1.5B-Instruct --n 200 --rate 4 --seed 0 \
    --out workloads/sharegpt_qwen1.5b_n200_r4.jsonl

Requires: transformers
"""
import argparse, json, os, random
from pathlib import Path


def _iter_conversations(data):
    """Yield (human_text, gpt_text) from several common ShareGPT shapes."""
    if isinstance(data, dict):
        data = data.get("data") or data.get("items") or data.get("conversations") or []
    for elem in data:
        if not isinstance(elem, dict):
            continue
        # vicuna ShareGPT: {"conversations":[{"from":"human","value":...}, {"from":"gpt",...}]}
        conv = elem.get("conversations") or elem.get("items") or elem.get("conversation")
        human = gpt = None
        if isinstance(conv, list):
            for turn in conv:
                if not isinstance(turn, dict):
                    continue
                role = turn.get("from") or turn.get("role")
                val = turn.get("value") or turn.get("content") or ""
                if role in ("human", "user") and human is None:
                    human = val
                elif role in ("gpt", "assistant") and human is not None and gpt is None:
                    gpt = val
                    break
        else:
            # flat {"prompt":..,"response":..} / {"instruction":..,"output":..}
            human = elem.get("prompt") or elem.get("instruction") or elem.get("question")
            gpt = elem.get("response") or elem.get("output") or elem.get("answer")
        if human:
            yield human, (gpt or "")


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--dataset", required=True, help="ShareGPT-style JSON file")
    p.add_argument("--tokenizer", required=True, help="HF tokenizer matching the serving model")
    p.add_argument("--n", type=int, default=200, help="number of requests")
    p.add_argument("--rate", type=float, required=True, help="arrival rate (requests/sec, Poisson)")
    p.add_argument("--seed", type=int, default=0)
    p.add_argument("--min-in", type=int, default=8, help="min input tokens")
    p.add_argument("--max-in", type=int, default=8192, help="max input tokens (long-context cap)")
    p.add_argument("--min-out", type=int, default=8, help="min output tokens")
    p.add_argument("--max-out", type=int, default=512, help="max output tokens")
    p.add_argument("--out", required=True)
    args = p.parse_args()

    rng = random.Random(args.seed)
    ds_path = os.path.expanduser(args.dataset)
    with open(ds_path) as fp:
        data = json.load(fp)

    from transformers import AutoTokenizer
    tok = AutoTokenizer.from_pretrained(args.tokenizer, trust_remote_code=True)

    pool = []  # (input_ids, output_toks)
    for human, gpt in _iter_conversations(data):
        ids = tok(human, add_special_tokens=True)["input_ids"]
        if not (args.min_in <= len(ids) <= args.max_in):
            continue
        out_len = len(tok(gpt, add_special_tokens=False)["input_ids"]) if gpt else 0
        out_len = max(args.min_out, min(args.max_out, out_len or args.min_out))
        pool.append((ids, out_len))
        if len(pool) >= args.n * 4:  # gather a surplus, then sample n
            break

    if len(pool) < args.n:
        raise SystemExit(f"only {len(pool)} usable prompts in {ds_path} (need {args.n}); "
                         f"loosen --min-in/--max-in or pick a bigger dataset")
    rng.shuffle(pool)
    chosen = pool[:args.n]

    # Poisson arrivals: interarrival ~ Exp(rate)
    t_ns = 0
    out_path = Path(args.out)
    out_path.parent.mkdir(parents=True, exist_ok=True)
    with open(out_path, "w") as fp:
        for ids, out_len in chosen:
            gap_s = rng.expovariate(args.rate) if args.rate > 0 else 0.0
            t_ns += int(gap_s * 1e9)
            fp.write(json.dumps({
                "input_toks": len(ids),
                "output_toks": out_len,
                "arrival_time_ns": t_ns,
                "input_tok_ids": ids,
            }) + "\n")

    span_s = t_ns / 1e9
    in_lens = [len(i) for i, _ in chosen]
    out_lens = [o for _, o in chosen]

#!/usr/bin/env python3
"""Replay an LLMServingSim-format JSONL workload against an OpenAI-compatible
vLLM endpoint and emit a CSV in the same schema as LLMServingSim's outputs/*.csv.

Usage:
  python replay_jsonl.py \
    --workload /path/to/sharegpt-llama-3.1-8b-300-sps10.jsonl \
    --endpoint http://localhost:8000/v1/completions \
    --model meta-llama/Llama-3.1-8B \
    --tokenizer meta-llama/Llama-3.1-8B \
    --output llama8b_real_300.csv

Output columns (matches LLMServingSim scheduler.save_output exactly):
  instance id, request id, model, input, output, arrival, end_time,
  latency, queuing_delay, TTFT, TPOT, ITL

All time fields are nanoseconds since the replay start (matches sim's ns units).

Requires: aiohttp, transformers
"""

import argparse
import asyncio
import csv
import json
import time
from pathlib import Path
from typing import List, Dict, Any

import aiohttp


async def fire_one_request(
    session: aiohttp.ClientSession,
    endpoint: str,
    model: str,
    prompt: str,
    max_tokens: int,
    request_id: int,
    arrival_offset_ns: int,
    base_t0_ns: int,
) -> Dict[str, Any]:
    """Dispatch one streaming completion. Returns metric dict."""
    # Wait until this request's scheduled arrival relative to base_t0_ns.
    target_send_ns = base_t0_ns + arrival_offset_ns
    now_ns = time.monotonic_ns()
    if target_send_ns > now_ns:
        await asyncio.sleep((target_send_ns - now_ns) / 1e9)

    arrival_ns = time.monotonic_ns() - base_t0_ns

    payload = {
        "model": model,
        "prompt": prompt,
        "max_tokens": max_tokens,
        "temperature": 0.0,        # deterministic — single token at each step
        "top_p": 1.0,
        "stream": True,
        "ignore_eos": True,        # force exactly max_tokens generation
    }

    ttft_ns = -1
    last_chunk_ns = -1
    itl_ns: List[int] = []        # inter-token latency list (ns)
    tokens_emitted = 0
    error_msg = None

    try:
        async with session.post(endpoint, json=payload, timeout=aiohttp.ClientTimeout(total=600)) as resp:
            if resp.status != 200:
                error_msg = f"HTTP {resp.status}: {await resp.text()}"
            else:
                async for raw_line in resp.content:
                    if not raw_line:
                        continue
                    line = raw_line.decode("utf-8", errors="ignore").strip()
                    if not line or not line.startswith("data:"):
                        continue
                    payload_str = line[len("data:"):].strip()
                    if payload_str == "[DONE]":
                        break
                    try:
                        chunk = json.loads(payload_str)
                    except json.JSONDecodeError:
                        continue
                    choices = chunk.get("choices") or []
                    if not choices:
                        continue
                    text = choices[0].get("text", "")
                    if not text:
                        continue
                    now = time.monotonic_ns()
                    if ttft_ns < 0:
                        ttft_ns = now - base_t0_ns - arrival_ns
                    else:
                        itl_ns.append(now - last_chunk_ns)
                    last_chunk_ns = now
                    tokens_emitted += 1
    except Exception as exc:
        error_msg = f"{type(exc).__name__}: {exc}"

    end_ns = time.monotonic_ns() - base_t0_ns
    latency_ns = end_ns - arrival_ns
    if tokens_emitted > 1 and ttft_ns >= 0:
        tpot_ns = (latency_ns - ttft_ns) // (tokens_emitted - 1)
    else:
        tpot_ns = 0

    return {
        "request_id": request_id,
        "arrival_ns": arrival_ns,
        "end_ns": end_ns,
        "latency_ns": latency_ns,
        "ttft_ns": ttft_ns,
        "tpot_ns": tpot_ns,
        "itl_ns": itl_ns,
        "tokens_emitted": tokens_emitted,
        "error": error_msg,
    }


async def replay(args) -> None:
    # Load workload
    requests: List[Dict[str, Any]] = []
    with open(args.workload, "r") as fp:
        for idx, line in enumerate(fp):
            if not line.strip():
                continue
            rec = json.loads(line)
            requests.append({
                "id": idx,
                "input_toks": rec["input_toks"],
                "output_toks": rec["output_toks"],
                "arrival_time_ns": rec["arrival_time_ns"],
                "input_tok_ids": rec.get("input_tok_ids"),
            })
            if args.limit and len(requests) >= args.limit:
                break

    print(f"[replay] loaded {len(requests)} requests from {args.workload}")

    # Detokenize input_tok_ids to prompt strings
    from transformers import AutoTokenizer
    tok = AutoTokenizer.from_pretrained(args.tokenizer, trust_remote_code=True)
    for req in requests:
        ids = req["input_tok_ids"]
        if ids is None:
            raise RuntimeError(f"request {req['id']} has no input_tok_ids — cannot replay exactly")
        req["prompt"] = tok.decode(ids, skip_special_tokens=False)

    print(f"[replay] detokenized {len(requests)} prompts (tokenizer={args.tokenizer})")
    print(f"[replay] firing against {args.endpoint} (model={args.model})")

    base_t0_ns = time.monotonic_ns()

    connector = aiohttp.TCPConnector(limit=args.max_inflight)
    async with aiohttp.ClientSession(connector=connector) as session:
        tasks = [
            asyncio.create_task(
                fire_one_request(
                    session, args.endpoint, args.model,
                    req["prompt"], req["output_toks"],
                    req["id"], req["arrival_time_ns"], base_t0_ns,
                )
            )
            for req in requests
        ]
        done_results = []
        for i, fut in enumerate(asyncio.as_completed(tasks)):
            res = await fut
            done_results.append(res)
            if (i + 1) % 10 == 0:
                print(f"[replay] {i+1}/{len(tasks)} done")

    # Match results back to requests by id and write CSV in LLMServingSim schema
    res_by_id = {r["request_id"]: r for r in done_results}

    out_path = Path(args.output)
    out_path.parent.mkdir(parents=True, exist_ok=True)
    with open(out_path, "w", newline="") as fp:
        writer = csv.writer(fp)
        writer.writerow([
            "instance id", "request id", "model",
            "input", "output",
            "arrival", "end_time", "latency",
            "queuing_delay", "TTFT", "TPOT", "ITL",
        ])
        for req in requests:
            r = res_by_id.get(req["id"])
            if r is None or r.get("error"):
                continue
            writer.writerow([
                0,                      # instance id (real vLLM = single instance)
                req["id"],
                args.model,
                req["input_toks"],
                req["output_toks"],     # gen tokens only (matches sim: output - input == gen)
                r["arrival_ns"],
                r["end_ns"],
                r["latency_ns"],
                0,                      # queuing_delay — real vLLM doesn't separately expose this
                r["ttft_ns"],
                r["tpot_ns"],
                r["itl_ns"],
            ])

    errs = [r for r in done_results if r.get("error")]
    print(f"[replay] wrote {len(done_results) - len(errs)} rows to {out_path}")
    if errs:
        print(f"[replay] {len(errs)} errors:")
        for r in errs[:5]:
            print(f"  req {r['request_id']}: {r['error']}")

    p.add_argument("--max-inflight", type=int, default=512, help="Max concurrent TCP connections")
    p.add_argument("--limit", type=int, default=0, help="Only replay first N requests (0=all)")

#!/usr/bin/env python3
"""Compute SLO attainment from replay CSVs (LLMServingSim schema), reproducing
the Tropical paper's §V metrics: TTFT/TPOT p50/p90, and SLO attainment vs
arrival rate, with a Pareto (TTFT-attain vs TPOT-attain) view.

SLO definition (paper §V-A): TTFT SLO = `--ttft-mult` × light-load TTFT.
TPOT SLO = `--tpot-mult` × light-load TPOT. "Light load" = the lowest arrival
rate present for each system (or override with --calib-rate). A request *attains*
if TTFT ≤ TTFT-SLO AND TPOT ≤ TPOT-SLO.

Input: a directory of CSVs named `{system}_rate-{rate}.csv` (what run_phase0.sh
writes). Pure stdlib — runs anywhere.

  python analyze_slo.py results/ --ttft-mult 5 --tpot-mult 5
"""
import argparse, ast, csv, glob, os, re
from statistics import median

NAME_RE = re.compile(r"(?P<system>.+?)_rate-(?P<rate>[0-9.]+)\.csv$")


def pct(xs, q):
    if not xs:
        return float("nan")
    s = sorted(xs)
    k = (len(s) - 1) * q
    lo = int(k)
    hi = min(lo + 1, len(s) - 1)
    return s[lo] + (s[hi] - s[lo]) * (k - lo)


def load_csv(path):
    """Return list of {ttft_ms, tpot_ms} for non-error rows."""
    rows = []
    with open(path) as fp:
        for r in csv.DictReader(fp):
            try:
                ttft = float(r["TTFT"]) / 1e6   # ns -> ms
                tpot = float(r["TPOT"]) / 1e6
            except (KeyError, ValueError):
                continue
            if ttft <= 0:
                continue
            rows.append({"ttft_ms": ttft, "tpot_ms": tpot})
    return rows


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("results_dir")
    ap.add_argument("--ttft-mult", type=float, default=5.0)
    ap.add_argument("--tpot-mult", type=float, default=5.0)
    ap.add_argument("--ttft-slo-ms", type=float, default=0, help="override absolute TTFT SLO (ms)")
    ap.add_argument("--tpot-slo-ms", type=float, default=0, help="override absolute TPOT SLO (ms)")
    ap.add_argument("--calib-rate", type=float, default=0, help="rate to treat as light load (default=min per system)")
    args = ap.parse_args()

    files = sorted(glob.glob(os.path.join(args.results_dir, "*.csv")))
    runs = {}  # system -> {rate: rows}
    for f in files:
        m = NAME_RE.search(os.path.basename(f))
        if not m:
            print(f"[skip] unparseable name: {f}")
            continue
        sysname, rate = m["system"], float(m["rate"])
        rows = load_csv(f)
        if rows:
            runs.setdefault(sysname, {})[rate] = rows

    if not runs:
        raise SystemExit(f"no parseable CSVs in {args.results_dir} (expect {{system}}_rate-{{rate}}.csv)")

    print("\n========== SLO attainment ==========")
    summary = {}  # system -> list of (rate, ttft_attn, tpot_attn, both)
    for sysname in sorted(runs):
        by_rate = runs[sysname]
        calib = args.calib_rate or min(by_rate)
        cal_rows = by_rate.get(calib) or by_rate[min(by_rate)]
        ttft_slo = args.ttft_slo_ms or args.ttft_mult * median(r["ttft_ms"] for r in cal_rows)
        tpot_slo = args.tpot_slo_ms or args.tpot_mult * median(r["tpot_ms"] for r in cal_rows)

        print(f"\n### {sysname}   (light load = {calib} rps;  "
              f"TTFT-SLO={ttft_slo:.0f}ms  TPOT-SLO={tpot_slo:.1f}ms)")
        print(f"{'rate':>6} {'n':>5} {'TTFT p50':>9} {'p90':>8} {'TPOT p50':>9} {'p90':>8} "
              f"{'TTFT%':>6} {'TPOT%':>6} {'SLO%':>6}")
        summary[sysname] = []
        for rate in sorted(by_rate):
            rows = by_rate[rate]
            n = len(rows)
            ttft_ok = sum(1 for r in rows if r["ttft_ms"] <= ttft_slo) / n
            tpot_ok = sum(1 for r in rows if r["tpot_ms"] <= tpot_slo) / n
            both = sum(1 for r in rows if r["ttft_ms"] <= ttft_slo and r["tpot_ms"] <= tpot_slo) / n
            print(f"{rate:>6.1f} {n:>5} "
                  f"{pct([r['ttft_ms'] for r in rows],.5):>9.0f} {pct([r['ttft_ms'] for r in rows],.9):>8.0f} "
                  f"{pct([r['tpot_ms'] for r in rows],.5):>9.1f} {pct([r['tpot_ms'] for r in rows],.9):>8.1f} "
                  f"{ttft_ok*100:>6.1f} {tpot_ok*100:>6.1f} {both*100:>6.1f}")
            summary[sysname].append((rate, ttft_ok, tpot_ok, both))

    # attainment-vs-rate (the §V-B headline: who holds ≥90% longest)
    print("\n========== ≥90% SLO attainment — max sustained rate ==========")
    for sysname in sorted(summary):
        ok = [r for (r, _, _, both) in summary[sysname] if both >= 0.90]
        held = max(ok) if ok else 0
        print(f"  {sysname:<12} holds ≥90% up to {held:>5.1f} rps")

    # Pareto at the highest shared load
    print("\n========== Pareto (TTFT-attain vs TPOT-attain) @ each system's top rate ==========")
    for sysname in sorted(summary):
        top = summary[sysname][-1]
        print(f"  {sysname:<12} @ {top[0]:>5.1f} rps:  TTFT {top[1]*100:5.1f}%   TPOT {top[2]*100:5.1f}%   both {top[3]*100:5.1f}%")
    print()


if __name__ == "__main__":
    main()

"""InFaaS-style dispatcher for the Tropical Phase-0.5 pool.

Routes each request to the backend with the FEWEST UNFINISHED TOKENS (in-flight
max_tokens summed per backend), and streams the SSE response straight back.

This is the SEED OF THE TROPICAL TOGGLE: Phase 2 replaces the pick-min policy
with the slack-guarded Path-①/② admission (per-request TTFT-slack, per-worker
TPOT-slack, HBM watermark). For now it's a plain SLO-agnostic load balancer so
the 4-worker baselines are apples-to-apple with the paper's InFaaS dispatch.

Run inside the vLLM image (has aiohttp), --network host:
  BACKENDS=http://localhost:8001,http://localhost:8002,http://localhost:8003,http://localhost:8004 \
  PORT=8000 python dispatcher.py
"""
import os, asyncio
from aiohttp import web, ClientSession, ClientTimeout

BACKENDS = [b for b in os.environ.get("BACKENDS", "http://localhost:8001").split(",") if b]
PORT = int(os.environ.get("PORT", "8000"))
inflight = {b: 0 for b in BACKENDS}      # unfinished-token estimate per backend
served = {b: 0 for b in BACKENDS}        # cumulative routed count (for /stats)
lock = asyncio.Lock()


async def pick_backend():
    async with lock:
        return min(BACKENDS, key=lambda b: inflight[b])


async def proxy(request: web.Request, path: str):
    try:
        body = await request.json()
    except Exception:
        return web.json_response({"error": "bad json"}, status=400)
    maxtok = int(body.get("max_tokens") or body.get("max_completion_tokens") or 16)

    backend = await pick_backend()
    async with lock:
        inflight[backend] += maxtok
        served[backend] += 1

    session: ClientSession = request.app["session"]
    try:
        async with session.post(backend + path, json=body,
                                timeout=ClientTimeout(total=3600, sock_read=600)) as up:
            resp = web.StreamResponse(
                status=up.status,
                headers={"Content-Type": up.headers.get("Content-Type", "application/json")})
            await resp.prepare(request)
            async for chunk in up.content.iter_any():
                await resp.write(chunk)
            await resp.write_eof()
            return resp
    except Exception as exc:
        return web.json_response({"error": f"{type(exc).__name__}: {exc}",
                                  "backend": backend}, status=502)
    finally:
        async with lock:
            inflight[backend] -= maxtok


async def completions(request):       return await proxy(request, "/v1/completions")
async def chat_completions(request):  return await proxy(request, "/v1/chat/completions")


async def health(request):
    """OK only if every backend is healthy (used by pool_up's wait loop)."""
    session: ClientSession = request.app["session"]
    for b in BACKENDS:
        try:
            async with session.get(b + "/health", timeout=ClientTimeout(total=3)) as r:
                if r.status != 200:
                    return web.json_response({"status": "down", "backend": b}, status=503)
        except Exception:
            return web.json_response({"status": "down", "backend": b}, status=503)
    return web.json_response({"status": "ok", "backends": len(BACKENDS)})


async def models(request):
    session: ClientSession = request.app["session"]
    async with session.get(BACKENDS[0] + "/v1/models") as r:
        return web.json_response(await r.json(), status=r.status)


async def stats(request):
    async with lock:
        return web.json_response({"inflight": dict(inflight), "served": dict(served)})


async def on_start(app):  app["session"] = ClientSession()
async def on_clean(app):  await app["session"].close()


def main():
    app = web.Application(client_max_size=64 * 1024 * 1024)
    app.on_startup.append(on_start)
    app.on_cleanup.append(on_clean)
    app.add_routes([
        web.post("/v1/completions", completions),
        web.post("/v1/chat/completions", chat_completions),
        web.get("/health", health),
        web.get("/v1/models", models),
        web.get("/stats", stats),
    ])
    print(f"[dispatcher] :{PORT} -> {len(BACKENDS)} backends (fewest-unfinished-tokens)", flush=True)
    web.run_app(app, host="0.0.0.0", port=PORT, print=None)


if __name__ == "__main__":
    main()
