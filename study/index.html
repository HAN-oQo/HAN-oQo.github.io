Kimi K3: Open Frontier Intelligence Kimi K3: Open Frontier Intelligence

Paper note on Moonshot AI's Kimi K3 (arXiv:2607.24653) — the first open 3-trillion-parameter-class model: a 2.8T MoE (104B active), native vision, 1M context. Explained in plain language for an AI-model audience: it scales "information flow" along three axes — Kimi Delta Attention (gated linear attention that keeps a fixed-size state instead of a growing KV cache, on 69 of 93 layers), Attention Residuals (attention across depth), and Stable LatentMoE (896 experts / 16 active, kept from exploding by RMSNorm + bounded SiTU-GLU + quantile balancing) — for a claimed ~2.5× scaling efficiency over K2. vLLM PagedAttention v1 vs v2 — what the two decode kernels do, and where they went vLLM PagedAttention v1 vs v2 — 두 디코드 커널이 뭐가 다른가, 그리고 어디로 갔나

vLLM's original attention had two CUDA kernels, paged_attention_v1 and v2; they compute the same paged-KV decode attention but parallelize differently. v1 = one GPU block per (sequence, head) sweeps the whole context in one pass — fine when there are enough blocks to fill the GPU. v2 = split each sequence's KV into 512-token partitions, compute partial softmax per partition in parallel, then a reduction kernel stitches them via log-sum-exp — this is Flash-Decoding, for small-batch long-context decode where v1 leaves most SMs idle. Covers the exact use_v1 dispatch heuristic, and the twist: at HEAD (2026-07-30) the CUDA kernels have been deleted (PR #47361 "Delete PagedAttention" — body: "It is time"), replaced by FlashAttention/FlashInfer/Triton; the v1/v2 split now survives in vLLM's ROCm/AITER path (partition 256). Written for an AI-model audience (SM, occupancy, warp, split-K unpacked); diagram + code flow with permalinks pinned to pre-deletion commits. vLLM의 초기 어텐션엔 CUDA 커널이 둘, paged_attention_v1과 v2가 있었다; 같은 paged-KV 디코드 어텐션을 계산하지만 병렬화가 다르다. v1 = (시퀀스, 헤드)당 GPU 블록 하나가 전체 컨텍스트를 한 번에 훑음 — 블록이 GPU를 채울 만큼 많으면 괜찮다. v2 = 각 시퀀스의 KV를 512 토큰 파티션으로 쪼개 파티션마다 부분 softmax를 병렬 계산한 뒤 reduction 커널이 log-sum-exp로 이어 붙임 — 이게 Flash-Decoding, v1이 SM 대부분을 놀리는 작은 배치·긴 컨텍스트 디코드용. 정확한 use_v1 dispatch 휴리스틱과 반전을 다룬다: HEAD(2026-07-30)에선 CUDA 커널이 삭제됨(PR #47361 "Delete PagedAttention" — 본문: "It is time"), FlashAttention/FlashInfer/Triton으로 대체; v1/v2 구분은 이제 vLLM의 ROCm/AITER 경로(파티션 256)에 생존. AI 모델 독자용(SM·occupancy·warp·split-K 풀이); 다이어그램 + 삭제 전 커밋에 핀된 permalink 코드 흐름.

SGLang HiSparse — hierarchical KV offloading for sparse attention SGLang HiSparse — 희소 어텐션을 위한 계층적 KV 오프로딩

Sparse attention (top-k) is capacity-bound, not compute-bound — the full KV cache must stay in HBM even though only top-k is active per step, capping batch size. HiSparse is SGLang's decode-side fix: keep a small hot KV buffer on the GPU, offload the full history to host (CPU pinned) RAM, and swap each step's top-k back with a custom CUDA kernel + LRU. Covers the theory (with the similarly-named HySparse Xiaomi architecture paper as backbone — a different work), the hot-buffer/host-pool/swap-in mechanism, the honest effects (vendor-reported >3× @256 conc / up to 5× long-context, but a documented regression at low concurrency), flags & serve commands, and the end-to-end SGLang code flow with permalinks pinned to commit fc8b328. For DSA models (DeepSeek-V3.2/V4, GLM-5.x), PD-decode only, experimental. Diagrams + cited sources. 희소 어텐션(top-k)은 연산 바운드가 아니라 용량 바운드 — 스텝당 top-k만 활성이어도 전체 KV 캐시가 HBM에 남아야 해 배치 크기를 막는다. HiSparse는 SGLang의 decode 측 해법: GPU엔 작은 hot KV 버퍼, 전체 히스토리는 호스트(CPU pinned) RAM으로 오프로드, 매 스텝 top-k를 커스텀 CUDA 커널 + LRU로 다시 불러온다. 이론(이름 비슷한 HySparse Xiaomi 아키텍처 논문을 backbone으로 — 별개 연구), hot 버퍼/호스트 풀/swap-in 메커니즘, 정직한 효과(벤더 보고 256동시성 3배↑ / 롱컨텍스트 최대 5배, 단 낮은 동시성에선 문서화된 회귀), 플래그·실행 커맨드, 그리고 커밋 fc8b328에 핀된 permalink로 짚는 SGLang end-to-end 코드 흐름. DSA 모델(DeepSeek-V3.2/V4, GLM-5.x), PD-decode 전용, 실험적. 다이어그램 + 인용 출처.

OpenVLA: An Open-Source Vision-Language-Action Model OpenVLA: An Open-Source Vision-Language-Action Model

A 7B model (fused DINOv2+SigLIP → Llama-2) that emits robot actions as 256-bin discretized tokens (the last 256 Llama vocab ids), trained on 970k Open X-Embodiment demos; beats the closed 55B RT-2-X by 16.5% absolute at 7× fewer params, and is first to show LoRA (1.4% of params) and int4 (7 GB) for VLAs.
