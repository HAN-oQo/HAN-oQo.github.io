Problem문제 정의Speculative decoding speeds up generation by letting a draft model propose tokens that a target model then accepts or rejects so the output still matches the target distribution. Porting this trick to continuous diffusion models is hard, because the accept/reject step needs to draw from a residual distribution that is easy to sample for discrete tokens but awkward for continuous diffusions.추측 디코딩은 draft 모델이 토큰을 제안하고 target 모델이 수용/거부해 출력이 target 분포와 일치하도록 하면서 생성을 가속한다. 이 기법을 연속 디퓨전 모델로 옮기기는 어렵다 — 수용/거부 단계가 잔차(residual) 분포에서 표본을 뽑아야 하는데, 이산 토큰에선 쉽지만 연속 디퓨전에선 까다롭다.
Method방법The authors verify a whole block of diffusion steps at once rather than one step at a time, reformulating speculative sampling so the residual draw becomes tractable for the continuous setting, and reuse the existing parallel verification pass so there is no extra training and negligible overhead.저자들은 한 스텝씩이 아니라 디퓨전 스텝 블록 전체를 한 번에 검증하고, 잔차 추출이 연속 설정에서 다루기 쉬워지도록 추측 표집을 재정식화하며, 기존 병렬 검증 패스를 재사용해 추가 학습 없이 오버헤드를 거의 0으로 만든다.
Results결과Block verification yields up to a 6.3% speedup over existing speculative methods for diffusions with no additional training and negligible overhead beyond the verification pass already being run — a clean, drop-in acceleration.블록 검증은 추가 학습 없이, 이미 돌리는 검증 패스 외 오버헤드가 거의 없이, 기존 디퓨전 추측 기법 대비 최대 6.3% 가속을 낸다 — 깔끔한 드롭인 가속이다.
Summary요약Verify diffusion drafts a block at a time, not a step at a time — speculative decoding finally fits continuous diffusions.디퓨전 draft를 스텝이 아니라 블록 단위로 검증하라 — 추측 디코딩이 마침내 연속 디퓨전에 맞는다.

Problem문제 정의Post-training quantization is essential for cheap inference, but pushing weights, activations and the KV cache all to 4-bit is fragile. Method방법DynamicPTQ studies how these extreme activations move through the residual stream layer to layer, and adapts quantization dynamically along that path instead of treating each tensor in isolation — channeling the error away from the values that matter most.DynamicPTQ는 이 극단 활성값이 레이어를 거치며 residual stream을 따라 어떻게 이동하는지 분석하고, 각 텐서를 고립적으로 다루지 않고 그 경로를 따라 양자화를 동적으로 조정한다 — 가장 중요한 값에서 오차를 비켜가게 한다.

Method방법The paper makes a locality-aware GEMM schedule compatible with page-granularity memory placement, so the kernel's tiling lines up with which chiplet physically owns each page — turning placement decisions and compute schedules into one coordinated plan rather than two systems fighting each other.논문은 locality-aware GEMM 스케줄을 페이지 단위 메모리 배치와 호환되게 만들어, 커널의 타일링이 각 페이지를 물리적으로 소유한 칩렛과 정렬되도록 한다 — 배치 결정과 연산 스케줄을 서로 싸우는 두 시스템이 아니라 하나의 조율된 계획으로 만든다.
Results결과Aligning GEMM tiles with page placement keeps more operand traffic chiplet-local, cutting the cross-chiplet hops that dominate latency on these non-uniform memory systems and improving achieved throughput for inference-style matrix multiplies.GEMM 타일을 페이지 배치와 정렬하면 더 많은 피연산자 트래픽이 칩렛 내부에 머물러, 이 비균일 메모리 시스템에서 지연을 지배하는 칩렛 간 홉을 줄이고 추론형 행렬곱의 실측 처리량을 높인다.
Summary요약On chiplet GPUs, schedule the matrix multiply where the pages already live — locality is throughput.칩렛 GPU에선 페이지가 이미 사는 곳에서 행렬곱을 스케줄하라 — 지역성이 곧 처리량이다.
